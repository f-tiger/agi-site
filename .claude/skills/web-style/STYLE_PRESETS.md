# 风格预设

面向中文用户的网站风格预设。每套给出定位、色彩 token、字体、构件特征与适用场景。
用法：在视觉化选型阶段挑 3–4 套生成预览，不要一次全上。

## A · 朱砂票券（中式传统）

**像什么**：老式票据、印章、丹青。
**适合**：优惠 / 福利 / 收藏类，需要"经手核验"的可信感。

- 色彩：`--paper #f4f2ef` `--ink #1d1a19` `--cinnabar #c8352a`（强调）`--jade #0f7a63`（正向语义）
- 字体：标题宋体（`Songti SC / SimSun`），正文黑体（`PingFang SC`）
- 构件：卡片带虚线撕口与半圆缺口，模拟票根；关键状态用印章样式（旋转 -4°、朱红描边）
- 禁忌：不要满屏红，朱砂只用在强调与印章上

## B · 素纸墨线（极简克制）

**像什么**：Linear、Vercel 的中文版；产品经理与设计师会觉得"高级"。
**适合**：工具型、开发者向、信息密度高但要显得干净的站。

- 色彩：`--bg #ffffff` `--ink #0a0a0a` `--mute #737373` `--line #e5e5e5`，强调色只用一个（如 `#2563eb`），且只出现在可点击处
- 字体：全站无衬线，靠字重（400/500/700）和字号阶梯拉层次，不靠颜色
- 构件：分隔线代替卡片阴影；大量留白；数字用等宽数字对齐
- 禁忌：不要加圆角以外的任何装饰，不要用渐变

## C · 终端暗色（开发者向）

**像什么**：命令行、代码编辑器。
**适合**：API、编程工具、技术受众占比高的站。

- 色彩：`--bg #0d1117` `--surface #161b22` `--ink #e6edf3` `--accent #3fb950`（终端绿）或 `#58a6ff`
- 字体：标题与数据用等宽（`SF Mono / JetBrains Mono / 更纱黑体`），正文用无衬线
- 构件：方角或小圆角、1px 边框、hover 时边框亮起而非阴影；标签像终端徽章
- 禁忌：别让整页都是等宽字，正文长文本可读性会崩

## D · 榜单促销（中式电商）

**像什么**：什么值得买、京东秒杀页。
**适合**：折扣 / 薅羊毛 / 榜单类，用户预期就是"信息多、有紧迫感"。

- 色彩：`--bg #f5f5f5` `--card #fff` `--ink #222` `--hot #e63946`（价格/优惠）`--gold #ff8f00`（榜单标记）
- 字体：全黑体，标题字重 700 以上，价格用超大字号 + 等宽数字
- 构件：高密度卡片、角标（"限时""每日""0元"）、榜单序号、红色价格对比（原价划线）
- 禁忌：角标别超过 2 个/卡片，否则从"促销感"变成"牛皮癣"

## E · 学术白（严谨克制）

**像什么**：论文、文档站。
**适合**：科研、教育、需要引用与出处的内容。

- 色彩：`--bg #fbfbfa` `--ink #1a1a1a` `--accent #0f4c81`（学术蓝）`--line #e0e0e0`
- 字体：标题衬线（`Source Han Serif / Songti SC`），正文无衬线，行高放到 1.8+
- 构件：编号列表、引用块、脚注样式；表格用细横线不用竖线
- 禁忌：不要用高饱和色，不要用卡片阴影

## 挑选建议

- 受众是**普通中文用户 / 消费决策**场景 → D 或 A
- 受众是**开发者 / 设计师** → B 或 C
- 内容是**知识 / 研究** → E
- 想要**辨识度**而非安全 → A（从主题世界里长出来的风格最不容易撞脸）
