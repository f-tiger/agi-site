# 舰队营销执行：先形成获客证据

## 三轮优化后的执行指令

1. 目标：用 AGI/BPJ/ECO/TDS 的真实任务验证外部获客；先形成可复核案例，再考虑销售营销 MCP/技能。交付不是发布数量，而是可核验的渠道状态、到站事件、真实工具动作及成本。
2. 对抗：不能用内部跳转、爬虫、示例或 CI 事件冒充用户增长；网站功能多不等于有渠道；缺少曝光不能证明需求不存在。以可访问账号为执行边界，Pinterest/DEV 登录未完成时不重复请求验证。
3. 执行：检查一手基线、比较路线、只落地一个能完整度量的新内容角度。继续已获授权的 YouTube/TikTok 自然发布；不买广告、不发外联、不新增自动化、不恢复 ECO 储能/阳台光伏。

## 实际证据与本轮决策

Search Console web 查询窗口为 2026-08-30 至 2026-09-26（America/Los_Angeles）。AGI 1 点击/161 展示；BPJ 3/663；ECO 0/92；TDS 4/348。完整摘要见同目录 marketing-baseline-2026-09-30.json。这不是全站流量，也不覆盖新视频发布后时段。TDS 点击落在 /rarity、/、/checker，不能视为图片工具需求。

Metricool 对 2026-09-29 至 09-30 初的 YouTube/TikTok 指标读取返回 rows=[]；播放、观看时长、点击率均未知。旧视频已有 provider 发布证据，但不能据空数据判定营销失败。

| 路线 | 此轮决定 | 可证伪条件 |
|---|---|---|
| 四站互链 | 暂不铺开；任务相关性弱，Google 流量基数小，其他渠道总量未核实 | 只有存在具体后续任务与相关入口数据才试一个推荐位；内部流量始终独立 |
| 现有视频账号 | 执行 ECO 固定费用角度，一条内容、两种画幅、两个平台 | 先取得平台发布证据；再看曝光→到站→自有输入计算 |
| Pinterest / DEV | 素材保留，登录未完成，不将准备当发布 | 账号连接且平台准入完成后才恢复 |
| 嵌入/工作流模板 | 已有 ECO embed 与 TDS ZIP，维持，不继续堆功能 | 以真实第三方安装或实际使用反馈为扩展门槛 |
| 分享结果 | 现有能力维持，先测分享后的外部访问 | 分享按钮动作不等于分享送达或获客 |
| 社区答疑/合作 | 未获具体外联授权，不发送 | 找到真实问题与允许的参与方式，再就具体对象执行 |
| 付费分发 | 不执行 | 未验证到站激活，不投入预算 |

这是路线优先级判断，不是渠道收益排名。

## 已实现的获客实验

- campaign：`eco-fixed-02`，旧 `eco-bonus-01` 的默认查询保持不变。
- 主题：Lower Electricity Rate, Higher Bill? Check the Fixed Fee。
- 受众假设：正在比较两份按年固定费用+单价电价合同的用户；英语视频不等于已证明地域适配。
- 独立内容价值：虚构 A 0.30 EUR/kWh + 120 EUR/year；B 0.27 + 240。3,500 kWh 时 A=1,170，B=1,185；4,000 kWh 时都是1,320。无奖金、无换约成本、固定价格与用量，非供应商报价或节省承诺。
- 原创图示、英文合成配音、烧录英文字幕；源码 `tools/marketing/eco-fixed-02/render.py`。
- 入口：`/bill-youtube` 和 `/bill-tiktok` 固定302到现有英文工具，携带独立UTM；不接受任意跳转目标、不收集输入。
- 画面明确让观众在浏览器输入地址，不声称 TikTok 简介或视频描述链接可以点击。YouTube 使用横版普通视频；其外链是否可点击仍取决于频道功能资格，尚未验证。
- 查询：`/api/video-growth?campaign=eco-fixed-02`。仅完整UTC日，按平台/证据/示例或自有输入分列；缺失referrer只能是tag_only，内部跳转不能算外部增长。URL标签可以复制或伪造。
- 缓存按campaign分开；未知campaign返回400，不触发D1全表读取。旧新campaign不能混算。

## 继续/停止门槛（经营规则，不是统计显著性）

从真实发布日期开始累计7个完整UTC日，再评估（本文件不创建提醒）。如果平台数据仍缺失，结论为数据不足；若少于500次平台观看，先判断分发不足，不能否定工具需求。达到500次观看但没有可辨认的到站证据，先改入口或CTA，不制作更多同类视频。取得至少20次外部referrer页面事件、5次自有输入计算后才考虑下一条同受众内容；事件不能换算成独立人数或转化率。只有tag_only信号时作为线索，不宣布平台归因成立。

若到站后没有自有输入计算，检查语言、第一屏、输入门槛与任务匹配；不得用增加视频数量掩盖激活问题。最终商业验证仍需独立用户重复任务和实际收入凭据。
