# TDS 每日 1,000 用户目标：计量与第一轮入口修复

日期：2026-11-07。用户要求持续对标成熟联盟站、改进 TDS 并上线，目标是每天 1,000 人；此前确认的每月全站总收入 USD100 仍保留。这是增长目标，不能用上线次数、自动请求或页面产量代替。

## 三轮 Prompt 优化及执行口径

1. **目标**：持续改善 TDS 的有效获客和购买决策。暂以连续七个完整报告日的 GA4 日 `totalUsers` 平均值至少 1,000 作为操作验收线，同时分别核对站点可归因收入。此口径是本轮公开说明的执行假设，不是用户已经确认的统计定义。
2. **约束**：只用可核实来源和现有授权、渠道、预算；不把 Cloudflare unique IP、匿名动作、浏览量、机器人或 QA 当人；不虚构竞品 CTR/CVR、成交或预测达标日期。继续遵守隐私退出与现有数据限制。
3. **验收**：先确认读数可用，再按真实漏斗缺口选择一次改进，完成代码、测试、部署、生产核验、SEO/GEO/IndexNow及回执。缺测时保留 unknown，只执行已有证据支持的独立修复；不能因为功能完成就宣布流量目标完成。

执行 Prompt：围绕收藏者的展示、收纳、携带和送礼任务，持续比较 TIWIB 与 Wirecutter 的获客、类目、营销和点击路径。读取同口径完整日期的 TDS 数据，识别一个能改变用户下一步的缺口，实施并上线最小有效修复。分别记录交付、外部分发、访问、购买意图和可归因收入；保留未知和失败证据。下一轮由已有观测决定，不机械生成页面或重复发布内容。

## 为什么现有数字不能验收

- 既有 Cloudflare `uniques` 来自边缘请求，含自动化、扫描及其他请求，不等于自然人或合格买家。即使读数出现 1,000，也不能作为本目标完成凭据。
- 第一方 `human_pv` 和购物事件没有可靠的人级去重，不能替换 GA4 日用户数，亦不能把两个匿名事件总数相除称用户转化率。
- 最近原生统计任务缺少 GA4 配置；连接器访问又受到当前套餐限制。绿色任务不等于取数成功，缺测不等于零流量。私人账户读数、报表和标识不进入公开仓库。
- GA4 `totalUsers` 仍只是测得的用户代理：浏览器/设备、隐私退出、阻断与剩余自动化都会影响统计，不能声称验证了独立自然人。七日均值是七个日计数的平均，不是七日去重人数除以七，也不表示每一天都达到 1,000。

代码审计发现：28 个系列 × 3 种语言的展示配件入口仍指向旧收藏指南，中文还转到英文；8 个品牌 × 3 种语言的尺寸工具下一步没有按任务接到新导购。这些是可直接复现的路径问题，不是从缺失流量中推断出来的跳出率。

## 本轮产品和计量实现

- **84 个系列页**：展示配件入口改为同语言 `/shop/display-cases`，同步可读文字镜像。
- **24 个品牌页**：Jellycat 空间工具之后进入同语言 `/shop/plush-display`；另外七品牌进入 `/shop/display-cases`。保留独立通用购物目录入口及原计算工具。
- **毛绒说明**：测量耳朵、尾部与完整姿态及可用架面，不把硬质柜门间隙套用到毛绒。模板修改日与官方资料核对日分别保留。
- **GA4 只读目标检查**：复用既有 06:00 UTC 任务，固定主域 hostname、`date` 与 `totalUsers`；按属性时区请求 `10daysAgo` 到 `4daysAgo`，留下三个完整报告日期的处理缓冲，并拒绝跨午夜歧义。此缓冲不保证数据最终不会修订。
- **质量闸门**：必须返回七个唯一、连续且正好匹配的报告日；拒绝缺行、错误结构、非安全整数、阈值、采样和 other-row 数据损失。失败为 unknown，不将漏报日补零。默认只在内存读取，公开日志仅固定 health/result，绝不输出人数、属性 ID 或原始 API 错误。
- **GSC 健康检查**：既有只读脚本放到私有临时目录执行，捕获其 stdout/stderr，检查报告后清理，只公布固定 health。移除工作流中原始 GA4/GSC 报表的公开提交路径。既有边缘与第一方聚合任务未改变其口径，不能与新代理混用。

所需的是仓库已有命名的 `GA4_PROPERTY_ID_TDS`、`GA4_SERVICE_ACCOUNT_JSON` 和 TDS 属性 Viewer 权限；密钥不得粘贴到聊天或提交到仓库。GSC 还要求同一账号对该站点有读取权限。读取流程不会创建账号、增加权限或购买连接器。接入未完成时，待下一次现有任务执行或有限只读核对，不能为得到达标结果重复重试。

## 两轮自我质疑

**入口修复会带来 1,000 人吗？** 不会凭实现就知道。它解决已有路径断点，可能改善到站后的决策，不能替代外部获客或创造搜索需求。下一轮必须区分曝光不足、搜索点击不足、意图不匹配和商家成交问题；没有分母就不计算转化率。

**绿灯会不会再次掩盖缺测，或误泄露数据？** 新任务显式输出 missing/unknown/quality 状态；GA4 原始响应不落盘，GSC 临时文件清理，公开日志和提交不含原始 Google 报表。七日均值只作为代理达标线，数据质量和真实商业结果仍须分别评估。持续升级不代表无限加功能或无依据等待增长。
