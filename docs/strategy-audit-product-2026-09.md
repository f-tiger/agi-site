# 把股票方向变成一个可售卖的工具:卖的是尺子,不是预测(2026-09-11)

owner 原话:「继续搞清楚这个方向,变成一个工具,并可以售卖」。

**一句话结论**:这个方向里**可售卖且合法的部分不是预测,是测量**。三轮调研已经把预测那半边
钉死了(公开最好的月度样本外 R² 只有 0,26–0,40%;真钱 8 年半的 AIEQ 输指数约 4,9 个百分点/年;
年化 100% 需要夏普 ≥1,177 而 Medallion 费后也只有 39%)。而**「这份业绩记录到底算不算数」
这件事:是算术、不是受监管的投顾、并且几乎没人在卖**。所有回测平台都在帮你**造**回测,
没有一家在问你造出来的那个**经不经得起多重检验**。

**已建(零 owner 动作)**:`tools/strategy-audit/audit.py`(单文件、零依赖、35 条自检)+
免费网页 `/backtest-audit`(**纯浏览器运行,数据不出本机**)+ 一条**跨实现对等测试**
(从已发布页面里抽出 JS,与 Python 在同一批夹具上比对 129 个字段,挂在 agiscorecard 部署路径上)。
**售卖路径不新建任何基建**:免费工具做需求入口,付费的是 `/audits` 上已有的定价审计。

## 二、为什么是「尺子」:监管边界就落在一句话上

| | 卖**预测** | 卖**测量** |
|---|---|---|
| 输出 | 「买 X / 持有 Y / 下月看多」 | 「你这条曲线的夏普在 200 次试验后不显著」 |
| 德国 | Anlageberatung / Anlagevermittlung,BaFin 许可 | 不是投顾:没有针对金融工具的个人化推荐 |
| 美国 | RIA 注册(自动执行破 Lowe 豁免) | 统计软件 |
| 中国内地 | 证券投资咨询牌照 + 2026 AI 荐股严打 | 不涉荐股 |
| 舰队红线 | `/ai-trading-ledger` 明令永不为之 | 不冲突 |

**分界线是「有没有对某个金融工具给出建议」。** 本工具读的是**用户自己已有的一列数字**,
返回的是**关于这列数字的统计量**,不命名任何标的、不预测、不建议。这条边界写进了代码注释、
README、页面 FAQ 与 `.md` 镜像四处,**后续会话不得放松**:不出信号、不出「买」结论、不接券商。

## 四、已建的东西

### `tools/strategy-audit/audit.py` —— 单文件、零依赖、35 条自检

输入一列净值或收益率,输出五组数:
1. **概率化夏普(PSR)**:给定样本长度、偏度、峰度,真实夏普大于基准的概率。
2. **通缩夏普(DSR)**:先减掉「试了 N 次本来就会出现的那个高度」,再问还剩什么。
   N 次无边际试验的最好结果不是 0,而是约 `√Var[SR]·[(1−γ)Φ⁻¹(1−1/N)+γΦ⁻¹(1−1/(Ne))]`。
3. **最短可判业绩长度(MinTRL)**:这条夏普要多长的记录才能与运气分开。
4. **目标可行性**:目标年化所需的夏普,以及 `exp(S²/2)−1` 这个**任何杠杆都过不去的天花板**。
5. **成本折损**:按换手率付点差之后,夏普剩多少。

**演示用例就是标普自己**:14 个月的 SPY 年化夏普 1,63(高到 4 倍杠杆就能复利 100%/年),
但**如果你是试了 200 次才找到它,它的通缩夏普是 0,16**。指数当然没有过拟合——
这正是重点:**「看起来像边际」和「是边际」之间隔着通缩夏普问的那个问题,而几乎没有回测报告问它。**

### `/backtest-audit` —— 免费网页,数据不出本机

粘贴数字即出报告。**没有上传、没有存储、没有把你的数字带走的埋点。** 这既是隐私承诺,
也是产品定位:陌生人敢用,才有需求可量。

### 跨实现对等测试 —— 两份实现,一套数字

网页版与 Python 版是两份实现,不对账就是负债:页面悄悄算错,打出来的数字照样看着权威。
`test_parity.mjs` **从已发布页面里抽出那段 JS**(测的就是发出去的那个),与 Python 在
7 个确定性用例上比对 **129 个字段**,容差 2e-6(由浏览器端 A&S 误差函数的精度决定),
挂在 agiscorecard 部署路径上。

**它当场抓到一个真缺陷**:把净值粘进「收益率」框时,夏普算到上千,Python 端 `math.exp` 溢出崩溃、
JS 端会打出 Infinity。现在两侧都在夏普 >10 时**判定为单位错误并停止出数**,并各有断言守着。

## 五、售卖路径:不新建任何基建

**免费工具不是产品,是需求入口。** 付费的是 `/audits` 上**已经存在**的定价审计
(USDT 或发票,`revenue-experiments.md` E6 预登记 $500–2000),新增一类:**业绩主张审计**——
把同一套方法做成一份可被第三方复核的书面结论,外加表单做不到的部分:从成交记录重建真实换手率、
核对标的池的幸存者偏差、把结论写成别人能复算的形式。

**为什么不新建订阅/结账/Apify Actor**:①owner 不做销售,任何需要推销的渠道前置不成立;
②舰队铁律「产品不存在之前不挂价」;③`/audits` 的收款面已经在,**边际基建成本为零**。

**本轮发现:`/audits` 的「0 询单」根本不是需求读数,是仪器缺失。** 两条都实查过:
① `audit_click` **从来不在采集器的事件白名单里**——与 2026-08 那次 `affiliate_click` 一模一样的陷阱,
页面就算发了也会在收集端被丢掉;② 更要命的是 **`/audits` 整页没有任何联系动作可点**
(全页只有 3 个 `subscribe_click` 和一个指向 `/advertise` 的脚注链接)。
**所以那个 0 证明的是「没有东西可点」,不是「没有人想买」。**
2026-08-29 的对抗审议已经判死「audits 表单重构」,**那条杀单继续有效,本轮不碰那一页**;
本轮只做两件不越界的事:把 `audit_click` 加进白名单,并让新的 `/backtest-audit` 带一个真的 CTA,
**让这条判定线第一次有分母**。

本工具的赌注是:「检验我的回测」是一个**陌生人会主动搜索**的东西,而「AI 可见度审计」不是。
**这个赌注可能输,所以它有判定线。**
