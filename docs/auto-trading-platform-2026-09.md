# 个人自动交易平台:如何完善才能真拿到交易利润(2026-09-05,第三轮)

owner 原话(同日三条,按序):「自动化交易是个人用,类似孙宇晨的实验,目标是自己用来赚钱」
→「不是给别人用,所以为什么不能做,就是要做」→「先完善prompt再执行:调研清楚,如何完善这个
可以自动交易的股票平台,这样后续这个平台可以自动化交易,获取交易利润」。

**一句话结论**:证据支持一个人、cron 驱动、免费行情的自动化平台**可靠拿到的只有一样东西:慢速多资产
趋势规则的回撤减半**,收益相对买入持有 ≈ 0 到 −2%/年(震荡年更差)。「交易利润」意义上的超额
收益不在桌上(GEM 发表后 12 年实盘、McLean-Pontiff 58% 衰减、Cederburg 杀掉波动率择时都这么说)。
所以「完善平台」= ①把候选策略换成有样本外证据的那几条并加上 60/40 这根杆;②把执行做对
(收盘价成交、错峰、幂等、护栏);③把税算进判定。这三件本轮已做。

## 一、Prompt 三轮收敛(展示第 3 轮;前两轮改掉了什么)

**第 1 轮**照字面:「调研如何完善平台以获取交易利润」→ 会去找更好的策略、更多的指标、更高的频率。
**第 2 轮**对照证据自我质询,砍掉三样:①「找能赚钱的策略」——基率文献与 Alpha Arena 都说
alpha 不是 solo 能拿的,追它就是空转;②「提高频率/日内」——GitHub cron 抖动 15–60 分钟 +
IEX 免费行情 15 分钟延迟,日内在结构上不可行;③「多加指标」——参数越多,发表后衰减越大
(McLean-Pontiff),舰队零编造规则等价于「回测不是证据」。**第 3 轮**据此把问题改写为:

> 在「自己的钱、Alpaca、GitHub Actions 日频、免费行情、公开仓日志公开」约束下:
> (a)哪些规则有**发表后/样本外**记录可查,各自的真实期望(收益、回撤、衰减)是多少?
> (b)执行层要做对哪几件事才能让实盘成交与纸面台账同一根线、cron 抖动不伤钱?
> (c)哪些摩擦(费用、税、数据)会把薄边吃掉,判定线要怎么改?
> 能零 owner 动作建好的本轮建好;owner 侧只剩注册、密钥、变量。

**输入**:外部调研代理(~28 次检索;alpaca/github/telegram/SSRN 等主机被代理拦,以检索摘要为准,
单摘要标 [thin]);已建的台账引擎与执行器 v1;D1 投资簇数据(前文)。
**交付物**:本文 + 台账十一臂 + 执行器 v2 + 四 cron 工作流 + README + 判定线。

## 三、执行层要做对的事(Alpaca 事实)

- **market-on-close(`cls`)**:市价/限价可用;**15:50–19:00 ET 拒收**;19:00 后排到次日。
  **零股/名义金额单不能用 cls**(只能 day 市价)→ 整股 cls + 零股 day。
- **PDT 已废**:Alpaca 2026-06-04 起日内保证金框架,`pattern_day_trader` 等字段 2026-07-06 删除;
  执行器不读它们。日频再平衡本来就不构成日内往返。
- 费用:免佣;SEC $0.0000206×卖出额、TAF $0.000195/股(封顶 $9.79)、CAT $0.000003/股 ≈ 每千美元
  两美分。纸面账户无费用、成交为模拟。
- 数据:Basic 免费 = IEX 实时 + SIP 延迟 15 分钟、200 次/分;Algo Trader Plus $99/月。**日频收盘
  策略不需要 SIP**,cls 成交价与你的行情源无关。
- 组合历史端点 `GET /v2/account/portfolio/history` 有官方「可能不准」警告 → **自己的台账才是真值**。
- 资格:195+ 国家,加拿大除外;香港支持;德国有评测列为可用 [thin];中国内地无公开清单,需邮件确认。
  W-8BEN 开户自动生成,股息默认 30%、协定 10–15%,资本利得对非居民不预扣。
- **GitHub cron**:官方文档承认高峰延迟、极端时丢弃;实务 15–60 分钟;公开仓 60 天无活动自动停用。
  → 四条错峰 cron + 幂等(从 Alpaca 读当日订单)+「太晚就跳过并变红」。Cloudflare Workers cron
  更准时但无重试无告警,不适合放 Python + 密钥 + 台账。
- 从业者护栏:波动率作仓位、外生风险乘子、10–15% 回撤断路器、失效状态跨重启持久(KILLED 文件)、
  陈旧价不交易、异常下单率检测、订单额 ≤ 权益比例、2% 现金缓冲。
- 日志:GitHub 掩码只做精确字符串匹配,账户号/权益/仓位不是 secret 不会被掩;**只打印计数**是唯一
  真正的保护;金额只走 Telegram(1 条/秒/会话、4,096 字符上限,每次 1 条远在限额内)。

## 四、摩擦:税(改变判定的那一项)

- **德国**:26.375%(25% + Soli);股票 ETF 30% Teilfreistellung;2026 Basiszins 3.20% 的 Vorabpauschale;
  美国券商不代扣,自行申报 Anlage KAP;**月度再平衡每年实现收益**,相比买入持有的递延,择时规则税前
  要先有 1–2%/年的边才能税后打平。
- **中国**:境外资本利得与股息 20% 个税;2025 年上海/浙江等地追缴已扩展到中产;CRS 数据自 2018。
- **判定线因此改为「税后跑赢 60/40 与 QQQ 且回撤更小」**——不是税前。
