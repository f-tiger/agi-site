# Jarvis v21：返回时重新打开上次任务

日期：2026-10-12。基线为 `main` 提交 `581f09c72716b6772650af512adb4389ef32d3ce`、线上 `jarvis-20261012-20`。上一版部署 38188715591 成功。本轮只保存合成测试与非敏感工程结论；没有读取客户任务、记忆、密钥或私有报表。

## 三轮任务优化

1. 把“继续任务”缩成可观察缺口：v20 可恢复同标签页未提交目标，但提交后的任务在刷新或以后回来时不再自动打开，用户必须从列表重新寻找。本轮成功标准是同一设备能回到最后主动打开的、仍由服务器授权返回的任务。
2. 比较候选：确定性任务指针为 0 次模型调用、0 次 D1 写入；小模型、当前 8B 与更强模型都不能比精确 ID 更可靠地选择一个已知任务，反而会增加延迟、token、错误选择与隐私面。故模型仍只用于有来源的综合，不参与导航状态。
3. 冻结发布条件：精确记录结构、工作区与语言绑定、30 天上限、任务必须存在于本次授权返回、草稿优先、显式新建/删除/退出/切换清理；中英文浏览器旅程必须证明刷新后打开原任务，任务数与模型调用数不变。

## 新证据与反证

[W3C Web Storage](https://www.w3.org/TR/2021/SPSD-webstorage-20210128/) 将 `localStorage` 定义为跨窗口、跨当前会话的同源持久存储。这支持保存一个跨访问的最小导航指针，不支持把它视为可靠的服务器状态或安全记忆。

[OWASP HTML5 Security](https://cheatsheetseries.owasp.org/cheatsheets/HTML5_Security_Cheat_Sheet.html) 明确指出本地存储可被同源脚本读取和篡改，不应存放敏感数据或被用作认证。反证因此是：若保存目标、结果、记忆、凭证、授权或执行状态，XSS 与共享设备会扩大泄露和污染影响；如果仅凭指针打开未授权任务，则构成越权。

实现据此仅保存 `{version, scope, lang, id, at}`。它不含正文或凭证，且被当作不可信输入。只有私有 API 先验证当前能力密钥并返回同一 ID 的任务后，客户端才允许选中。指针本身从不发往分析服务，也不触发模型、工具、恢复或任务状态改变。

Cloudflare 2026-10-12 的官方模型目录仍列出当前 `@cf/meta/llama-3.1-8b-instruct-fast` 为可用快版。本轮没有模型质量问题需要额外推理，因此不消耗一次真实 AI 验收额度。

公开运行状态：v20 的发布作业 38188715591 已成功，任务仍由提交时 HTTP 执行与约两小时维护队列接续；本轮没有发现部署失败，也没有新增 Cron。当前工作环境没有获准可读的 Jarvis 聚合使用/反馈报表，因此真实任务启动、重复使用、帮助度与注册转化均保持未知；页面事件、夹具任务和部署检查不充当这些指标。

## 两轮对抗自检

1. 用户价值：自动打开可能让用户意外离开新建界面。处理是只有用户创建或点击过任务才保存；“新建”立即清除；未提交草稿优先；不自动运行、恢复、提交、勾选授权或改变任何任务状态。真实重复使用仍未知，不能把自动打开或页面事件称为留存。
2. 攻击与数据面：攻击者可伪造、跨工作区复制或保留过期指针。处理是精确字段、十六进制 ID/范围、语言与时间验证，30 天上限，并要求 ID 存在于当前鉴权后的任务列表。异常、缺失或跨范围记录清除；删除、退出和切换工作区也清除。任务正文、结果、记忆、密钥、授权和查询不进入该记录。

## 不变边界

一次访客任务后引导免费注册；不要求付费会员。全站 12 次/24 小时、每 IP 窗口 3 次、Jarvis 最多 2 次/任务不变。两小时维护任务、30 天服务端保留、暂停/删除、GA4 固定业务动作、首页倒计时/投票、独立电商周报导师、SEO/GEO 与现有 IndexNow 周更/手动机制均不变。不新增模型、Cron、付费服务、外部写入或每次 push 的 IndexNow 提交。
