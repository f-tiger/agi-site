## 怎样自动营销，而不变成自动垃圾内容

现有舰队已有每日核实、趋势输入、sitemap/IndexNow与自有页面自售入口。本次新增可执行营销计划生成器，挂到已有fleet-autopilot，每日读取已批准入口和BPJ实时收款状态，输出带UTM的活动清单、草稿、阻塞项和执行收据。不新增付费模型调用，不重复新增定时工作流。新候选没有发布URL就不生成“已上线”的推广文案。

| 环节 | 自动化规则 | 商业验收 |
|---|---|---|
| 发现 | 复用已有官方变化/趋势输入，标时间与失败；一条具体任务匹配一个入口 | 查询与目标买家相符；不按爬虫请求数选择赢家 |
| 站内转化 | BPJ工具/分类赞助位 → 真实触达 → 下单；已有有用工具保持公开 | 广告点击、草稿、结账、支付确认、有效投放分开 |
| 分发准备 | 按产品生成带utm_campaign/utm_content的链接与可审核草稿，去重/稳定活动ID | 实际发布与“生成草稿”分别记录；本次不声称已外发 |
| 内容发布 | 原创案例、可重现演示、嵌入工具；来源过期/收费未就绪阻断销售文案 | 实际使用任务/交付，不能只看文章数 |
| 提醒/会员 | 未来只发给有明确订阅同意的人；退订先于发送，唯一事件键去重 | 回访任务/续费来自真实账号账本，不拿匿名PV推留存 |
| 放大 | 同一买家、同一任务出现付款且贡献为正后复制页面或工具 | 退款、渠道成本、维护人工一起扣；未达标不买广告 |

本轮代码自动化完成的是站内广告交易与每日营销准备。没有接入社交发布账户或营销邮件投递服务，没有对他人发推广，也未开启广告预算；无人营销分发仍是待接入环节，不能把“计划生成器”说成已经带来流量。

## 会员不应只有一把全站付费墙

B2B厂商、普通AI使用者、家庭节能者、收藏者买的东西不同：分别设计产品权限，登录/支付底座后续可复用。公开搜索入口不加墙；付费增量放在保存历史、批量、定制提醒、团队协作和明确下载交付。

会员正式链路：账号验证 → 服务端创建subscription → invoice.paid授予相应产品/期间 → payment_failed进入可解释状态 → 取消入口与到期撤权 → 退款/争议处理。只相信签名回调和服务端账本；不能复用现有localStorage免费订阅门当安全付费权限。本次BPJ赞助为一次性订单，没有暗中自动续费，也没有把旧人工license签发说成自动会员。

## 验证门槛、成本与决策

每个P1候选第一轮最多1个任务工具＋3篇匹配任务的实证内容，复用现有域。实现工作量估计：已有纯计算/导出工具2–5工程日，带账号/提醒/付费储存5–15工程日；这是规划估计，不是已交付工期或固定报价。付费API、存储和客服另记；持续人工处理即按服务成本算，不能自称零边际成本SaaS。

门槛适用于所有24项，额外产品门槛见下方；计数剔除自测/机器人，100相关访问不是100个独立人：

1. 30天复盘或100次相关落地访问（先到者触发检查）。访问少先判分发未验证，不断言无需求。
2. 20次用户自己的任务完成，5条同细分用户的独立重复任务证据；匿名点击不能代替5个受访者。
3. 至少3个独立买家拿到可验收交付，再观察真实付款与退款。没有这一步时不把收费价签算验证。
4. 软件会员至少跨两个计费周期观察续费；一次性包看再次购买/推荐及支持成本，不硬算MRR。
5. 有流量但没有任务完成：修输入/定位一次再测；免费替代同样好且无支付理由：停止付费扩建。连续需要大量人工定制：转服务报价或停止。

| 首批实验 | 额外通过条件 | 否决条件 |
|---|---|---|
| BPJ LaunchDesk | 实际收款/投放/退款闭环通过；≥3真实购买，交付投诉与重复扣款为0 | 支付未配置先不开售；付费者零交付属立即修复，不等30天 |
| TradeCheck | 同类样本中准备+复核总时间比原流程减少，严重漏报为0（仅指验收样本） | 主要需求是未实现的OCR/ERP，或准备输入耗时更长 |
| LocaleBatch | 实际商户导入和术语/尺寸/数字QA通过 | 原生免费功能足够，或翻译人工返工吞掉贡献 |
| BillLens/DisplayFit | 用户自己的数据完成决策，并有可归因购买/报告付费 | 只有泛流量、参数不可靠、联盟点击不产生可核验订单 |
| 收藏清单 | 非自测用户第二次更新已有清单，愿为保存/恢复付费 | 只看新闻，不愿维护藏品/官方提醒足够 |
| ClassroomPuzzles | 教师实际打印使用、答案正确、许可清楚 | 只有下载量，无实际教学使用/购买 |

单位经济只能用情景计算：若€9净收款的报告每单变动成本€2，则贡献€7，€110贡献需16单，€1,100需158单；固定开发/获客还没扣。如果€29/月产品扣除税/退款后的收入仍为€29，变动交付成本€6，月贡献€23，€1,100需48个有效客户。两式都是假设，不是预测。
