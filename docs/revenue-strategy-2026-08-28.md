## 一、AI 时代的诚实账本（先把幻想清掉）

**2026-08 真实给小站付钱的"AI 营收新方式"只有一个：AI 助手引荐 → 联盟点击。**
本舰队已在跑（eco €9.96/30d + chatgpt.com/perplexity/copilot 真实引荐 25 次）。
- 被爬付费/内容授权类（Cloudflare Pay Per Use、TollBit、ProRata、Microsoft PCM）:
  要么闭测、要么只对 Hearst/AP 级媒体开门;按本舰队量级(约 1–3 万 AI bot
  命中/月)估算实收 **$1–50/月,中位数接近个位数美元**。TollBit 自报约 80%
  接入站点收入为零。
- x402 复查(上次 2026-08-17 判死):日结算 ~$28–42k,**YTD -93%**,笔数是
  均价 $0.13 的机器互刷。**维持判死,下次复查 2026-11**(看 Cloudflare 代理
  钱包是否带来真需求)。
- OpenAI 广告分成:官方明确不分(2026-06)。Perplexity Publisher:邀请制。
  Brave 归因付费:方向是反的。全部不做。
- 行业转化数据全部指向已验证的方向:AI 引荐转化 = 传统搜索的 **1.5×(Criteo
  500 家零售实测,最保守)到 23×(Ahrefs)**;ChatGPT 购物 2026-03 放弃站内
  结算回到"跳转商家站"模式 = 内容站被引用后的联盟归因路径**完好**。
- **合规红线(唯一可能危及已验证现金流的动作)**:Amazon Associates 链接
  **永不**进 MCP server / API / 任何 AI 输出面(运营协议 GenAI 条款灰区)。
  人从 AI 助手点进网页再点链接 = 正常点击,无问题。

**两个零成本期权(挂号即可,不投入)**:①Cloudflare Pay Per Use 公开申请表
(三个域都报,owner 2 分钟);②TollBit 仅 bpj 候选(若①获批则不做)。
**保险丝(比判定线优先级更高)**:引用队列爬虫(GPTBot/OAI-SearchBot/
ClaudeBot/PerplexityBot/Google-Extended)**任何时候不设价不屏蔽**——它们是
分发渠道,不是矿。

## 二、突破方案:把 eco 建成三层联盟旗舰(一个已索引域名,不开新域)

容器判定(两路调研独立同结论):新域有 4–8 个月死区、仅 5.7% 页面能在一年内
进前十;HouseFresh(真实测评、同品类)被 Google 打掉 91% 是前车之鉴。本舰队
唯一的分发资产 = eco 已被 Bing/DDG 索引 + 已被 AI 助手引用的域名。
**分发假设按本站实测重排:AI 引用第一、Bing/DDG 第二、Google 最后**(eco 的
Google 引荐本来就是 0——别人的灾难对我们不是新损失)。

### 第 1 层(现有):Amazon 商品联盟 —— 深化
- ASIN 直链:管线已建,runner 被 Amazon 反爬墙挡(已记录),owner 3 分钟
  核验清单见会话报告。PA-API 解锁线已达(5 单 ≥ 3)。
- **GEO×联盟加倍(第一方证据驱动)**:AI 引荐 25 次全部落在问题解决页
  (tilt-and-turn 6 次、kippfenster 5 次——正是 20%+ CTR 的转化页)。
  按同一形态(判定型标题+首屏答案+表格+一手数据+联盟卡)扩 **3–5 个德语
  商业意图页**,选题从 rising 数据来,过既有三门。
  **判定线 2026-11-30**:AI 引荐会话或 Amazon 点击相对基线无可测增量 → 停扩。

### 第 2 层(新,单笔价值 10–100× Amazon):能源/供暖 lead-gen

  Verivox ~€20(Awin/financeads);Thermondo €10/lead;Aroundhome €5–35+分成;
  Enpal 標 €50/lead(UNVERIFIED,入网后核)。**一条 lead ≈ eco 一个月的
  Amazon 收入。**

  balkonkraftwerk 页正在收 Perplexity 引荐。**不新建能源页**(守 owner
  2026-08-26 降级令——lead CTA 挂在既有页上不是新增能源内容)。
- **阻塞项 = owner 一次性注册**:Check24 Partnerprogramm(直连)+ Awin

### 第 3 层(新垂直):Bodenpflege(吸尘器/洗地机)目录 —— 经空气质量桥接入
- 利基扫描判定 rank 1:四个候选里竞争最薄(无 coffeeness 级霸主)、唯一有
  2026 上升子类(Nass-Trockensauger,Tineco/Dreame 双头)、耗材复购层
  (滤芯/滚刷/电池/清洁液)天然适配 Amazon、且**是唯一能诚实桥接 eco 的**:
  HEPA/细尘/过敏原/Tierhaare 本来就是室内空气质量话题。
- **入口从桥接页进**(Staubsauger für Allergiker、Saugwischer auf Parkett
  等问题型),不做"beste X 2026"榜单——那正是 Google 2026 三月/五月核心更新
  ×4 惩罚、Amazon 2026-04 新协议过滤的形态,也是零编造规则本来就禁止的形态。
- **动工前置(三门)**:rising 种子(akku staubsauger 08-26 已种、saugwischer
  今日补种)出首轮全量数据(~09-02)且有 v≥200 的真实需求词 → 首页从快反
  规则走,1 页/天,KGR 过门。**没有需求数据不动工。**
- 判定线:入口页上线 28 天,AI 引用或站内浏览无信号 → 停在 3 页以内。
