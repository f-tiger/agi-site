# Web3 Workbench: usability and discovery improvements

Date: 19 September 2026. Scope: the ten Web3 tools and their hub. Agent Delivery Lab retains its separate deployment.

## Optimized execution brief

Improve the existing tools' first useful result, repeatable workflow and shareability; strengthen search and AI citation eligibility with actual examples, methods, sources and crawlable pages; establish relevant owner-controlled discovery links and reusable sharing assets. Verify calculation semantics, local privacy, host isolation, generated pages and deployed bytes before claiming completion. Do not invent traffic, rankings, citations, customers or independent endorsements.

## What changed

| Area | Implemented behavior | Evidence / boundary |
|---|---|---|
| First use | Three runnable scenarios per tool; one-click hero action; selected case links | 30 fictional scenarios computed by the actual engine, including missing evidence, exhausted budgets, stale data and unsupported assumptions |
| Own records | Guided forms, JSON import and CSV paste per record group | Strict headers, quoted fields, exact monetary strings, finite safe numbers and bounded lists; no input upload |
| Repeat use | Keep one result for same-tab comparison; JSON and Markdown reports; print / PDF | User-controlled local exports; tab reload clears inputs and comparison; reports may include record labels |
| Discovery | Searchable hub and workflow categories; related next-step links | Existing tools remain independent; no implied data transfer or integration |
| SEO | Task-specific titles, canonical HTML, Open Graph images, sitemap and navigation | 44 substantive HTML pages across 11 hosts; `/index.html` redirects to `/`; no thin keyword variants |
| Structured data | WebApplication, visible-content FAQ, breadcrumbs and WebPage metadata | No fabricated ratings or review counts; structured data does not guarantee rich results |
| GEO | Answer-first definitions, method/limits/source blocks, 30 worked examples, Markdown and machine-readable contracts | Same facts exposed to people and crawlers; structural schema is explicitly not the complete engine validator |
| Sharing assets | 11 static 1200×630 cards; ten tool cards with plain, Markdown and optional HTML links | HTML embeds use branded anchors and `rel=nofollow`; only public fictional scenarios appear in generated share URLs |
| Submission | Per-host public key verification and four-URL sitemap validation in existing weekly/manual IndexNow job | Submission only on scheduled/manual runs, never on push; accepted submission is not indexing |

## Official guidance used

- [Google: AI features and your website](https://developers.google.com/search/docs/appearance/ai-features): standard SEO eligibility applies; no special AI files or schema are required, and inclusion is not guaranteed. Search crawling and model-training controls have distinct roles.
- [Google: software application structured data](https://developers.google.com/search/docs/appearance/structured-data/software-app): structured descriptions must represent the actual product; no ratings are invented to meet rich-result requirements.
- [Google: spam policies](https://developers.google.com/search/docs/essentials/spam-policies): avoid scaled thin pages, manipulative links and keyword-rich distributed-widget links.
- [IndexNow protocol](https://www.indexnow.org/documentation): verify host ownership with the key file and interpret 200/202 as submission outcomes, not indexing guarantees.
