# ECO 德语区趋势与品类扩张决策

调研日：2026-11-12。范围：德国、奥地利、瑞士；供下一轮产品开发使用。本次交付是研究与开发顺序，不代表新商品已上线、关键词已有排名或新增收入。基线代码：`a4a24bb43418484e9047ed16c0b625b48338369a`。

## 决策

ECO 应围绕“家庭设备是否适合、使用成本和维护代价”扩张。首轮深化**智能温控**，新增**洗地机购买决策**；扫拖机器人作为紧随其后的有条件扩展。保留已有除湿、室内晾衣和空调购买路径。加湿器、空气净化器及德规耗材逐步补齐，不同时铺开所有品类和三个国家。

“市场增长最强”和“ECO 最容易切入”是两个排序：清洁设备有更强的实际销量证据；智能温控更能复用本站现有能力、赶上冬季需求。当前站内观察样本不足以证明“型号太少”就是低点击的主要原因，不能用增加页面数替代获客验证。

## 6. SEO、GEO 与主动获客如何跟上扩张

每个品类交付一个完整问题链：**使用条件 → 原创检查/计算 → 有来源的比较 → 合适的购买或不买结论**。静态 HTML 提供结论、条件和来源；Markdown/MCP 保留相同事实，继续遵守既有无商业链接 AI 镜像规则。型号表统一记录 `market / exact_model / generation / role / constraint / source / checked_at / unknowns`，既帮助人选择，也便于引用和审计。

一个意图保留一个主 URL；来源复核日期与文章实质更新时间分开。后续生产验收覆盖 canonical、站内可发现性、手机和无 JS 阅读、与可见内容一致的结构化数据、GA4 与真实购买出口。不凭 llms.txt、标记或文章长度承诺 AI 引用。Google 官方说明，AI 搜索功能无需专用额外标记 [S15]。

首批分发题材与落地页保持一致：

| 题材（德语工作标题） | 视频/图文内直接给出的价值 | 对应落地 |
| --- | --- | --- |
| `Passt dein Thermostat wirklich? Prüfe diese drei Dinge.` | 阀门、现有中枢、套装完整性；不许诺节省固定比例 | 现有温控指南升级后 |
| `Saugwischer: Rechne die Reinigung danach mit.` | 设备工作后的排污和维护也计时；展示原创用时表 | 洗地机购买页上线后 |
| `Hohe Türschwelle? Miss Form und Höhe.` | 单层/双层门槛、基站空间不是同一条件 | 后续机器人页面 |

沿用既有 owned YouTube/TikTok、小批量和去重规则；不新增投放预算、账号或群发推广。本轮没有新发帖或改变已安排的除湿内容。研究结论用于下一次选题，不将“安排了推广”写成获得了访问。

## 7. 怎样判断扩张是否值得继续

区分五层证据：搜索曝光/排名 → 真实来源访问 → 有用检查完成 → 商家点击 → 有效订单及结算佣金。缺 GSC/GA4 权限时保留未知；第一方事件比值不是用户购买转化。后台订单读取仍暂停，不把数十欧历史佣金当作本批增长结果。

- **有曝光、无到访**：检查意图、搜索展示与竞争；需要实际查询/页面数据，不能凭印象改标题。
- **有到访、无有效检查/选择**：检查页面首屏是否兑现承诺、条件是否过多；必要时减少型号而非继续添加。
- **有选择、无商家点击**：检查准确型号、市场、价差/套餐解释和出口；保留无需购买结论。
- **有商家点击、无可核实订单**：检查配送、商品匹配与归因数据；不能直接认定市场无需求。
- 上线后第 14、28 天复盘；如样本仍小，只做质量与分发诊断，不能宣布胜负。不用任意点击阈值假装统计显著性。

收入规划采用可替换假设：`目标月佣金 ÷ 每个有效订单平均净佣金 = 所需有效订单数`。若目标为 €1,000、每单 €5/€10/€20，则分别需要 200/100/50 单；这是敏感性计算，**不是 Amazon 费率或 ECO 预测**。没有每类真实佣金、退货和获客数据前，不以高客单价或大类目推导必达目标。
