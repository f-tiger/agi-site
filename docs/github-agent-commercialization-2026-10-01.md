# GitHub AI Agent 商业化：借鉴收入机制，补出可交付产品

研究与实施日期：2026-10-01。对象：Edison 的 agi-site / BPJ。

## 决策

本轮优先推进现有 **BPJ ReleaseCheck 收费应用发布验收**：免费开源执行工具包作为
演示与获客入口，拟议 $299 单应用服务销售规则确认、适配、执行证据和一次复测。
不新开域名，不另造通用 Agent 平台，不增加第二个相同申请表。

这是当前资产条件下的验证选择，不是已证实的成功生意。BPJ 仓库的
`sites/baipiaoji/data/release-pilot-report.json` 在 2026-10-01T06:37:30Z 仅记录
2 个页面会话事件、1 个价格曝光、0 份申请，QA 已剔除；不是两位独立访客。
订单与收入字段为 null，不能读成已核实零收入或已能收款。现有曝光不足，首要商业
风险仍是分发与付费意愿，不能靠继续堆功能解决。

## 三轮优化与两轮对抗

1. 优化目标：找明确买家、重复任务、购买单位和交付物，而不是按 stars 排行。
2. 加强证据：逐项区分官网价格、公司自述、独立财务证明、我们自己的推断；检查
   开源许可、原版替代和真实运行成本。已有资产只影响实施成本，不替代需求证据。
3. 落实验收：六类项目比较、候选路线取舍、可运行原型、负例测试、同站点双语入口、
   有上限的试点服务和停止条件。沿用仓库既有上线授权。

对抗一（商业）：原版免费＋既有编码助手是强替代；工具包本身很难卖 $299。
因此免费开源执行器，卖客户特定的规则梳理、适配和证据交付。即使如此，客户是否
愿付仍未知。通用浏览器 Agent 云、工作流平台、客服知识库和 RFQ 工具都保留比较，
没有因已有源码就假定发布验收胜出。

对抗二（交付）：模型说“通过”、HTTP 200、虚构报告都不能证明正确。
实现状态码＋字段断言、缺失覆盖不完整、网络错误阻断、固定版本、回调重放与副作用
计数、显式测试授权、凭据环境变量、报告不含响应正文。用故意保留到期权限的
合成应用验证检查确实会失败。此为本次自检，不是独立第三方审计。

## 六个 GitHub 案例

所有价格均为检索时官网展示，币种和计费期不能互换。没有拿融资或用户数代替收入。

| 案例 | 可核实证据及等级 | 商业机制 | 可借鉴部分与约束 |
|---|---|---|---|
| [n8n](https://github.com/n8n-io/n8n) | 官方 2025-10-09 自述当年收入增长 10 倍；不是审计收入。当前 Starter €20/月、Pro €50/月，均按年付 | 免费自托管入口，云执行量、协作和企业功能收费 | 借鉴明确工作流、人工介入、模板分发。不要重造连接器平台。代码为 Sustainable Use License，企业文件另有许可，不能按 MIT 换皮销售 |
| [Firecrawl](https://github.com/firecrawl/firecrawl) | 官方 2026-09-22 自述超过 150 万用户；官方 2025-08 公布 Shopify、Zapier、Replit 等使用。用户不等于付费客户。Hobby $19/月或年付折合 $16/月；本轮未核实审计营收 | 免费额度／开源让开发者开始，按托管 API 用量收费，企业购买可靠性与控制 | 借鉴单一明确任务、可复制运行示例、API/CLI/助手入口。AGPL-3.0；托管与自托管能力需分开评估 |
| [Browser Use](https://github.com/browser-use/browser-use) | 官网公开收费：浏览器 $0.02/小时，代理与流量另计；Agent 模型成本另加 20% 服务费，再加浏览器／流量。未核实收入、付费客户或利润 | 开源库免费，售浏览器基础设施与执行服务 | MIT 允许按条款复用，仍应保留通知。但基础价格很低，简单套壳溢价难；应卖完成后的业务结果 |
| [Skyvern](https://github.com/Skyvern-AI/skyvern) | 官方 Hobby $29/月、Pro $149/月，有公开托管产品；“users & customers”是混合口径，不能当付费客户数 | 浏览器工作流执行，团队能力、凭据及企业支持分层 | 借鉴可查看每次执行、重试与人工处理路径。AGPL-3.0；本轮未证明自行维护一套浏览器云能盈利 |
| [Dify](https://github.com/langgenius/dify) | 官网 Professional $590/工作区/年、Team $1,590/工作区/年；证明公开商业产品存在，非收入证明 | 开源入门，云工作区与企业部署／服务收费 | 借鉴工作流版本与反馈。其修改版 Apache 2.0 对多租户服务、前端标识另有约束；不能一键改名当无限制 SaaS |
| [OpenHands](https://github.com/OpenHands/OpenHands) | 官网本地与 Individual 为免费，模型 BYOK 或按成本，Enterprise 定制收费；本轮未核实收入 | 开源编码 Agent＋企业组织管理、部署与支持 | 借鉴在真实仓库完成任务、保留变更与测试证据。核心 MIT，复用时仍检查具体组件；免费 Individual 是我们必须面对的替代 |

成功证据强弱不同：n8n 有第一方增长自述；Firecrawl 有第一方采用与客户资料；其余
主要证明收费产品已经存在。本轮没有六家经审计的营收／利润证明，不把它们统称为
“六个已验证赚钱项目”。stars 在本决策中只代表开发者关注度，不计算购买力。

## 路线比较

| 路线 | 买家与结果 | 获客／留存假设 | 成本与反证 | 本轮取舍 |
|---|---|---|---|---|
| 通用 Agent 编排平台 | 技术团队搭建各种流程 | 开源社区、模板；集成持续使用 | n8n / Dify 成熟，连接器支持繁重，缺差异 | 不复制整个平台 |
| 网页监控／采集 Agent | 电商或 SaaS 团队拿变化与证据 | 搜索、垂直模板；持续监控有留存 | Firecrawl 等已直接供应；采集权限、反爬、代理费；BPJ 已有 Watch | 候补，先读现有询价，不再新建同类 |
| 企业知识／客服 Agent | 支持负责人买解决问题和权限治理 | 企业销售或实施伙伴；数据接入形成留存 | 需要文档、权限、评测和支持；当前缺企业渠道 | 暂不启动 |
| 外贸 RFQ／单据 Agent | 采购负责人买报价或异常处理 | 行业渠道、授权样本；重复订单 | TradeCheck 已有，关键缺口是输入整理／OCR和真实买家，不是再加计算器 | 保留，等同群体样本 |
| 付费应用验收 Agent 工作流 | 维护收费应用的小工作室，买一次可复核交付 | BPJ 编程类、源码演示、问题型内容；后续版本可能复购 | Playwright＋原有编码助手可替代，信任与人工工时可能吃掉利润 | 本轮一个有边界的执行工具包，接现有试点 |

为何暂选最后一项：BPJ 已有编程相关入口、双语 $299 试点、私有申请队列和度量；
可用自家代码演练，无需先拿客户账号或购买外部基础设施。09-25 报告记载的 coding
61/395 是过去的带来源页面事件结构，只能作为历史渠道提示，不是今天的买家数。
当前选择置信度中低。免费工具下载不能证明安装、使用、满意、付款或续费。新增 kit_download 会话事件只记录点击，不当作运行或商业结果。

## 已实现的产品层

路径 `sites/baipiaoji/products/release-check/`：原创 MIT 本地 Node.js 22+ 执行器、
配置示例、中英文说明、给现有编程助手的任务简报。不是在当前 ChatGPT 安装新技能。
本轮未复制第三方项目代码，没有新增模型 API、密钥、付费基础设施或外联消息。

八个合成 HTTP 场景：未登录、未付费、已付费、已到期、跨租户、无签名回调、
签名事件、重复事件（相同事件只产生一次效果）。工具包生成 JSON/Markdown 报告，
保留版本、时间、断言、配置／响应哈希、失败及缺失项。下载文件在构建时从明确清单
复制，附 SHA256SUMS，不会把私有配置或运行报告发布到站点。

AI 负责的部分是客户已有助手在授权仓库中阅读代码、帮助适配和解释；执行器不调用
模型，不声称是独立托管智能体。用户自己的模型费用与数据条款仍适用。
真实 Stripe 事件、账期推进、浏览器结账、退款、套餐迁移及真实客户系统未在本轮
验证。它补出交付基础，不能把合成演练包装成完整收费 SaaS 已上线。

双语既有入口 `/studio/release-check` 与 `/en/studio/release-check` 增加可复现演示、
源码／说明／配置下载；保留既有申请范围和截止日期，没有新收费 SKU。

## 收入与成本假设

试点仍为 $299 单次。先售确认范围内的一次交付；客户自然重复购买后，再考虑
按版本或月度套餐。不能从一次性服务款制造 MRR，也不预售无人值守监控。

以下只是经营算式：每单其他直接费用假设 $15，人工内部估值 $35/小时；固定开发、
获客、税务和未列费用另计，真实费用尚未测量。

| 每单人工 | 假设直接成本 | 假设贡献 | 含义 |
|---|---:|---:|---|
| 2 小时 | $85 | $214 | 需高度复用的适配与报告，未实证 |
| 4 小时 | $155 | $144 | 可以作为首批交付时间上限假设 |
| 8 小时 | $295 | $4 | 基本失去商业吸引力，必须缩范围或调整价格 |

先记录规则确认、环境准备、执行、分析、报告、复测与售后全部工时；不能只计 CLI
运行时间。2 单 × $299 = $598 毛销售额仅为算式，不是收入预测，更不是已获订单。

## 商业推进与明确停止条件

1. 已实施：把可运行的失败／修复演示接回原有编码类与自研工具入口。源码附原站
   链接，说明一项具体付费任务，而不是引导去泛工具目录。
2. 下一验证单位：一个经过确认的真实任务。核对买家有预算权、近期版本、隔离环境、
   月内重复需求、现有测试缺口。申请仅是未经核实的自述，须人工核对。
3. 接单前：在客户授权的合成环境演练完整约定范围，包括浏览器与支付测试模式，
   确认工时、交付负责人、排期、条款与退款，之后才单独开放付款。
4. 沿用原试点 2026-10-10 截止与阈值，不因增加工具包重置窗口。少于 50 个价格
   曝光会话且没有匹配任务＝分发不足；达到 50 仍无匹配任务＝先调整受众或报价，
   不继续无依据扩功能。没有足够曝光不能宣布“市场没需求”。
5. 后续扩张门：两个独立实际付款买家、自然重复需求、测得重复交付贡献率至少 30%；
   若客户用已有测试同样轻松、准备输入比原流程更费时、频繁超过 4 小时或只有
   一次性修复需求，则缩小服务或暂停，不自动转成订阅平台。

外部分发材料可围绕“付款成功但权限未开”“取消后仍可访问”“重复回调重复发权益”
三种真实问题，演示先坏后好。没有在本轮代发社区帖子、邮件或视频。也没有新增定时
任务；现有日常试点聚合报表沿用。报告、演示和下载本身不是外部新增流量。

  预检、跨源／重放约束、重定向／非 JSON／超限／网络错误、报告防覆盖、CLI 退出码。

- 最终构建的 2,353 个 HTML 页面经过断链、结构化数据、语言残留等门禁，均为零错误；
  canonical 门禁通过。与并发上线的报价工作室提交整合，保留其改动。
- 中英文 390px 手机与 1440px 桌面浏览器检查通过；已目视检查截图。运行器／清单下载、
  申请失败重试、SQLite 保存、回执恢复、撤回及 QA 事件隔离通过。
- 页面只增加可复现的合成演示；未发生客户测试、模型 API 调用、真实支付或外部营销发送。
- 部署结果以对应 GitHub Actions 运行与线上下载校验为准；本地全绿本身不是线上回执。
