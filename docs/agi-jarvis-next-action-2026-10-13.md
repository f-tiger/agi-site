# Jarvis v22：建议核阅的继续位置

日期：2026-10-13
版本：`jarvis-20261013-22`

## 本轮选择

本轮不增加 agent、上下文或模型调用，而是在已经返回的下一步与用户自报进展上，用确定性规则给出一个可选的“建议核阅位置”。顺序固定为：受阻步骤优先，其次最近尝试但未完成的步骤，最后是第一条未标记步骤；已完成步骤跳过。提示只返回行动序号与固定状态，不复制目标、行动正文、记忆、密钥或来源。

提示不会自动滚动、自动改状态、创建任务、写入记忆、恢复执行或调用模型。用户点击“查看这一步”后才把焦点移动到现有行动卡片。界面明确说明它只依据自报状态，建议可能不正确，行动前应核对全部步骤。

## 三轮任务优化

1. 先缩小问题：v21 已能恢复上次查看的任务，但用户仍需重新阅读整份报告寻找继续位置。本轮只处理“回到任务后的定位成本”，不扩大执行权限。
2. 再比较候选：确定性规则为 0 token、0 新 D1 字段、0 新授权；小模型、现有 8B 和更强模型都会增加延迟、配额与错选空间，而已知枚举排序没有需要语义推理的证据。
3. 最后冻结验收：最终状态选择、显式点击后聚焦、完成后隐藏、受阻后重现、隐私字段不进入提示、任务数与模型调用不增加。引用、纠错与任务恢复现有行为不得回退。

## 一手证据与反证

Altmann 与 Trafton 的受控实验报告，中断后的首次行动平均需要 3.8 秒，而通常行动间隔为 1.9 秒；可用外部线索在较长的中断准备窗口中降低了恢复延迟。[原始论文](https://www.interruptions.net/literature/Altmann-CogSci04.pdf)

Microsoft Research 的 CHI 2010 研究用 371 名开发者的调查和受控实验比较编程任务恢复线索，自动生成的线索比笔记条件更能支持恢复。[研究页面](https://www.microsoft.com/en-us/research/publication/evaluating-cues-for-resuming-interrupted-programming-tasks/)

这些证据不直接证明 Jarvis 的规则会提高现实任务完成率。前一研究只有 96 名本科生，线索效应只在 8 秒条件达到可靠；后一研究局限于编程任务。本站的进展还是用户自报，可能过时或错误。因而本轮只发布可撤销的核阅入口，不把它当自动决策或成功证明。

Cloudflare 2026-05-08 的官方弃用公告仍保留当前 `@cf/meta/llama-3.1-8b-instruct-fast`；模型可用性不是本轮切换模型的理由。[官方公告](https://developers.cloudflare.com/changelog/post/2026-05-08-planned-model-deprecations/)

|---|---:|---|---|
| 固定状态排序 | 0 次模型调用 | 完整；规则和输入枚举可检查 | 选择发布 |
| 更小模型 | 占用共享额度 | 可能改写或错选 | 无冻结集优势证据 |

## 可证伪实验

冻结 12 个纯函数案例：空进展、跳过已完成、尝试优先、受阻优先、多个受阻取最近、多个尝试取最近、全部完成、未知状态、越界索引、畸形时间、缺失报告与空行动。接受条件是 12/12 得到预期的 `{index,state}` 或 `null`，输出中没有任务正文。

浏览器验收另要求中英文首次报告显示“第一条未标记步骤”，只有显式点击才聚焦行动卡片；标为完成后提示消失，改为受阻后提示重新出现；前后 D1 任务数与报告中的模型调用数保持不变。

## 两轮对抗自检

第一轮，错误建议：用户可能已在站外完成其他步骤，或原始 AI 行动本身错误。缓解方式是把提示标为“建议核阅”，解释仅依赖自报状态，不自动操作，也保留全部步骤供复核。

第二轮，隐私与状态污染：恶意/畸形状态、越界索引、旧运行或行动正文可能污染提示。实现只读取当前可见报告的行动数量和服务端返回的固定枚举，忽略未知/越界状态，跳过完成项，只返回索引与状态；没有新存储、分析参数或跨任务合并。

## 能证明与不能证明的内容

工程测试能证明排序、显示、聚焦和零额外模型调用边界；不能证明真实客户更快恢复、留存更高或任务完成率提升。当前有权限的数据没有 Jarvis 聚合使用/反馈端点，真实使用、重复使用、引用准确率与收入保持未知。后台最近一次公开维护运行成功且处理 0 个到期任务，只说明该次队列为空和运行器可达，不能推断用户数。

现有一次访客任务、随后免费注册、12/24 小时全站窗口、每 IP 3 次、每任务至多 2 次模型调用、约两小时维护、暂停/删除/到期清理、GA4 同意和固定事件、周更/手动 IndexNow 均不变。
