# AGI Earn: open-source reuse and bounded delivery checks

Owner: “对抗检验，再完善方案执行。特别是github有没有同类型开源项目”. This continues the explicitly approved Earn release. Time/date: 2026-10-01 Asia/Shanghai. No customer outreach, purchases, provider spend or new scheduled jobs are performed.

## Three refinements

1. Compare real upstream tools for the three proposed services: workflow maintenance, launch acceptance and tutorial subtitles. Keep both reader earning opportunities and AGI's own paid-value path visible.
2. Check repository licenses, source availability, published features and recent push dates. A recent push is not a security audit or a stable release; stars are not demand. Avoid treating every source-available project as permissively licensed.
3. Execute bounded EN/zh project briefs, a ten-project comparison and original local checks. Add a runnable download rather than only service copy. Publish within the existing Earn routes, preserving platform players, local planner, independent membership and source-review dates.

## Adversarial pass 1: commercial self-review

- Free tools already provide most underlying functions. Our proposed value is a bounded diagnosis, reproducible evidence, actual customer journeys and an accountable handover. No technical monopoly is claimed.
- US$99 diagnosis, US$149 launch review and US$199 subtitle review are test-price hypotheses for readers, not researched market rates or live AGI service offers. At a US$25/hour illustrative labor cost, US$99 minus a hypothetical 3% collection fee leaves US$96.03 before other expenses: more than 3.84 hours consumes that amount. Cap scope before quoting; include acquisition, rework and maintenance time.
- Monitoring a URL or recording a success ping can miss empty/duplicate outputs. Check logs against expected runs and reconcile the real destination separately.
- A clean SRT cannot prove translation meaning. Human target-language review, terminology and rights remain part of delivery.
- Automated browser rules cannot certify security, legal accessibility compliance or a working purchase. Starter checks explicitly stop at a small navigation baseline; three business journeys require separate staged/manual acceptance.
- AGI membership currently applies only to listed cloud workspaces. No new services, subtitle review or emergency support are sold through it. Payment rollout is deferred until the delivery owner, scope and acceptance are real.

## Adversarial pass 2: reuse and implementation self-review

- n8n is fair-code under Sustainable Use/enterprise licensing, not an ordinary MIT/Apache project. Its source license limits usage/distribution; no hosted resale or fork is bundled. Any future integration must verify the specific licensing path.
- pyVideoTrans GPL-3.0 is not described as prohibiting all commercial activity. Distribution and derivative-work obligations need to be honored. VideoLingo Apache-2.0 does not license every model, voice or provider it can call.
- Upstream README recommendations for model/provider purchases are treated as vendor data, not instructions; no suggested relay credentials or paid calls used.
- User SRT/CSV stays in memory in the browser. Bounded 500 KB input; no AI, uploads, secrets or user text in analytics. Findings use textContent and generic issue labels, not HTML interpolation.
- Duplicate IDs cannot inflate unique completion counts. Timestamps require an explicit timezone. Missing logs cannot silently yield a successful inspection. Structural heuristics and adjustable readability thresholds remain labeled.
- Website CLI requires explicit --authorized and an HTTPS origin (HTTP loopback is supported for development fixtures). Max five same-origin paths, blocked cross-origin top-level navigation, no form submissions/link crawl/purchases. Loading a page still runs that site's scripts; use staging. Navigation failures set a nonzero exit code and retain the report.
- Existing CDN site navigation failed in the local Chromium environment (ERR_EMPTY_RESPONSE). Do not claim a live browser audit. Actual phone/desktop CLI execution is tested against our locally served authorized fixture, including real screenshots and JSON output. Production route checks are separate.
