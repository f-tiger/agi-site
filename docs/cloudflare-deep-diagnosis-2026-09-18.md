## 结论与决策

**可归因的搜索入口已经出现，接下来优先把这些入口变成任务完成。** 白嫖计有增长迹象，但规模仍小：当前滚动窗口 331 次带来源 JS 浏览，56 天窗口减去它得到此前区间 107 次。不能直接称为严格 28 天增长率：当前接口包含今天未完成的数据，两个区间长度不同。新代码补上完整 UTC 周/月对比。

**发现并修复了生产 URL 的明确冲突。** Pages 把 `.html` 地址 308 到无后缀地址，落地页 canonical 却指回 `.html`；内链、hreflang、sitemap 同样发布文件地址。不是推测：下面三组生产请求全部复现。此次统一为已经返回 200 的无后缀地址，保留现有文件与旧链接的 Pages 跳转，不迁域、不删除页面。它能消除站内多余跳转和规范信号冲突；是否提升收录/排名仍需上线后的搜索数据验证。

**大量边缘活动属于 API/MCP/扫描，不能算真人增长。** 昨日采样排名里，AGI 的 `/mcp`、Eco 的三个 MCP 路径、白嫖计的 `/api/mcp` 占据前列。不能把“请求越来越多”当产品留存，也不能把所有 404 当坏内链。先修有来源和生产响应证据的问题，不全站封爬虫或改 WAF。

同窗 `go=90`、`calc=6`、`sub_ok=4`；这几个事件的采集面和分母不同，**不计算 6/331 的用户转化率**。加之旧工具组装器初始化也会计 calc、五类事件曾被后端丢弃，历史工具使用只能作为很弱的信号。修好后从实际部署日建立新基线。

本轮补充落地：

1. 全站生成的自有绝对 URL 去除 `.html`：canonical、语言互链、导航、结构化数据、站点地图、数据/引用资产一致；第三方来源链接不改。内容文件仍按 Pages 规则保留，旧 URL 继续可达。
2. 编程/API 分类页首屏把“免费方案 / 额度计算或订阅核对”放在长目录前，匿名直达可保存的结果。曝光与导航分别计数。
3. 组装器新增独立 `stack-use` 聚合路径，真实操作才触发；之前 `soft-use` 是每页首次操作，不能冒充组装操作次数。导出链接也使用无跳转 URL。
4. `reach` 增加固定完整 UTC 的当前 7/28 天及各自前窗，独立列来源浏览、计算、出站、订阅成功事件。导出脚本保留新字段；旧字段兼容，不把历史缺失补成零需求。
5. 本地检查和浏览器用例模拟 Pages 的 308 行为，而非只读取 `.html` 文件。验证任务入口无跳转、方案还原、匿名导出、事件、隐私边界和中英移动端布局。
