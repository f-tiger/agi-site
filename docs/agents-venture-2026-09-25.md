# AI agents 创业机会点：找楔子，做出"哈佛阶段"（2026-09-25）

> owner 原话：「先优化3轮prompt再执行：你是一个创业者，你需要挖掘一切可能性在ai大时代，找到创业的agents机会点，
> 通过类似扎克伯格的成长路径，成为ai时代的巅峰企业。手上目前已有的bpj站点都可以成为你的武器，如果不够你可以自主扩张，直到达成最终目标」

## 〇、三轮 prompt

1. **把愿望变成问题**。"成为巅峰企业"没有终点也没法验收；能验收的是：AI agents 这条赛道里，哪个机会点是本舰队今天就有不公平优势的，它的"哈佛阶段"长什么样。
2. **加舰队约束**。先读已有裁定、不重复论证：09-12「AI 时代的站点」（抄机制不抄形态）、09-13 应用工厂循环、09-16 工具付费五触发器、09-22 分享即分裂、09-07 预测市场，以及整张杀单。三门、零编造、不开新子域、外部副作用只挂 schedule。扎克伯格路径只抄机制：边界清楚的小网络先做到饱和 → 每个成员一份会被认领的档案 → 再开平台 → 最后变现。
3. **可执行**：带日期信源的机会扫描 → 按三门选唯一楔子 → 在 bpj 内建出第一步（零 AI、搭已有 schedule、只读礼貌抓取）→ 预登记判定线 → 文档、手册、台账 → 过门禁后随下一次部署上线。明确不做：新子域、新收款面、双边市场、代币、没有读数的"规模化"。

## 一、结论（三句）

1. **第一个楔子被数据否掉了，而且是在动手之后。** 我先选了"MCP 服务器信任层"（每日只读普查官方注册表的远程端点：能不能连、暴露什么、何时变了），管线、页面、判定线都写好了——然后外部扫描发现 **mcpcensus.com 从 2026-09-04 起就在做几乎一模一样的事，连名字都叫 MCP Census**，另有三家同月入场，且**没有一家有付费用户的证据**。按三门撤回，一行没上线。
2. **bpj 在 agents 赛道真正有密度的网络是"用编程智能体的开发者"。** 本站 28 天 395 个带来源真人里，"agent"类目只有 5 个，编程类有 61 个（第二大类目，/c/coding 是 Google 第二大落地页）。他们问的正是 bpj 的核心资产能回答的问题：这个编程智能体还免费吗、免费多少、这周变了没有。
3. **本轮做出的"哈佛阶段"第一步**：补上两个缺席的主力编程智能体（Kiro、OpenAI Codex，官方页当日直抓、中英两份、带付费档 → 判定页与升级页自动生成），按官方页当日原文重核漂移探针刚标红的 Cursor，给这个网络装上第一个需求仪器（Trends rising 种子），并修掉一个让任何一次额度编辑都把全站 1 700 页标成"今天变了"的发现面缺陷。判定线 `bpj-coding-harvard-1025`。

## 五、扎克伯格路径的 bpj 版本（只抄机制）

Facebook 的顺序：2004 年只在哈佛 → 同年扩到其他高校 → 2006 年向所有人开放 → 2007 年开放平台 → 之后才靠广告变现。能抄的是**先在一个边界清楚的网络里做到饱和，再一格一格往外扩；每一步都有门槛。**

| 阶段 | 对应 | 本站动作 | 进入下一阶段的门槛 |
|---|---|---|---|
| 0 哈佛 | 编程智能体开发者 | 每一个有免费档的编程智能体，都有一份当日核实的额度记录与变更史；读者最常问的那一页（/c/coding、判定页）永远是最新的 | `bpj-coding-harvard-1025`：coding 28 天 ≥92 且新页有读者 |
| 1 常春藤 | 同一网络做满 | 30 个条目 30 天内全重核（现在多数停在 08-03/04）；补齐仍缺的（opencode、Qwen Code 等，官方页写明免费档才收）；编程子集变更流 | 变更流有订阅或回访 |
| 2 开放平台 | agent 自己来查 | 现有 bpj MCP 加 `coding_agent_quotas`（哪个编程智能体此刻还免费、多少） | 非索引器、带参数的调用方出现（舰队 09-24 口径） |
| 3 变现 | 最后才收钱 | 编程智能体定价变更告警（watch Pro）；/c/coding 厂商赞助位 | 第 1–2 阶段读数 + owner 的收款决定（Stripe） |

**刻意不抄的**：通讯录导入式增长、"move fast and break things"用在安全上、用资本买对手。

1. **补录两个编程智能体**（`limits` 全部来自当日直抓的官方定价页，中英两份，`quota-facts-check` 333 组 0 问题）：
