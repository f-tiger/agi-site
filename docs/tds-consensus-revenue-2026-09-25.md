# TDS：从工具使用走向可验证协作与月收入

研究与执行日期：2026-09-25，亚洲/上海。项目：f-tiger/agi-site，thedollscout.com。

**本轮决策：把可验证的客户交付作为有限商业实验，保留现有文档工具作为入口。先验证重复任务和付费，再建设多人网络。当前证据不支持发行代币、自动估值或靠复制编号创造收入，也不足以宣布这个细分市场已通过验证。**

用户目标是“营收1万/月以上”，没有指定币种。本文先按人民币10,000/月规划，同时保留美元10,000/月情景。目标是销售收入，不是市值、平台成交额、代币价格、访问量或净利润。没有承诺达标日期。

## 优化后的任务

> 不预设原行业或PDF必须成立。审计TDS的真实使用、分发、计量、收款和旧商业实验。使用Google Trends真实时间序列、用户原始讨论、Product Hunt供给线索及竞品官方价格，对工具、共识协作、金融辅助和投机型路线做反证比较。区分兴趣、使用、意向、订单、净收入与续费。选择一个可控制成本的首个实验，明确付费买家、现有替代、可触达渠道、商业上限的条件及停止规则，再完成必要产品和获客入口。借鉴比特币的公开规则和独立验证机制，不把金融包装当作价值证明。

## TDS这次究竟做什么

当前入口是小型数字服务团队的交付记录：保留实际文件、约定范围、原始沟通来源与客户真实回复，再导出一份可以带走的记录。选择此实验，是因为它接近既有文档能力，成本可控，也能直接检验跨人协作是否发生；不是因为已证明它优于所有路线。

本次工具完成：本地SHA-256、10文件清单、范围/交付/回复备注、JSON和HTML下载、文件一致性比较、公开格式、英德中页面、首页与PDF工具内链。免费。用户不用上传文件或登录。对方可以独立复核文件字节，记录和说明本身仍未认证。

真正可收费的增量假设是：团队角色、共享审查历史、可核对的收件与更改流程、品牌化交付及重复项目管理。这些功能尚未交付，页面明说79美元/月方案只在调研，不能购买。不把匿名预算投票当成客户、不假装已经有订单。

“像比特币”的演化顺序：公开格式和可重复验证 → 用户自愿带给真实收件人 → 双方授权记录具体动作 → 保留更正与版本历史 → 有足够真实案例后形成信誉网络。可选Bitcoin时间锚定应在买家确有此需求时再加；目前完全未接入。不会根据分享次数生成金融价值或承诺回报。

它首先是协作传播回路，还不能称为网络效应。需测每次真实交付是否带来独立收件人使用、是否再次发起自己的交付。现有无用户标识计量无法证明这些，后续需要经同意的账户/访谈证据。

## 月收入1万的条件模型

以下价格、转化、成本和汇率都只是规划参数。汇率固定按1美元=7元演算，不是当前报价；销售收入未扣退款、税费、获客、人工和支付成本。

| 模式 | 达到人民币1万/月 | 达到美元1万/月 | 关键区别 |
|---|---:|---:|---|
| 一次性流程设置149美元 | 每月10单＝10430元 | 每月68单＝10132美元 | 必须每月继续卖出新单，不是MRR；服务尚未开放 |
| 团队79美元/月 | 19家＝10507元 | 127家＝10033美元 | 需要留存和续费；共享团队产品尚未建成 |
| 高级团队199美元/月 | 8家＝11144元 | 51家＝10149美元 | 需要更高价值与支持能力，不因定价高就更容易 |
| 纯广告，假设每千次页面收入10美元 | 约142858 PV/月 | 100万 PV/月 | 10美元仅是假设，不是TDS实测RPM或行业均值 |

优先验证149美元小范围交付服务是否有人真实购买，再决定能否产品化成79美元月订阅。允许反证：如果使用者只是临时整理一次文件，按次收费可能比订阅更合适；如果邮件和Drive足够，就不应卖团队方案。

单位经济压力测试：149美元服务若每单2小时、内部人工成本25美元/小时，另假设支付/退款损耗10%、工具成本5美元，单笔获客前贡献约79.10美元。若花6小时，则为负20.90美元，尚未计获客。79美元订阅若每客户每月支持30分钟、基础设施5美元、支付/退款损耗10%，获客前贡献约53.60美元；以3个月贡献为内部CAC上限约160.80美元。以上只是算术测试，未声称实际毛利或CAC。

增长算术也不能省略：每月新增5个付费账户、月流失5%的假设下，A(t)=0.95A(t-1)+5，从0起第4个月约18.55、第5个月约22.62个期望账户。达人民币目标需要持续获得新客户并续费；没有依据承诺5个月能做到。若假设有效目标访问→试用20%、试用→付费2.5%，获得5个新客户需约1000次目标访问/月。这个0.5%的总转化尚无实测。

天花板不能用整个PDF市场冒充。人工服务若每月只有80小时交付容量、每单2小时，上限约40单×149＝5960美元/月，未计获客支持；软件若能留住500家×79＝39500美元MRR。两者都是资源或客户数条件下的情景，**不是已确认TAM，也不是预测**。真正上限仍取决于可触达目标团队数、替代品优势、支持成本、获客成本和续费。

## 证伪与下一笔收入之前的门槛

1. 先解决测量和分发可见性：保留故障，不静默把失败计为零。取得GSC历史28天和前28天的查询/页面/国家/设备，以及新首页、批量检查和交付页的URL Inspection。区分未发现、已抓取未收录、已收录无曝光、有曝光无点击。
2. 收款状态单独复核。修复监测后也不能直接把旧会员当新付费产品；先定义可交付范围、价格、退款规则、支持渠道，再完成真实付款/退款/授权验证。当前没有足够信息替用户建立新商户主体或接受支付合同。
3. 找10家匹配团队，问过去30天实际交付次数、最近一次争议或返工、现用流程与既有支出；至少5家展示重复任务，3份获准样本。不能只问“喜不喜欢这个工具”。
4. 与邮件/Drive及现有工具比较完成同一交付的总耗时。至少3个无关联实际付费试点且贡献为正，才开发团队收费层。初始50次目标体验若没有重复任务或现有流程缺口，停止扩功能。
5. 到10-23复盘：若流量不足，结论是获客尚未验证；若有至少100次有效目标访问但导出少于20次，修任务/入口；若工具有用却没人按明示价格买，调整收费单位或淘汰付费假设。100/20/3都是本项目预设学习门槛，不是行业基准。订阅扩张需要续费证据。
