# Web3 行情：用户为什么还要打开本站

日期：2026-09-20。范围：Web3 Workbench 现有域名与页面。用户认为原行情太简单，要求从用户视角参考币安、OKX 的行情和讨论板块。延续上线授权，不新增站点或收费项目。

## 优化后的执行任务

从普通行情用户、AI/算力赛道研究者和工具使用者三种视角，对比现有强替代；识别首次使用与回访理由。实现一个可用的研究流程，覆盖真实价格/历史、观点证据和复盘，保留原工具与 MCP。以来源真实性、时效、实际交互、隐私和部署验收为完成标准；吸引力与付费意愿须通过真实使用继续验证。不给不存在的社区编用户、评论或热度，不把 AI 总结当价格原因，不发送外联或下交易单。

## 竞对现况与产品选择

以下是 2026-09-20 对官方公开页面的核对；页面功能不是独立留存或收入证据。

| 替代品 | 当日可观察能力 | 用户获得什么 | 对本站的约束 |
|---|---|---|---|
| [Binance Markets](https://www.binance.com/en/markets/overview) | 价格、涨跌、成交量、市值与交易入口 | 快速筛选并执行交易 | 四个币的价格表没有广度或执行优势 |
| [Binance Square](https://www.binance.com/en/square) | 创作者信息、热门话题、讨论热度和情绪入口 | 获取观点、参与讨论和寻找解释 | 我们没有相应内容供给与社交关系；不能用空论坛假装社区 |
| [OKX Markets](https://www.okx.com/markets/prices) | 自选、宏观数据、赛道分类、涨跌榜、走势图栏目 | 把观察对象与市场背景联系起来 | 基础图表、自选和 AI 标签属于已有功能 |
| [OKX Orbit](https://www.okx.com/orbit) | 官方导航定位为话题讨论到交易，附直播入口 | 观点交流与交易场景衔接 | 不假设已有用户会迁移到我们的独立讨论区 |
| [DefiLlama](https://defillama.com/) | 链/协议、费用收入、解锁、watchlist、比较、AI 与 MCP 入口 | 深入研究原始数据 | “数据＋AI”不是独特壁垒；我们的来源仍依赖第三方 |

原版不足：只有当下价格，没有变化的时间参照；官方消息与用户关心的问题分离；计算器服务工程/财务任务，不能直接替代投资研究；没有保留用户研究工作的理由，也没有真实讨论供给。现有工具的沉没投入不能证明目标用户选对了。

当前生产 `/api/growth`（2026-09-20T01:15:46Z）仍无非 QA 自愿事件。没有相关访谈、足够同类求助样本或已验证付费用户，不能宣称已发现市场空白。本站定位仍是低信心、可撤回的产品假设。

## 选择与范围

优先实验：关注 AI/算力赛道、愿意核对原始证据的轻度研究者。价值主张为“看清关注对象的变化，保存支持与反对的证据，下次核对自己的判断”。这是一种流程便利性假设，不声称交易所没有研究工具、笔记或提醒能力。

暂不投资三类扩张：全币种交易终端（数据广度/延迟竞争）；开放综合社区（供给、审核和冷启动）；自动行情归因/荐币机器人（来源与因果不充分，免费替代也强）。不是永久否定讨论：如果后续出现同类用户重复分享研究笔记，可测试由真实作者提交的、有原始来源与反证的议题。届时还需身份、内容规则和实际维护流程。

## 本轮实际实现

1. 在原 `/market.html` 上重做研究台，保持原 canonical。以真实数据表作为首屏主体，使用既有蓝白体系、清晰的正负变化文字与宽表，窄屏允许表格横向查看；笔记与快照区域独立排布，避免把功能塞成一排营销卡片。
2. 精选 BTC、ETH、USDC、USDT、TAO、RENDER、FET、AKT。AI/compute 分组是编辑筛选，非完整行业指数或推荐。项目定位核对自 [Bittensor](https://www.bittensor.com/)、[Render](https://rendernetwork.com/)、[Fetch.ai](https://www.fetch.ai/)、[Akash](https://akash.network/)，不采用厂商营销效果数字。
3. [DefiLlama 公共接口](https://api-docs.defillama.com/llms-free.txt)的价格与历史均完成实际取数验证。7 天图为日采样线，不伪装成 K 线；1d/7d 百分比采用目标时间前后两小时以内的采样点，JSON 保留精确起止时间。无成交量、市值、全市场排名或虚构走势。
4. 当前价格每五分钟按需刷新，历史每小时按需刷新。逐资产判断 15 分钟新鲜度；AKT 等源更新时间较慢时单独显示 stale，不掩盖也不把别的价格一起抹掉。历史失效时保留可用价格，比较值为 null。原 `/api/market` 四资产契约保持不变，新研究数据使用 `/api/research`。
5. 自选快照仅由用户主动保存，包含保存时间与提供方时间。回访不会自动覆盖旧快照；新鲜且更新的报价才显示相对变化。30 天有效、独立删除入口；没有推送提醒、后台盯盘或云同步。
6. 观点笔记要求填写主张、原始证据、反证、失效条件、复查日期。仅主动保存到浏览器，或导出 Markdown 供用户选择分享/交给 AI；不上传自由文本、不自动发布、不冒充 AI 分析结论。复查日期不代表已安排通知。
7. 官方消息在行情页可见，标注发布时间和“代码提交不等于发布”。它是协议背景，不关联为某币上涨/下跌的原因。逐资产 Review 提供原始项目链接和待核实问题。
8. 保留对账/成本工具，用具体问题连接。新增四个自愿类别事件：watch_save、watch_compare、review_save、review_export；不上传选择的资产、价格、观点或证据 URL。不将事件相除为漏斗，也不将 watch_compare 当独立留存用户。

## 获客、回访与商业假设

搜索入口先围绕已有页面回答具体问题，例如 token 热度和实际使用的差别、算力报价与有效输出成本的差别；没有搜索量证据时不量产币种页。机器可读 JSON 和带来源时间的文本让 AI 能引用方法，但不保证引用。研究笔记的自愿分享和已有发布工具箱可帮助分发；私人导出不是公开外链。

首次价值：无需登录，选择一个关注对象，识别变化并得到要核实的问题。回访价值：对比自己的旧观察，检查原先论点是否仍成立。现有报表/图表是实现手段，是否比用户现有自选＋笔记习惯更省事尚未证实。

免费层保持完整。未来只有在独立用户重复需求得到验证后，才考虑可交付的云端变更历史、团队复核、可靠提醒等付费增量。用户、购买决策人、可接受价格、获客成本、付费留存均未知；本轮无新支付、广告支出或 API 订阅。

## 验证与停止规则

在既有 2026-10-19 复核日增加 research board 专属观察（写入 fleet-bets）：至少 5 次非 QA 自愿 review_export 和 3 次 watch_compare 只触发进一步核实，不代表人数或市场验证；扩建需要另有至少两个独立使用者的重复研究需求和相对替代品的改善证据。缺少相关曝光或 opt-in 不足时记 insufficient；有明确曝光且保存/复盘不发生，或反馈显示比现有流程更麻烦，则收缩到免费辅助工具，不继续建设独立社区或收费历史。门槛是本项目经营规则，不是统计显著性。

不新增 cron。沿用每日 fleet-autopilot 和已安排的 2026-09-26 一次性复盘。API 每个边缘缓存未命中只请求固定的两类源；每次体积和时间有界。新增客户端逻辑无模型调用、无第三方脚本或新的付费依赖。每日巡检多一个 HTTP 读，沿用已有三分钟上限。

本地验收：91 项测试、60 个 HTML 页校验通过；包括源时间、单资产降级、历史缺口、快照过期/篡改、无新报价时拒算变化、复查日期与反证必填、HTML 转义和 API 范围。
