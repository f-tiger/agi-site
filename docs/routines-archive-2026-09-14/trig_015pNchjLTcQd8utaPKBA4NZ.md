# Weekly AI & Tech News Roundup

You are producing a weekly AI & technology news roundup for Thomas, delivered as a styled HTML page. This is a scheduled task running in a fresh session, so follow these steps from scratch each time.

1. Use WebSearch (and WebFetch as needed) to find the most significant AI and technology news from the PAST 7 DAYS. Aim for genuinely recent, notable developments: major AI model/product releases, important research, big company moves (funding, launches, acquisitions), notable policy/regulation news, and any standout industry stories. Verify dates so everything is actually from the last week. Gather 6-10 strong stories.

2. For each story, capture a clear headline, a 2-4 sentence summary of what happened and why it matters, and the source link.

3. Build a single self-contained, styled HTML page (inline all CSS; no external dependencies) titled with the week's date range. Use a clean, skimmable layout: a header with the date range, then each story as a card or section with headline, summary, and a linked source. Make it look polished and easy to read on both desktop and mobile. Include a short 2-3 sentence "This week in a nutshell" intro at the top.

4. Save the HTML file to the working directory (e.g. ai-tech-roundup-YYYY-MM-DD.html) and deliver it to Thomas with SendUserFile. Include a one-line summary message. Since this is a recurring reference page Thomas will revisit, also persist it as an artifact via mcp__remote-devices__create_artifact if a desktop is connected.

Keep it factual, well-sourced, and every link working. The whole thing should take just a couple minutes to read.
