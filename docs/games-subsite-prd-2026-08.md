# 游戏子站 PRD:The Game Evidence Ledger(暂名,2026-08-22)

Owner 指令:「增加子站点,寻找方向,我朋友在游戏这里还不错」+ 追问确认:朋友做
**欧美游戏、上市场**(向西方市场发行/上架游戏)。三路并行调研(幸存形态 / 供给侧
合作经济 / 需求缺口),全部多源带日期;完整报告存 scratchpad,关键数字下引。

## 一、三路证据在哪里会合(为什么是这个方向)

**① 幸存形态**:游戏编辑部/榜单站已死(Retro Dodo -85%、gamedesigning.org 月入
$23K→$1.8K);活下来的是**带会话时长的工具/数据库**(palworld.gg 两年后仍 240 万
访/月)与**每周变化的数据**。游戏展示广告 RPM 全网最低($2-6/千次),真实钱来自
订阅/捐赠 + key 店联盟(Fanatical 12%/Humble 10%)+ 25K PV 后的 Raptive。
**② 供给侧(朋友 fit)**:**Poki 对「外链/搜索进来的玩家」付 100% 分成,平台自然
量只付 50%**(TechFundingNews 2025-26,双源核实)——SEO 在别人的游戏上是**边际
收入翻倍器**,且逐链接可测,天然适合按归因流量分成的合作。朋友正做欧美上架,
这条套利线一开始就有真实客户。诚实预期:一个受管理的游戏组合年一 $500–5K/月,
是「利润倍增层」不是横财。
**③ 需求缺口**:游戏信息的缺口已不是覆盖而是**信任**——"is X dead" 查询量巨大,
而在位供给(activeplayer.io 等)**公然编造玩家数**;Steam 生成式 AI 披露率
10.9%→19.9%→**30.8%**(2024→2026,公开数据集)却**没有任何活体追踪器**。
两个缺口都长着本舰队台账的脸:带判定、带日期、带翻转条件、零编造。

## 二、站点形状(一站三引擎)

**定位:游戏界的证据层**——与 agiscorecard 同一 DNA,不同战场。

1. **引用引擎:Steam AI 披露追踪器**(旗舰差异化)——活体数据集 + 一页式判定
   (当前披露率 % / 趋势 / 大厂名单 / 销售表现),数据源 Steamworks 公开披露,
   每日自动重算(站点自有触发器)。全网供给 = 一份 substack + 一次性研究,
   无在位者。天然与 agi 的 AI 叙事互链(受众重叠)。
2. **搜索引擎:"Is X dead?" 判定台账**——只用 Steam 官方并发数(公开 API,
   可自动化),主机端如实写 "unknown";每游戏一页:结论 + 日期 + 翻转条件 +
   30 天并发曲线。程序化生成(gen_lib 模式),首批 15-20 个高查询游戏。
   在位者全靠编数,零编造就是护城河。页内挂 key 店联盟模块(worth playing →
   cheapest key,5-12%)。
3. **营收引擎:朋友供给线(Poki 直达流量套利)**——为朋友已上架欧美的游戏建
   品牌落地页/攻略页/GEO 面,外链导入 Poki/CrazyGames(或自托管构建),
   归因流量按分成结算。这是唯一 day-one 有付费对手方的线。

**90 天加速器(可选)**:中国 AAA 出海的英文信息套利(钟馗 8-20 刚发 15 分钟
实机、Phantom Blade Zero 10-29 发售、HoK:World 全球版待宣)——CN 一手源每天更新,
EN 侧全是抢注垃圾站;双语能力是结构性优势。按「be-first」窗口打,不作主线。

## 三、三门判定

- **数据门**:Steam API 并发数 = 官方一手;AI 披露 = Steamworks 公开数据;
  Poki 100%/50% 机制 = 双源核实;全部可自动重算,零编造可满足。✅
- **需求门**:"is X dead" Steam 论坛持续开串 + 在位者靠编造存活(= 真需求被
  劣质供给占据);AI 披露趋势被 Engadget/PC Gamer 反复报道但无追踪器;朋友的
  买量成本痛(¥98/用户、渠道双寡头)是行业级实证。✅
- **商业门**:三条钱路——key 联盟(即时)、朋友分成(day-one 客户)、
  25K PV 后广告;外加数据集授权期权(Steam AI 披露数据被媒体引用即有 B2B 面)。✅
