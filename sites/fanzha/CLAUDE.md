## 定位
AI 时代的**反诈判定站**,不是案例站。主站记录 AI 走到哪一步,本站负责那一步之后的事:
**眼见不再为实,那怎么核实**。三样东西——带法律条款与官方提示的判定页、三个不上传的工具、
只列官方入口的资源页。**不讲案例吓人、不引追不到原始通报的统计、不卖任何东西、不收录第三方
「反诈课程 / 防骗软件」、不用注册。**

判定页六件套(标题即问题 / 首屏一句结论 / 一张表 / 可见 FAQ 与 FAQPage JSON-LD 逐字一致 /
带日期的一手依据 + 一手源外链 / 翻转条件)——与主站同规,`faq ok` 是部署闸门的一部分。

## 机器结构
- 纯静态 `site/`,`worker.js` = 资产透传 + `/e` 白名单事件 + 服务端 page_view + ua_audit + `/api/pulse`。
- **D1 复用** `after35-events`(6109b81e-…):账号 10 库上限(建库返回 7406)。本站表名前缀 f:
  `fev`、`fua_audit`。三站(after35 / learn / fanzha)永不共用表;舰队 `ai_referrals` 按 `fev` 登记。
- 部署 `deploy-fanzha.yml`(push 路径过滤 + dispatch + 每日 08:20Z 兜底);闸门 = 文件齐 + `node --check`
  + 单测(5 条,假 D1)+ `gen_md.py` 重生成 4 张 .md 孪生与 llms-full + 零编造 grep + 三页 FAQ 一致;
  冒烟 15 路径 + `/api/pulse`。
- 一键停止:`sites/fanzha/KILLED`。IndexNow 密钥文件已放 site/,host 在 `tools/indexnow-subdomains.mjs`。
- 事件白名单:`page_view`、`tool_result`、`bridge_click`、`resource_click`、`share_click`、`faq_open`、
  `card_print`。**永不记录暗号、号码、任何输入内容**——工具只回传形状(`family:generated`、
  `check:red:9`、`transfer:all6`)。

## 内容硬约束
1. 一手依据只认:法律与行政法规原文(《反电信网络诈骗法》第十八、三十一条,2022-09-02 通过、
   2022-12-01 施行;《禁止传销条例》第七条)、公安机关公开提示与政府门户页。每条带日期与外链。
2. **不引任何「诈骗案件激增 xx%」「受骗率」「拦截金额」统计**——2026-09-15 检索到的全是二手转述,
   追不到公安机关原始通报。部署闸门 grep 了这一类写法。
3. 不写案例细节、不用恐惧带流量;不点名任何具体 App、平台、品牌为「骗子常用」。
4. 法律只概括不解释,页面明写「不构成法律建议,以原文与执行机关为准」。
5. 三个工具全在浏览器里跑。**家庭暗号永不写进链接、永不上传、永不进 D1**——这是本站唯一一条
   无论如何不能松的技术红线;`/family-code` 的表单没有任何 fetch。
6. 每页底部保留 110 与 96110;本站不替代报警。
