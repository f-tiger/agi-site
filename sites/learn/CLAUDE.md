## 定位
AI 时代的**教育判定站**:两条主线——成年人失业后学什么(接三十五后)、家长替孩子决定学什么(家庭教育)。
方法与主站一致:判定型页面六件套(标题即问题 / 首屏结论 / 表格 / FAQ 与 JSON-LD 逐字一致 / 带日期的一手依据 /
翻转条件)+ 纯前端工具 + 只列官方来源的免费资源。**上游 = 主站 AGI-2027 追踪器**:分数动了,本站翻转条件跟着触发。
**不卖课、不推荐机构、不接广告、不做分销、不用注册。**「各个方向主动尝试」的边界:任何新方向都必须能落成
「带一手依据的判定 + 不上传的工具 + 官方免费入口」三件套;落不成的不上。

## 内容硬约束
1. 一手依据只认:法律原文(家庭教育促进法)、政府文件(人社部财政部 2025-03 通知、四部门 2024-12 通知、
   教育部 2025-05 两份指南)、官方平台(smartedu.cn、12333.gov.cn)、主站追踪器、姊妹站核实过的额度。
2. **不引任何「就业率 / 成功率 / 编程学习人数 / 焦虑比例」统计**(09-15 检索到的全是自媒体二手)。
3. 各城市补贴金额与项目一律不列,只给查询入口。
4. 法律只概括不解释;页面明写「以原文与执行机关为准」。
5. 家长侧文案不制造焦虑:每条建议都要配「别花钱的地方」。
