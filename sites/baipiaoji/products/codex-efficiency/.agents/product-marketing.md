# BPJ Codex Efficiency marketing context

**Document version:** v1
**Last updated:** 2026-09-30

## Product Overview
Local Codex Skill + dependency-free CLI for task usage review. Free Lite reads selected local sessions; optional server evaluation returns deterministic project rules and descriptive history. Category: Codex usage review / workflow skills. Proposed Pro offer: 19 USDT / 30 days, manual renewal, 3 project slots, 100 evaluations; one evaluation free per account. Checkout remains closed pending live acceptance and owner enablement. No MCP shipped. Product source, PRD and live readiness are authoritative.

## Target Audience
Hypothesis: independent developers repeatedly using local Codex CLI on the same projects. They can inspect installation commands and task acceptance. Job: understand a completed run, decide what to change, and retain a review across future runs. Not a general ChatGPT audience.

## Personas
Initial self-service buyer and user are the same developer. Team approvers and organizational procurement are unvalidated; no enterprise claims.

## Problems & Pain Points
Repeated attempts and changing scope may make a task expensive to finish. Actual frequency, lost time, willingness to pay and emotional language have not been established through customer interviews. Subscription complaints are a research signal, not a conversion forecast.

## Competitive Landscape
Alternatives: existing local counter tools, maintaining one's own project instructions, reading session logs, doing nothing. We have not established superiority over any named competitor. A developer who only needs counters should use Lite or their existing tool. A developer happy with their own rules may need no purchase.

## Differentiation
Explicit session selection, reviewable numeric submission, evidence-linked deterministic rules and per-project history form the proposed workflow value. These are implemented features, not unique-market claims. Raw code/conversations are not uploaded. Hashed identifiers remain pseudonymous. Repeated paid usefulness is unproven.

## Objections
- “Why pay for generic rules?” Do not unless repeated project review/history is useful; inspect the full free evaluation first.
- “Does it save quota?” No verified savings or official quota conversion; no enforced cap.
- “Will it read my credentials?” The CLI does not discover OpenAI auth files; BPJ device authorization is separately scoped.
Anti-personas: browser-only ChatGPT users, buyers expecting model credits, automatic hard limits or semantic code diagnosis.

## Switching Dynamics
Push: repeated rework. Pull: inspectable local review and reusable rules. Habit: own instructions/log tools. Anxiety: installation complexity, data handling, whether rules add value. Reduce anxiety with source access, precise compatibility and a free first task, not urgency.

## Customer Language
No verified customer quotations. Editorial headline hypothesis: “Codex stuck retrying? Review before the next run.” Use task, review, failures, acceptance, local counters. Avoid guaranteed savings, unlock quota, official plugin, anonymous upload, autonomous optimization, customer counts and scarcity.

## Brand Voice
Direct, specific, technical enough to verify, candid about limits. Lead with a concrete task and a single installation action. Chinese owned audience; English developer communities. Disclose affiliation in any community draft.

## Proof Points
Implementation and tests support capability claims only. Synthetic examples are labeled. No customer logos, testimonials, savings benchmark, real payment acceptance or product revenue established. Closed checkout is not a paid launch.

## Goals
Current phase: free installation and actual task validation. Existing checkpoints remain bpj-codex-efficiency-ready-1007 and bpj-codex-efficiency-paid-1030. Paid day zero starts only when checkout opens. Qualified offer viewer requires supported client, a real task and price exposure, not a page hit. Purchases, refunds, successful evaluations and returning accounts must be verified independently. See launch kit for operational denominators and stop rules.
