# BPJ 自研工具与报价比较台

Owner 2026-09-25 明确要求：完善一轮，发布到 agi-site 的 BPJ，新增定位为自研的工具板块。本次授权覆盖历史保活限制中的新板块、新工具与导航入口；访问方式不变，不将“自研”误解成私有站点。

## 依据与定位

承接本会话的 Workfit 深度研究与 18 条合成报价规则验证。合成样本验证了算术和拒绝条件，未证明 OCR、模型提取质量、真实买方需求或收入。已有 `/work-plan` 已经覆盖“实际岗位 → 工具方案 → 免费额度计算”，本轮直接复用。采购比较是一个可操作的首个工作任务，不宣称覆盖所有行业。

`/studio/` 与 `/en/studio/` 是 BPJ 自主开发工具的独立板块；第三方收录继续留在原工具目录。首页、全站导航、站内搜索与机器索引都可找到。所有页面沿用本站布局、纸色、规则线、系统字体、无圆角阴影或图片，蓝色标识工作流程，绿色标识通过核对的状态。

## 本轮功能

- 纳入现有岗位规划、API 额度、Token 计数、商用核查、订阅体检等自主实现；不复制第三方工具记录，不改变目录的收录与核实口径。
- `/studio/quote-compare` 中英工作台：单一物料、最多 10 家报价，统一需求数量和交期；来源备注与人工复核；件/箱、箱规、起订量、整订倍数、阶梯价、含税/未税、含税运费、人工确认的汇率、有效期、替代料与超买确认、版本排除、原行金额冲突。
- 精确十进制金额运算；只对条件齐全且已人工核对的报价排名；不完整报价列原因，不以零填缺项。不按最低单价直接选供应商。
- 可手动录入、导入 CSV；比较 CSV、完整 JSON 备份和 Markdown 报告；主动保存/恢复/清除本机草稿。导入后清除报价复核与例外批准，重新核对后才进入候选。
- 原文可粘贴并保留。人工复核是用户确认，不是自动语义验证。基准中存在字段级行号引用时，另外验证引用片段确实出现在那一行；不把这个检查称为 AI 准确率。
- 计算与导出免费，报价不上传；本轮报价工具不卖云端保存。已有岗位规划器的会员云存储保持原服务和收费边界。

## 验收与边界

复跑原 18 案例，再加精确小数、坏输入、过期且缺字段、包装倍数、导入批准清除、CSV 注入、同组排序、备份往返测试。构建后核验双语、本地资源、导航、canonical、hreflang、sitemap、结构化数据与真实结果。CI 在部署前运行规则和产物测试，部署后验证页面与资源版本。

不做任意 PDF/扫描件 OCR、自动模型提取、实时汇率、多物料运费分摊、自动下单、新收款方式、新 cron 或外部推广。来源只在浏览器和用户主动导出的文件里；分析事件仅有固定工具动作与 demo/own 类别，不含报价、供应商名、料号、来源或数量。

本轮发布是用户指定的产品实验。后续看真实自有数据计算与导出、复用及独立核实的付款，不把示例使用、自检请求或保存点击计为营收。不编造需求量或用户反馈。
