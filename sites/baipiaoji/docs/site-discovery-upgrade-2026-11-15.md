# BPJ 全站发现与选型升级 · 2026-11-15

Owner 在帧选两轮升级后要求「整个 bpj 站点也升级一次」。沿用 CRO、AI SEO、SEO Audit、Prompt Optimizer；读者是寻找第三方工具或现有 BPJ 工具的个人和创作者。免费价值是找到任务匹配的入口、额度与来源；本轮没有新增收费权益、联盟资格、广告承诺或付费服务。

## 三轮任务明确

1. 目标：把从首页到类目、工具详情和实际使用入口的共同路径升级，覆盖中英文。
2. 约束：不改厂商额度、不把旧资料刷新成今天核实、不批量放开 discovery noindex，不改变支付或私密页，不新增 cron/支出/外联。
3. 验收：首页 14 分类；28 类目指南的 HTML/JSON/MD 同源；700 工具 × 两语言回链；无脚本手机路径、来源日期、canonical、既有统计、发布和真实变更 IndexNow。

## 同类观察

2026-11-15 读取 https://www.futurepedia.io/ 、https://www.toolify.ai/ 与 BPJ 首页。

Futurepedia 以岗位、目标和约束组织工具与工作流；借鉴「先明确任务再选入口」，复用已有 BPJ work-plan 和各类额度对照工具。Toolify 将产品目录、分类、榜单与赞助区分；借鉴清晰导航与标注，不复制榜单、不声称自身有访问量排名。两者公开描述不证明实际质量、转化或 AI 引用表现。

## 发现与实现

- 中/英首页分类原只有名称与数量：加入各类具体任务问题，窄屏卡片纵向排列。
- 14 个类别各有人工编辑的区别与核对步骤：聊天/文件/联网，补全/仓库/Agent，图片生成/导出，设计/授权，视频生成/编辑，配音/转写/音乐，文档/协作，写作/翻译，网页/带出处回答，学习/研究，个人/团队自动化，API 速率/总量，安全信息核对，本地运行/远程服务。
- 28 类目在长清单之前给选型说明与实际下一步，页首可直接跳工具或指南。复用现有免费工具、方法页、额度板与目录，明确输入和授权条件，不把普通选型指南当实测。
- 独立重算「有来源与日期的额度记录」与缺失数；不把未知视作无免费档。日期范围按真实 limits.checked，链接可达与内容核实分离。
- 原类目页底“数据核实于”使用全局日期，容易暗示整类刷新；改为逐条额度日期与固定指南修订日期。改写「每日巡检记录每次额度变化」的过强承诺。
- 700 工具双语详情接入对应指南；保持已有 discovery noindex，公开目录收录不代表测试或免费。
- 新增 28 JSON 和 28 Markdown 类目资料，HTML 中用 alternate 链接并在正文可见，llms.txt 描述使用边界。原 canonical、hreflang、ItemList 沿用；不新造 HTML 薄页，不改变排名评分。

## 技能应用与两轮自检

CRO：保留已有使用/购买主路径，补充选型路径，避免再叠加表单。比较「最佳工具」「热门工具」「先核对任务与限制」三种文案，选择最后一种，无排名或质量实测依据支持前两者。

AI SEO：具体任务区别、可复算数据与带日期出处，HTML/机器资料保持一致；文件存在或允许检索不保证引用。搜索机器人与训练抓取控制分开，不能把 GPTBot/Google-Extended 当搜索开关。

SEO Audit：检查稳定 canonical、真实内部目标、移动端及渲染后的 schema；不因网页摘要未包含 JSON-LD 就误报缺失。缺少 GSC/Windsor 实际数据（此前订阅/额度限制），不推断 CTR 或收录改善。

自检一：任务指南不是价格复核。本轮不改 limits；缺失数不等于没有免费档，所有最新日期都不能代替逐条日期。自检二：回链不能扩散 noindex 或破坏首页统计；测试原目录边界、单次点击事件和 QA 排除；部署门禁不裁剪。

## 验证与测量

新增静态回归覆盖所有 28 类目、1400 工具回链、双语镜像、真实目标、schema、无来源/日期夹具。浏览器验证中英文首页→类目→额度板，禁用 JavaScript，320/390/1440 宽度，所有请求拦截；截图人工查看。运行既有 tool-evidence、catalog-expansion、homepage-signals、homepage-clicks-browser、search-experiment、canonical 回归和 GA4 coverage。

搜索/AI 引用待有可读后台数据后验证；已有首页目录点击与工具出站只衡量行为，不等于收入。IndexNow 只通知变化且可索引的 canonical，接收不等于收录。真实发布、线上验证及回执另记工作区交付记录。
