# 帧选目录分类 v2（2026-10-04）

用户反馈：目录分类混乱，需要像成熟短剧产品那样方便找剧。本轮借鉴按题材、剧情兴趣浏览的交互原则，不声称复刻或核验了红果当前客户端的分类清单。

任务三轮收敛：先解决观众找剧；再拆开频道、题材、剧情标签和入口信息；最后验证分类计数、组合筛选、旧链接、分享收藏和移动端，并沿用原发布、SEO/GEO/IndexNow 流程。

## 固定层级

- 频道：剧集（剧情短剧和漫剧）、文化短片；全部作品为跨频道视图。默认展示剧集，诗词与典籍不混入默认剧集列表。
- 主题材：都市、悬疑、奇幻、科幻、古风、人文。每部作品一个主题材，使用稳定 ID。
- 剧情标签：职场、成长、冒险、小说改编、神话、西游、古文明、种田、诗词、典籍；可多选归档，用户一次选一个标签，与题材组合筛选。
- 更多筛选：内容形态、入口平台、观看入口。AI 制作形态不当作故事题材，平台名称不当作内容类型，未核验完结状态不出筛选项。

字典与作品归类同在 `data/manju.json`。新增作品须使用字典；未知分类、重复或未知标签会阻断构建。只显示当前频道和筛选条件下有匹配内容的题材/标签，当前选中的空结果条件仍保留，以便用户取消。计数是目录作品数，不是热度或播放量。

例：北派笔记 = 剧集 / 悬疑 / 冒险、小说改编；美猴王 = 剧集 / 奇幻 / 神话、西游、成长；千秋诗颂 = 文化短片 / 人文 / 诗词。分类依据仍是原始公开简介，不改变来源核查日期。

切换频道清空下级条件；换题材清空标签。收藏视图与分享片单跨频道展示，避免文化短片收藏被默认频道隐藏。旧版 `genre=悬疑冒险` 等链接迁移到稳定类别 ID。查询词不写入统计或分享 URL。详情中的分类可点击返回相应目录；关联作品先限定同频道，再按题材和标签排序。

反方检查一：用八部作品铺几十个甜宠、重生、逆袭等空分类，会增加选择负担。当前只展示有资料支持的分类；后续增加类别需先有作品和清晰定义。

反方检查二：仅替换分类名会让旧收藏、分享、搜索和机器资料分裂。本轮保留作品 ID、旧 URL 兼容，HTML、JSON、Markdown、详情关联和筛选共用归类字段；测试覆盖跨频道分享与分类计数。

移动端首屏优先频道和主题材；剧情标签折叠，选择具体题材后展开，避免筛选控件占满屏幕。
