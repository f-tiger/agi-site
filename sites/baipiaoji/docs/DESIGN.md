# 白嫖计 · 视觉设计规范

风格：**油墨纸 × Unigrid**。定稿于 2026-07-28，方向选择记录见根目录 `direction-approved.md`。
改动前先读这份规范，改动后同步更新它。

来源：A（Lynn Fisher 纯 CSS 几何构成）+ C（Massimo Vignelli / Unigrid）的混合——
**A 给色彩与硬边界与「内容即插画」的母题，C 给信息骨架与「颜色只作编码」的纪律。**

---

## 1. 视觉基调

这个站的灵魂是**一本不骗人的账本**：核实日期、省多少钱、几步做完、多少人失败。
所以视觉的职责不是好看，是**让事实可扫读、可比对、可信**——Vignelli 做纽约地铁图和美国国家公园手册用的就是这套逻辑。

- **零圆角、零阴影、零渐变**。层级靠规则线（1px 发丝 / 2–3px 主线）与留白，不靠柔化。
- **零图片、零 emoji**。插画由内容自己长出来——首页那六行步骤条就是六份作业各几步。
- 受众：中文的普通人，多数在手机上快速浏览、比较、点走。

**两条必须记住的教训**（都是真实踩过的）：
1. 做过一版纯白极简 —— **太素**，看起来像没设计。
2. 做过一版红→金渐变通栏 —— **太重**，那是双 11 活动页的浓度，不是常驻站点的样子。
3. 这个品类（AI 赚钱）的骗局**全靠视觉煽动**：金币、涨幅箭头、大红收益数字。
   我们的差异化有一半来自**看起来不像它们**。凡是能让人联想到「暴富」的视觉元素，一律不用。

## 2. 色彩：只回答「这条信息属于哪一层」

```
--bg    #efece6   纸底（不用纯白：纯白是实验室，纸色是出版物）
--card  #f6f4ef   抬起一层的纸面
--ink   #141414   主文字
--ink-2 #4a4640   次要文字
--mute  #857f73   辅助信息、日期
--line  #d6d0c4   发丝线
--rule  #141414   规则线（Unigrid 的骨架）

--work  #e5502e   赚钱作业   —— 印刷红，由站内原朱红压低 chroma 得到
--plan  #1b4de4   0 元方案   —— 靛蓝
--tool  #1f7a5c   免费工具 / 已核实 —— 墨绿
```

深色模式重定义同名 token：底 `#141414`、纸面 `#1c1b19`、文字 `#efece6`，三色提亮为 `#ff6a47 / #7e97ff / #46a880`。

**用色纪律（唯一一条，但不可破）**：
> **颜色只用来编码「属于哪一层」，不用来装饰、不用来煽动。**

推论：
- 三色同处 oklch 低 chroma 的油墨区间，互相拉开色相 ≥60°；不新增第四个有彩色。
- 没有大面积色块、没有渐变、没有满屏红。
- 语义色（成功/警告）不复用编码色。
- 颜色不单独承载信息——每处配色都有文字说明同一件事。

## 3. 字体规则

全站黑体系统栈，不引外部字体（中文 webfont 动辄数 MB，对普通人的网速是负担）。

```
-apple-system, BlinkMacSystemFont, "PingFang SC", "Microsoft YaHei", "Hiragino Sans GB", sans-serif
```

| 角色 | 字号 | 字重 |
|---|---|---|
| 首页主标题 | clamp(30, 4.1vw, 52) | 900 |
| 详情页 h1 | 26–28px | 900 |
| 区块标题 | 12px + 2px 字距 | 800 |
| 行/卡片标题 | 15–17px | 800 |
| 正文 | 13.5–14.5px | 400 |
| 辅助 / 日期 | 11–12.5px | 400 |
| 统计数字 | 30px | 900 |

- 巨号标题用**负字距 -1 ~ -2px**——这是本规范相对旧版的唯一反转：中文在 900 字重、40px 以上时字面本就发散，收紧才成块。**正文与小字仍然不加负字距。**
- 所有成列数字用 `font-variant-numeric: tabular-nums`。
- 区块标题用「小字号 + 大字距 + 高字重」，不用大字号——Unigrid 的标签逻辑。

## 4. 组件样式

**时刻表行（赚钱作业 / 0 元方案）**：三栏——标题+适合谁 / 失败原因或场景 / 右对齐的步数与成本。
行前有 `01 02 03` 编号（CSS counter，自动跟随筛选后的顺序）。hover 换纸面色，不上浮。
**这是全站最重要的构件**：它让「这条路要几步、多少钱、怎么失败」三件事一眼可比。

**工具格**：密排网格，1px 发丝线分隔，无圆角无阴影。

**角标**：卡片右上角，内容来自工具的**真实福利标签**（完全免费 / 每日福利 / 注册赠送 / 免费额度 / 免费API），
实色红底白字。**不是装饰，是信息**，每张卡最多 1 个。

**已核实标记**：墨绿色 + 等宽数字。绿色在本站只有这一个含义。

**步骤条母题**：首页 hero 右侧，每份作业几步就几根条，首根为红。
它是**从内容长出来的插画**——作业数量或步数变了，图自动变。这是本站唯一的图形元素。

**价格对比**：方案详情页顶部并排两块，共用 1px 外框——左「本方案 ¥0」（墨绿大字）、
右「不用它要花 ¥XX」（灰色划线）。**这是全站唯一允许把数字放大的地方。**

**主按钮**：墨黑实底白字（hover 转印刷红）。文案是动作（「领福利」），不是名词。

**失败原因 / 骗局提醒**：各用一条 3px 红色左线；骗局逐条列出，行前 `×`。
这两块是本站独有内容，给足视觉重量，但**不用惊悚色、不加感叹号**。

## 5. 布局原则

间距阶梯：`4 / 8 / 12 / 16 / 22 / 30`。

- 左侧固定导航 208px：**纯文字 + `01 02 03` 编号，零图标**；顶部两个跳转（作业/方案）带编码色方块。
- 首页 hero 分 7:5 两栏（文字 / 步骤条）；**没有步骤条的页面自动单栏**（`:has(.plot)`），不留空档。
- 工具网格 `minmax(256px, 1fr)`，无 gap，靠边框分隔。
- 区块标题前有一个 12px 编码色方块作图例。

## 6. 深度层次

**只有一级**：静止 → hover 换背景色（`--bg` → `--card`）。
不做阴影、不做位移、不做拟物。纸不会浮起来。

## 7. 禁忌清单

- ❌ 圆角、阴影、渐变（任何一处）
- ❌ 图片、emoji、装饰性图标
- ❌ 引入第四个有彩色，或让三色承担装饰功能
- ❌ 金币、涨幅箭头、放大的收益数字——**任何让人联想到「暴富」的视觉**
- ❌ 每张卡片超过 1 个角标
- ❌ 为了好看给无福利的工具加角标——角标必须来自真实标签
- ❌ 编造价格数字——金额必须来自 `solutions.json` 已核实的区间
- ❌ 正文与小字加负字距（只有 40px 以上的巨号标题可以）
- ❌ 榜单序号乱排（必须对应真实的 hot 标记）

## 8. 响应式

| 断点 | 变化 |
|---|---|
| > 1000px | 左侧固定导航 + 7:5 hero + 三栏时刻表 |
| ≤ 1000px | hero 单栏、步骤条移到文字下方；时刻表压成两栏 |
| ≤ 860px | 导航移到顶部横滑（编号隐藏、变胶囊）；`.stage` 边距降到 15px |
| ≤ 520px | 时刻表压成单栏；价格对比上下堆叠 |

宽内容各自 `overflow-x: auto`，页面主体永不横向滚动（已用 Playwright 在 390px 下实测 `scrollWidth === clientWidth`）。

## 9. 动效与无障碍

- 只保留一处动效：hover 换底色，.12s。**没有位移、没有缩放。**
- `prefers-reduced-motion: reduce` 时全部关闭，包括平滑滚动。
- 焦点态：`2px solid var(--work)` 外框 + 2px 偏移，键盘可见。
- 正文对比度 ≥ 4.5:1；编码色从不单独承载信息。
