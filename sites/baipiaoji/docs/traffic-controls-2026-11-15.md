# BPJ 异常流量治理 · 2026-11-15

Owner 明确授权执行「统计分开、接口限流、精准拦截」。三轮明确：①先取得最近完整日期基线；②保留原始统计、正常访客和搜索/AI 内容抓取，不按国家或 UA 单独封禁；③验证并发限流、输入保留、重复请求、隐私排除、可撤销和线上状态。此工作不修改 GA4 历史、不购买 Cloudflare 套餐、不新增定时任务。

## 只读诊断

`d1-usage.yml` 的 bpj 模式仅查询 baipiaoji.com，最近 1–14 个完整 UTC 日，默认 7 日；GA4 请求按属性时区的最近 7 个完整日期。报告 RSA/AES 加密，Actions 保留 1 天，私钥仅在工作区。没有 IP、查询串或会话指纹查询。CF UA 聚合只在加密报告中，不写公开仓。GA4 缺凭据或套餐不可读保留未知。

本次窗口 11 月 8–14 日，35 个 CF 聚合均成功且未触及 2000 分组上限。GA4 缺 service account。脱敏结果保留工作区，不能以请求占比代表 GA4 用户占比。已验证抓取包括正常搜索/AI/预览，不等于恶意。异常浏览器身份只作启发式观察；不作逐人断言。

## 已实施保护

仅 POST `/api/manju-discover`、`/api/submit`、`/api/claim`、`/api/manju-inquiry`：

|接口|每个边缘来源地址的预算|请求体上限|
|---|---|---|
|远程搜索|30 次/60 秒|2000 字节|
|投稿|5 次/600 秒|16000 字节|
|认领/更正|6 次/600 秒|16000 字节|
|咨询/纠错|5 次/600 秒|6000 字节|

先做同源与 JSON 类型、流式体积检查；超过频率返回 429 与 Retry-After，数据库不可用返回 503，不继续昂贵业务。只信任 Cloudflare 注入的 cf-connecting-ip，忽略 X-Forwarded-For；用接口/时间桶/地址 SHA256 建私有临时限流键，不存原始 IP。这是伪名安全计数，不声称绝对匿名。共享出口用户共用额度，等待后重试，不将其贴真人/机器人标签。固定窗口边界可能出现双倍短时突发，非全网严格滑动窗。

D1 原子计数防并发穿透；超额回复在边缘按到期时间缓存，减少后续 D1 访问。到期行在后续请求中通过 expires 索引每次最多删除 50 行；无请求时不会主动清理。跨 PoP 缓存并非共享，最终判断仍依赖 D1。分布式攻击仍可能消耗请求/数据库配额，不能把应用层限流说成 CDN WAF 防护。

远程搜索原有 5 次未命中/10 分钟、40 次全局源查询/小时、query hash 缓存和 pending 合并保持；公开发现资料 GET 加 5 分钟边缘缓存。投稿以单条条件 INSERT 防并发重复，并增加 URL 索引。认领原有单记录冷却保留。本次不改其域名授权模型。

普通页面、robots、sitemap、LLM 资料、只读工具 API、MCP 和 GET 认领查询不受此限流。任何 UA 即使自报 Googlebot 也不能绕过这些 POST 写入预算。

## 统计分开

保留 `hits` 原始写入，额外 `bpj_traffic_quality` 只聚合 UTC 日期 × 固定事件种类 × 四类观察：Cloudflare verified_bot、declared_automation、ua_anomaly、unclassified。UA 规则复用已核查的不一致浏览器版本及 iOS/Chrome 格式；未分类不代表真人。

类目区分普通 page、帧选 view、search_submit、official_open、save、分享、云收藏、工具出站/关注及 other_event，曝光不记成有效互动。排除 CI/QA、DNT/GPC；沿用现有客户端的统计拒绝规则。无新 Cookie、会话 ID 或指纹；不存路径、国家交叉、UA、输入内容。

`GET /api/traffic-quality` 返回最近 7 个完整 UTC 日的汇总，边缘缓存 5 分钟；缺表/读取失败 rows=null、status=unavailable，不伪装零。它是经既有处理器校验的第一方 beacon 观察，不涵盖 CDN 请求或所有自动化，也不是 GA4 的后台清洗。历史不回填。GA4 可见停留继续沿用现有采集器；后台访问受限，不能声称已证明真人或互动提升。

## 两轮自检与回滚

1. 可误伤共享 NAT：低成本读页不受限；写入预算按业务节奏保守设置，返回明确等待时间，表单输入不清除。部署后观察拒绝和用户反馈，不能按国家封禁。
2. 可伪造 UA、header、事件：UA 只观察，限流不依赖 UA；固定事件/索引聚合不建立身份关联。质量写入故障不影响原始统计或页面。限流存储故障按 503 明确返回，不能静默放行昂贵动作。

紧急撤回限流：设置 BPJ_TRAFFIC_LIMITS=off 后发布，仅撤频率检查，同源/体积保护仍保留；质量计数可设 BPJ_TRAFFIC_QUALITY=off，报告返回 disabled。也可 revert 本次 PR 并正常重发。不要删除历史原始统计。
