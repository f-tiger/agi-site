# 帧选营销执行材料

这套材料用于验证中国创作者是否会实际使用帧选，以及作者是否愿意引用可复算观察。首轮优先通用视频，App 演示作为第二个练习场景。

| 材料 | 用途 | 当前状态 |
| --- | --- | --- |
| [营销方案](../video-marketing-expansion-2026-10-11.md) | 优先级、渠道依据、商业假设、两周实验 | 研究与执行规格 |
| [两条教程脚本](CONTENT-KIT.md) | 连续录屏、口播、披露、行动入口 | 待录制和平台发布 |
| [发布交接空白 CSV](publication-handoff.csv) | 按平台记录待办、修订及公开规则出处 | 可复制使用；填写内容自行保管 |
| [七次榜单观察](rank-report/README.md) | 供读者引用具体统计并独立复算 | 帧选自有研究；未确认外部采用 |
| [中文图表](rank-report/endpoint-comparison.png) | 解释两个日期的样本构成 | 原创统计图；带完整口径 |
| [计量实施清单](MEASUREMENT.md) | 补齐工具曝光、结果语义和固定渠道值 | 尚未修改线上埋点 |
| [交付与验证记录](DELIVERY.md) | 查看审视修正及文件验收 | 对应本目录版本 |

已有产品入口为 [视频工具](https://baipiaoji.com/manju/video-fit)与[片库](https://baipiaoji.com/manju/)。本目录是仓库资料，不是新部署的站点页面。教程发布和新增外联按实际授权与账户规则执行；没有新的第三方引用或流量成果可据此宣布。
