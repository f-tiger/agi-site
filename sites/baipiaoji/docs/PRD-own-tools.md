# PRD：自建 AI 工具线——「数据长出来的工具」

2026-08-08 立项。回应的诉求：站上大量工具都是外部的，要逐步积累自建 AI 工具，
让网站独一无二。

## 一、调研结论（证据，不是感觉）

- **用户是谁**：可验证真人点击 59 次中 94% 落英文页，集中在 /en/c/coding 与
  fireworks / fastgpt / deepinfra / siliconflow / dify——英文开发者，在查
  「这家平台的免费额度到底多少」。
- **竞对格局**：搜索核查确认，市面上的计算器全是**付费成本计算器**
  （tokens → 美元：aitokencalculator、langcopilot、pricepertoken 等），
  没有一个回答「哪个**免费档**扛得住我的用量」。OpenRouter 只有清单文。
- **本站独有弹药**：115 条带官方出处与核实日期的 limits、39 条商用授权判定、
  每日变更日志。这批数据没人有。

## 二、洞察：自建工具的护城河公式

**通用 AI 玩具（聊天框/改写器）= 零护城河**：任何人接一个 API 就能抄，
且本站没有付费 LLM key，跑不起推理。

**本站的公式：工具 = 界面 ÷ 已核实数据。**
数据别人没有，工具就无法复制；数据每天在自动更新（巡检/变更检测/雷达），
工具的答案就每天自动变新——这是「AI 时代算法」在本站的落地形态：
不是在页面上挂个模型，而是让**核实流水线成为工具的引擎**。

已核实数据 → 结构化（散文给人读，结构化给程序算）→ 工具 → 使用量度量（calc 事件）
→ 决定下一个结构化投入方向 → 回到数据。飞轮闭环，每一环都已自动化或有硬规则。

### 扩张节奏规则（2026-08-12 定，长期有效）

两侧的扩张逻辑**相反**，不能用同一个日配额去推：

| | 目录 / 核实 | MCP 工具 |
|---|---|---|
| 多了会怎样 | 覆盖面变大，长尾入口变多——**越多越好** | 全部定义都进每次对话的上下文，描述相近的互相抢匹配，选择准确率**下降** |
| 日配额 | 有：每日至少 20 个新工具入库 + 至少 3 条存量 limits 核实到官方来源 | **没有**。按数据成熟度推进，不按数量 |
| 新增门槛 | 确有免费额度、官方站可达、不重复 | 覆盖一个**尚未被覆盖的问题形状**，且背后有一份真实数据集 |

实测依据：11 个工具已覆盖现有数据能支撑的全部问题形状。再往下扩会开始互相
抢匹配——我们自己就是证据，5 个工具时期 agent 只调过 search_ai_tools。
工具数的自然增长路径在数据侧：每结构化一个新类目，compare_free_tiers 的
覆盖面就扩一格；等 image/audio/design 都结构化完，再评估是否值得单开工具。

**新工具入库的纪律**：只写可确信的事实（是什么 / 免费档形态 / 怎么开始 /
官方站），**一律不写额度数字**。数字归 limits，须逐条核实官方页面，
经 scripts/limits-edit.mjs 两步写入。新条目无 last_verified，
站上显示「待核实」，由每日 verify.mjs 巡检确认链接后进核实队列。
扩覆盖面不得稀释「每个数字都有出处」——这条是站点的命根子。

## 四、诚实边界（自建工具同样适用）

- 折算只用官方口径；官方没给折算的（Cerebras $5）**明说不代算**；
- 官方未公布数字的（HF/DeepInfra/Google 实时表）单列成行——「不知道」也是答案；
- 计算器只做除法，事实全部来自结构化数据，结构化只从已核实文本提取；
- 每个结果行带核实日期与工具页回链，可追问「凭什么」。

## 五、AI 时代的分发与商业模式（阶段化，证据门控）

1. **当下（分发）**：AI 助手/代理是新的搜索。已有 llms.txt、FAQ schema、
   CC BY 开放 limits.json、AI 爬虫可达性每日探测（9 家全通）。自建工具页
   本身是最强的可引用资产——助手回答「哪个免费 API 够用」时唯一可引的结构化来源。
2. **积累（资产）**：邮件名单（通道待 API key）+ 变更日志权威性 + 工具使用数据。
3. **变现（全部门控，不提前建）**：
   - 赞助位（sponsor 位已在站上，virtu 空置中）——门槛：真实流量；
   - 计算器 Pro（保存配置/团队对比/API 访问）——门槛：calc 事件周均 >50 且有回头用户；
   - 数据授权（limits API 商用）——门槛：有 agent/公司主动来抓 limits.json 的证据。
   在门槛达到前，一切保持免费——信任是本站唯一的复利资产。

## 七、v2 战略升级（2026-08-08）：垂直打透 + 工具工厂 + Agent API

用户方向指令：不保守、激进创新、确定性路径，「100 个工具」或「垂直打透」二选一。

**决断：垂直打透。**「100 个工具」会逼着造垃圾——工具农场正是社区嘲讽的对象
（40+ 工具一半是三个 prompt 的 demo）。激进的正确形态是把「免费额度情报」这个
垂直做到无人能追，数字目标给在能兑现的地方：

### 数值目标（确定性路径，全部可枚举可验收）

| 目标 | 现状 | 到位标准 |
|---|---|---|
| G1 已核实 limits 数值结构化 | 13/115（api 类） | **115/115**——每类一个 quotas 文件，全部只从已核实散文提取 |
| G2 工具矩阵 | 4 个 | **每类目 1 个数据驱动工具 ≈ 14 个**+跨类 3 个（栈/发布/API）≈ 17 个高质量工具 |
| G3 Agent API 覆盖 | limits | limits + licence + quotas + changes 四资产全部可查询 |
| G4 每日自动化闭环 | 8 步 | 发现→雷达→核实→结构化→工具→API→变更广播 全链无人值守（核实环节除外，永久人守） |

工厂模型：**每结构化一类数据，自动长出一族工具**——licence.json 长出 publish-check
与栈组装器商用模式；api-quotas 长出计算器；下一个结构化的类目照此复制。
工具数量是结构化进度的因变量，不是拍脑袋的 KPI。

### Agent API（2026-08-08 上线）——AI 时代最激进的一步

/api/limits：免鉴权 JSON、CORS 全开、CC BY 4.0、每条带 source 与 checked；
?slug= 单查、?category= 过滤；未知 slug 返回 404 并说明「缺席是有意的」。
llms.txt 向 AI 检索广播端点；/developers.html 双语文档含 agent 提示词范例；
CI 每日自测契约（slug 命中 / 404 语义 / CORS 头）。

逻辑：AI 时代的分发不是等人来点，是**让 agent 在回答「哪个免费档够用」时直接查你**。
~~全网免费额度站没有第二家提供带出处的结构化 API——这就是被引用的护城河。~~
**2026-08-16 修正（对抗核实推翻）**：至少 6 个站在做「带核实日期的免费额度/定价目录」
（FreeTier.co 857 个产品、CostBench、PricePerToken、TokenTab、CostGoat），
且机器侧抓取成本已跌到约 $1.20/1000 个定价页。**「带出处、带日期」是入场券不是护城河。**
护城河只可能是组合：赛道够窄（编程）+ 中文侧真空 + 有变更历史留痕 + 机器可读同源。
后续按 G3 扩 licence 与 quotas 端点；商用授权（数据授权变现）的证据就看

## 路线图新增（2026-08-16，依据 PRD-subscription-pivot v2）

### #18 撞墙页 `/wall/<slug>.html`（已上线，中英各 31 页）

对抗核实（21/21 通过 / 44 存活 / 4 杀掉）收敛出的最强一条：**诉求在事后 0 秒被错误码
触发，不在事前被担忧触发**。所以「订阅」站错了时间点，该站在这一刻的是一个页面。

只答撞墙的人真正在问的三件事，按他问的顺序：① 撞的是哪堵墙（取已结构化的 `kind`）
② 官方给的额度到哪为止（**带出处 + 核实日期，这是与测评文的唯一实际差别**）
③ 现在换谁还有额度。另有 ③′ 最近变过吗（`limits-history` + `paid.effective`）。

覆盖面 = 编程赛道（PRD 选定的那一格）+ 任何已核实 `limits.paid` 的工具
（后者正是撞墙后要做付费决策的那批）。硬门槛同 `/vs/`：四项齐全才生成，
英文侧另需 en 覆盖。**首个在窗口内的实例：DeepSeek 峰谷计价，新价 2026-08-17
00:00 北京时间生效（公告 08-13，checked 08-15）。**

### #19 增量变更端点 `/api/changes?since=`（已上线）

机器那面。**性质是分发不是构建**——`limits.json` / `changes.json`(35 条) /
`limits.md` / `limits-history.json` 早就都在，缺的一直是**契约**：
版本号、`since` 参数、稳定路径承诺、`<head>` 与 llms.txt 自动发现。

设计照抄 litellm 的 `model_prices_and_context_window.json`（免费、CI 自动更新、
远程 URL 默认 + 本地 vendored 兜底、价值来自被硬编码为默认源）。
**但必须写下它的限制**：litellm 的分发力来自它绑在一个已被广泛依赖的库里，
我们没有那个宿主——所以「被引用」对我们不是副产品，是要单独解决的问题。

因此这个端点的成败指标是「**被写进别人代码**」（GitHub 代码搜索能命中我们的 URL），
**不是抓取次数**——每日数百次通用 AI 爬虫能把抓取数轻易刷成好看的数字，
而那类抓取是 118:1 至近 50,000:1、50%+ 重复的噪声。

### #20 问题页（根级，URL 即问题）——2026-08-16 首批 6 条

**依据是实测不是推测**。Bing Webmaster「AI Performance」30 天对比：
agiscorecard.com **564 次** Copilot 引用，baipiaoji.com **5 次**。拆开看：

- 对方 564 次里 **237 次（42%）来自单页** `/situational-awareness-summary`，前三页占 **72%**；
  grounding query 只有 **6 条**，其中 134 次来自同一个具名对象（Aschenbrenner 那篇论文）。
- **页数不是变量**：对方 193 页，我们 1347 页，引用是我们的 113 倍。
- 我们那 5 次全部来自 `/en/tools/vidu`——**词条页能被引，只是没在为任何具体 query 竞争**。
- 真正的差别是 URL 形态：它的 URL 就是问题（`what-is-agi`），我们的是词条（`/tools/vidu`）。

**首批 6 条**（`data/questions.json`，中英各一版）：
`why-did-my-ai-free-tier-stop-working` / `which-ai-coding-tool-has-the-biggest-free-tier` /
`do-ai-vendors-cut-free-tiers-quietly` / `did-anthropic-file-to-go-public` /
`which-ai-tools-are-completely-free` / `is-there-a-free-alternative-to-cursor`

**硬规则**：只出已核实数据能答的问题；`answer` 段必须自身站得住（会被整段抄进 AI 答案，
脱离上下文也不能读错）；凡不是从 tools.json 派生的一手事实，必须带 `source_zh/source_en`
与 `checked` 并在页面上显示。

Anthropic 那条是这批里唯一的热点实体，处理方式值得记：**标题写「上市了吗」而不是「上市了」**——
已核实的事实是 2026-06-01 向 SEC **保密递交 S-1 草案**、未定价未定日，
所以「Anthropic 已上市」目前不成立。我们的差异化角度也在这里：财经媒体报 IPO 本身，
**只有我们能答「这对我的免费额度意味着什么」**（答案是：递交 S-1 本身不改变任何额度，
我们逐日复核并记进公开日志）。

### #22 写作翻译类对照板 `/writing-quota-board.html`（G1 第九类，2026-08-17）

`data/writing-quotas.json` 7 条，零新增事实（quota-facts 21 组全过）。

**本类的轴与前八类都不同**：写作翻译类最容易被忽略的墙不是「你用得多快」，
是**你一次能贴多长**——QuillBot 改写单次 125 词、Wordvice 单次 500 词，
这类墙跟你一个月用几次毫无关系，长文一律要手工分段。

另有两条只有本类才明显的形态：
- **沉浸式翻译是软墙**：高级 tokens 用尽后不停，回落到基础引擎，翻译照常只是质量降档。
  所以「用完了怎么办」在这里的答案跟别家不一样：什么都不做也能继续用。
- **有道是余额制不是额度制**：50 元体验金用完就是用完，不会自动刷新；
  彩云是一次性 100 万字符且到期自动清零。两者都不是「每月还有」。

`gate` 五型：per_input / monthly / one_time / balance / degrade。
