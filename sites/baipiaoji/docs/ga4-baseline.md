## 三、问题 1：42% 的数据来自回退域名（已修）

| 域名 | 会话 | 特征 |
|---|---|---|
| `baipiaoji.com` | 20 | 平均时长趋近于 0，engaged 会话极少 |
| `aiyangmao.pages.dev` | **14** | 平均时长高出两个数量级，engaged 比例明显更高 |

同一份 GA4 同时在正式域和 Cloudflare Pages 的回退域上收数，**两个域名的行为特征完全相反**——混在一份报表里，任何结论都是假的。
pages.dev 上那批大概率是我们自己在预览。

**已修**：`scripts/build.mjs` 的埋点改为**只在 `baipiaoji.com` / `www.baipiaoji.com` 上初始化 GA4**。
非正式域名时 `gtag` 仍然存在（埋点照常调用），只是没有接收端，事件停在 `dataLayer` 里不发出去。

> 顺带提醒：`*.pages.dev` 默认可被搜索引擎抓取，与正式域构成重复内容。
> 目前靠每页的绝对 `canonical` 指向 baipiaoji.com 兜底，够用；如果以后发现 pages.dev 被索引，再在 Cloudflare 侧加访问限制。

## 四、问题 2：97% 的流量不是目标人群

| 国家 | 会话 |
|---|---|
| 美国 | 16 |
| 德国 | 4 |
| 英国 | 3 |
| 法国 / 波兰 / 加拿大 / 荷兰 / 新加坡 / 韩国 / 西班牙 | 各 1 |
| **中国** | **1** |

渠道：**32 Direct + 1 Referral**。落地页高度分散——8 个不同的 `/tools/xxx` 页各 1 次。

这个组合（Direct + 海外 + 全部首次访问 + 近零互动 + 按 sitemap 逐页扫）**高度疑似爬虫或扫描器，不是真人**。

**结论：目前没有任何可用于产品决策的用户信号。**
33 个会话、2 天、且大概率非目标人群——此时"根据数据优化网站"是过度解读。

## 五、第一个自然搜索用户来了（07-29）

复查时出现了上一版没有的信号——**全站第一个自然搜索会话**：

| 日期 | 来源 / 媒介 | 国家 | 落地页 | 互动时长 |
|---|---|---|---|---|
| **2026-07-29** | **google / organic** | **中国** | **`/tools/deepl`** | 11 秒 |

同两天里另有两个来自中国的会话落在 `/tools/wps-ai`（其中一个互动 25 秒），
以及 1 次 `/money/ai-tool-review-account`、1 次 `/en/`。

对比之下，同期美国那批 11 个会话全部落在首页 `/`，总互动时长只有 5–6 秒。

**这条信号改变了下一步的优先级**：

1. **工具详情页是目前唯一在带真实中文用户的入口。** 用户搜的是**工具名**，不是「AI 工具导航」。
   长尾 SEO 这条路被验证了——而首页没有任何自然流量，也不该指望有（没人搜品牌词）。
2. **所以杠杆点是把工具详情页做深，不是继续加板块。**
   已落地：给全部 154 个工具页加了**由真实字段推导的 FAQ + FAQPage 结构化数据**
   （免费吗 / 怎么领要不要注册 / 国内能不能直连 / 能用来做什么 / 什么时候核实的）。
   五个问题全部来自已有数据，一条也没编。
3. 分发仍然要做，但顺序变了：**先让已经能带量的页面更能带量**，再去铺新渠道。

| 动作 | 参考 |
|---|---|
| 提交 sitemap 到 Google / Bing / 百度 | `docs/seo-backlinks.md` |
| 提交到中文 AI 工具目录与导航站 | `directory-submissions` skill |
| 在知乎 / 小红书 / 少数派发第一批内容 | `content-strategy` skill |

**在样本量起来之前，增长闭环的自动优化仍然不会触发**——单分类 14 天点击不足 20 次就不动推荐位，现在一条都过不了。这是设计如此，不是故障。
