# BPJ 全站体验与功能发现重构

## 三轮 Prompt 优化记录

用户要求：先优化三轮，再重构全站视觉、功能导流、SEO/GEO/MCP和社区分享。执行范围为现有 BPJ，不另造一个没有数据、权限和支付能力的新站。

第一轮：目标与边界。将“适合欧美和中国”转成双语阅读、熟悉的导航、移动端可用、透明使用条件；不凭国别臆测审美偏好。盘点主站、独立工作台、会员页三套构建器；区分第一方工具、第三方目录、账户服务与商业推广。保留网址、数据、付款和本地处理契约。

第二轮：转化与发现。用户先选任务，再使用工具，再进入相关下一步。首页突出 PDF、商品图、视频变体和工作规划；全站导航、42项功能地图、相关入口与搜索互相接通。注册、云保存、付费试点按实际能力说明。不用虚构用户量、收入、倒计时或“全部免费”提高点击。

第三轮：验收与反证。对抗审查至少两轮；检查真实页面、表单、移动导航、旧链接、暗色对比度和公开分享边界。SEO/GEO通过可读正文、准确schema、双向语言链接、站点地图与引用信息落实；MCP只新增页面发现资源，不虚构执行能力。分享入口不等于社区发布，机器文件不等于被引用，访问不等于付费。

最终执行 Prompt：在现有 agi-site 的 BPJ 上实现上述体验重构；复用真实数据与功能；先完成三套页面的一致导航、任务发现和下一步导流，再补全搜索、结构化数据、MCP与公开链接分享。为高风险交互和发现契约保留自动验证，修复两轮审查发现后，按现有站点授权通过CI部署，并实际核验线上版本。只有真实使用和付款数据才能判断商业成效。

Prompt自评是需求完备性检查，不是成功概率。评分维度：目标20、范围与事实20、可执行路径20、验收25、反证与隐私15；最终自评96/100。缺少真实用户偏好及新版本转化样本，因此不能给产品效果95分。

## 实现

- 统一主站、8个双语工作台页、4个会员语言页的导航、字体、颜色、页脚和返回路径。
- 白底蓝色主要操作，任务优先首页，保留完整目录的旧分类锚点；旧 `#studio` 等入口继续有效。
- 42项双语功能地图：独立工具、额度板、业务工作台、比较、监控、开发者与厂商入口。标注8项邮箱注册门槛；云账户另说明。
- 搜索索引纳入功能地图，`?q=`真正预填并执行查询。相关下一步来自同一功能注册表。
- 分享只复制公开canonical，清除query/hash；支持原生分享、复制链接、引用和用户主动打开Reddit/X编辑器。没有代发社区帖子。
- MCP增加 `baipiaoji://site-journeys`，同步公开metadata与文案：16 tools / 11 resources / 4 prompts。JSON与Markdown也可直接读取，带CORS。
- 保留来源、核实日期、现有Markdown数据、API、RSS、可嵌入资产及署名回链说明；新增地图进入站点地图。
- 新壳和更新后的共享脚本使用内容哈希缓存版本，哈希参数不改变页面lastmod。
- CI在所有构建器完成后再次检查最终产物，避免后处理绕过断链、schema和语言检查。

## 两轮对抗审查

第一轮发现并修复：首页旧结构化清单与可见内容不符；URL搜索未消费查询；旧导航测试与新结构不兼容；旧#studio锚点缺失；深色表单白底浅字；功能地图遗漏额度板与监控；MCP中文计数滞后。

第二轮发现并修复：视频首页卡片与ItemList所指页面不一致；语言导航测试有旧class导致断言失效。新增真实浏览器检查首页卡片URL与ItemList一一对应，保留语言栏不能混入业务导航的检查。

## 验证与解释边界

最终静态检查覆盖2341个HTML页面，canonical检查覆盖2339个页面；嵌入组件保留自己的简洁界面。双语功能地图所有目标、锚点、搜索与真实MCP handler验证通过。浏览器覆盖390、1024、1440像素，以及暗色会员、工作台和文件工具表单对比度。保留并运行原有视频付费保存、账户切换、历史版本、试点申请和商业触发测试；测试使用本地或模拟数据，不创建生产付款。

主站新视觉覆盖所有通过共享layout生成的页面。长尾页面正文和具体工具功能保留现有逻辑；本轮没有为每个长尾页面重写业务内容。

流量观察：现有 `home /discovery/next…`、搜索 `gs/gs_go` 和分享事件只度量入口行为，不代表任务完成、独立访客或付费。QA标记排除。下一轮使用真实工具使用、云保存与真实订单分别检查；样本不足不宣称提升。没有新增付费投放，也没有声称已获得外链或社区流量。

依据：Google官方文档说明AI搜索仍适用SEO基础，不要求特殊AI文本文件；结构化数据应与可见内容一致。多语版本采用有效、互指的hreflang。MCP资源补充是现有用户/Agent的发现能力，而非排名承诺。
