# 帧选面向观众的快速交付

日期：2026-10-11。Owner 要求「视频站如何快速提供给 C 端用户，你执行优化」。

## 目标与三轮收敛

1. 先满足中文观众找剧：免安装、免注册，用现有移动网页交付；视频发布评估继续服务创作者，但退出观众主导航。
2. 审核实际资料：643 条（含分季），229 条官方合集／作品详情、411 条平台搜索、3 条介绍。两份红果快照各 100 条均有官方详情。主要摩擦是官方入口藏在折叠区、手机看不到收藏导航、默认整榜分享超出 60 条边界。
3. 冻结范围：保留单一封面目录、全量搜索联想、分榜热度与题材推荐；显露实际入口性质，增加官方入口筛选、单剧／当前页分享和浏览器回访说明。无新登录门、App、小程序、PWA、付费 API 或定时任务。

两轮独立对抗已完成。第一轮要求停止模糊的播放承诺、显示榜单观察日期、分享不泄漏查询或假报发布。第二轮放行，补充严格域名／路径校验、分页后的分享重算、长链接窄屏手工复制、每次跳转仅一个对应业务动作。

## 用户与商业模式

免费价值是减少观众的重复搜索：按题材找到作品、辨认来源、打开原平台、在当前浏览器保存片单。观看条件、登录、收费及地区以原平台为准，本站不托管正片，不保证实际播放。

潜在付费方仍是创作者／发行方。专题推广须单独标明广告且不能购买编辑排序；推广佣金须先取得正式授权协议。当前只接受合作意向，没有新的收费入口、佣金合同或已验证成交。

分发采用已获授权的自有入口：BPJ 首页、帧选目录与作品／题材页、站内搜索、机器可读目录、用户主动分享、现有 IndexNow 实质变更通知。没有自动发社交帖、私信、买量或承诺新增用户。

## 交互与数据契约

- 顶栏优先找剧、热榜、我的片单；创作者工具仍可访问。
- 官方入口根据 HTTPS、精确域名与路径／作品编号判定，不能仅凭封面或 collection 标签。入口动作分为 `official_open`、`platform_search`、`intro_open`；未知入口降为查看来源。
- 首页只有一份作品网格，每页 24 条。官方入口筛选可在 URL 恢复，新搜索和重置不能遗留隐藏限制。
- 分享主页用规范地址，单剧用已有作品地址或公开锚点；当前页片单只包含实际可见作品的公开编号。管理区整份筛选片单上限仍为 60 条，不静默截断。不分享搜索原文、QA 参数或浏览器收藏状态。
- 原生分享需用户点击。取消不自动复制、不记成功；不支持或失败时可复制，剪贴板失败提供可手工选择的链接。`share_native` 只说明 API 返回，`share_copy` 只说明复制成功，两者都不证明社交发布或获客。手工展示链接不记录成功。
- 榜单显示各自报告的 `observedAt`；同步失败继续使用最后有效数据，并在选片区域说明。部署日期不改写来源日期，热度不等于播放量。
- 不声明一键安装或离线可用；仅给浏览器收藏／主屏幕操作提示。收藏仅在当前浏览器，不与 BPJ 账户同步。

原生分享能力依据：[MDN Navigator.share](https://developer.mozilla.org/en-US/docs/Web/API/Navigator/share)（HTTPS、用户操作触发、浏览器支持差异、取消、各系统 Promise 返回含义）；回访说明参考 [Apple Safari 书签说明](https://support.apple.com/zh-cn/guide/iphone/iph42ab2f3a7/ios)。2026-10-11 查阅。

门禁覆盖恶意／未知链接分类、单份目录、筛选与全库搜索、分页和锚点、收藏失败、分享取消／复制失败／输入泄漏、320–1440px 布局，以及原有漫剧／视频评估功能。新增动作接入现有 D1 与 GA4 固定白名单，不收标题、搜索词、分享 URL 或收藏列表；保留 QA、DNT、GPC、已保存的 GA4 退出和私密页排除。

发布必须在全部生成器之后通过 GA4 coverage，保留 canonical、真实 JSON-LD 和 JSON／Markdown 内容依据；既有流水线只向 IndexNow 提交实质改变的规范页面。提交成功不等于收录，前端通过不等于 GA4 后台收到事件。

上线后 7 天复核：官方入口／平台搜索分别计数，收藏、原生分享返回和复制成功分别计数；本机有收藏时产生的 return 动作不是独立回访人数或留存率。若官方入口动作不足 30 次，不据此判断产品转化；若达到 30 次，结合真实失效入口反馈决定优先完善源链接还是推荐。需要同口径真人流量分母才能计算转化；当前没有新增用户、留存或收入结论。

本轮运行和上线结果随发布记录补充；GA4 后台收件只有取得真实报告访问后才能确认。
