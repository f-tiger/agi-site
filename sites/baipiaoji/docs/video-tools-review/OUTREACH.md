[公开试用资料](README.md)包含三组完整合成场景的入口、线上截图、方法边界和可运行的复现脚本。[机器可读状态](distribution.json)保留投稿与引用的不同状态。

## 渠道判断

1. [阮一峰周刊](https://github.com/ruanyf/weekly)的当前说明接受软件与资源 Issue。用 App 演示发布准备切入，附可复现输入，适合独立开发者读者。Issue 只是线索，入选周刊正文才是编辑采用。
2. [中国独立开发者列表](https://github.com/1c7/chinese-independent-developer/issues/160)接受面向普通用户的网站自荐。提交网页版工具，采用其贡献格式。完整读取当前 README 和该帖评论后，未发现 f-tiger、baipiaoji 或帧选的现有条目。
3. [小众软件规则](https://meta.appinn.net/t/topic/43728)要求披露开发者关系、真实收费和官方直链，内容经人工审核。适合免费工具的实际用法介绍；不以 SEO 项目或互链为投稿理由。
4. [少数派联系页](https://manual.sspai.com/more/contact/)提供编辑邮箱，列明开发者自荐职责；[审阅流程](https://manual.sspai.com/guides/review-procedure/)把社区发布与编辑采用分开。实际发送的是试用选题线索，并说明 AI 辅助整理和制作方关系，由编辑自主测试与评价。
5. [Smithery](https://smithery.ai/docs/build/publish)技术上支持现有 Streamable HTTP 接口，但账号和费用条件本轮没有验证完成；目录上架不等于独立引用。[PulseMCP 用例投稿](https://www.pulsemcp.com/use-cases/submit)现已关闭，服务器投稿页本轮无法核验恢复状态。本轮不付费购买目录或外链。

公开搜索未找到能确认的新独立报道；检索无结果不证明全网不存在。

标题：【工具自荐】帧选：免费的视频发布前检查清单，支持六平台与 MCP

我是帧选的开发者，想自荐一个面向视频创作者和独立开发者的小工具。

做好一条 App 演示或教程后，可以填写目标受众、时长、画幅、开头方式，以及素材权利和 AI 标识等情况，得到抖音、快手、小红书、B站、视频号和头条的发布准备清单与小测建议。信息不足时会保留缺项，不强行给平台排名。

工具免费，无需注册。网页版可在本机预览视频并读取时长和尺寸，也可直接填写草稿；不上传视频或表单文字，不识别画面或台词。支持导出文字报告，发布后手工记录实际表现。

目前建议基于公开来源和编辑规则，不预测爆款，也不保证审核通过。公开示例是合成输入，不是成功案例；视频号规则全文尚未完成核验，页面有明确标注。

欢迎独立试用，并指出建议不适用的场景。本次介绍由制作方使用 AI 助手协助整理、按线上功能复核。
