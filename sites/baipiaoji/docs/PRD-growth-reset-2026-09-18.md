# 先交付价值，再邀请注册（2026-09-18）

Owner 本轮明确要求大胆调整，并指出旧要求可能错误。本实验替代工具注册墙的旧约束；不把历史零读数当成注册墙导致流失的因果证据。

## 需求、假设与商业路径

- 输入：`data/reach.json`，生成于 2026-09-18，窗口 2026-08-21 至 2026-09-18。329 次带来源浏览，工具页 227（69.0%）；Grok 77、Kimi 20、Fireworks 18、Haiper 11、飞书妙记 11、Cline 6，六者合计 143（工具页的 63.0%）。判定页数组为空。事件 calc=6、sub_ok=4 是原始聚合，不能证明工具注册墙转化，不能当收入。
- 洞察：访问者先解决一个免费额度/替代品问题。现有入口把官网出站放在最前；站内下一步在多块说明之后。自建工具又在首次操作前索要邮箱。假设这两处摩擦降低了使用和后续访问。
- 商业路径：搜索落地 → 已有对比/计算工具 → 看见结果 → 自愿订阅或 webhook 监控。厂商广告仍在既有独立广告区；不把普通 go 点击说成联盟收入。

## 本次实现

1. 首页增加五个按任务进入的配置入口，中英同步。组装器支持白名单 URL 复现、无需邮箱的文本清单导出（附来源、日期、授权边界）、复制链接；移除初载 calc，商用筛选排除不可商用/未核实记录，记录 `/gate/stack-share/stack-builder`、`/gate/stack-export/stack-builder`。分享事件只表示操作意图，不证明外部传播。
2. 八个自建工具撤掉强制注册拦截；反复使用也免费。订阅不再是计算权限。六份 earn 作业包的服务端权限不在本实验内。
3. 对实际操作且触发 calc/audit 的用户，在工具后显示可关闭的自愿订阅表单；不弹窗、不滚走结果、不承诺未接通的邮件提醒。表单继续走原 `/api/subscribe`，新来源 `tool-soft:<slug>`。本地存储不可用时也能使用工具。
4. 固定六个高触达工具作为入口实验队列（两种语言），在答案之后、官网按钮之前放一块小型下一步导航。链接只到已有的相关对比、计算与免费/付费档说明；判定链接资格复用生成条件，无数据不造页。
5. 新点击/使用/曝光/订阅事件归到 `gate` 的 `/gate/soft-*`、`/gate/next/*` 路径，避免用导航点击抬高 `calc`。不记录输入值或邮箱到事件日志。
6. 定价页同步“无需注册”。已有付费服务、联盟归属和数据核实方式不变。

## 验收与读数

完整 build + verify-dist；浏览器验证匿名用户能操作、结果不被挡住、页面初载不出现订阅邀请，真实操作后才出现，关闭后不影响工具。六个入口中英链接全部存在。现有 earn 权限测试保持。

上线后 28 天窗口（以生产部署时间为准，计划复核 2026-10-16）：入口点击 / 有效曝光 ≥5%，且 ≥10 次下一步点击；至少两个不同工具产生真实使用；记录 soft-use、soft-view、soft-submit、soft-ok 和 D1 `src=tool-soft:*` 去自测订阅。新使用指标 t0=0（新埋点），旧 calc=6 只作背景，不直接同比。

少于 100 次有效入口曝光：样本不足，检查发现层并保留免费使用，不继续加表单。达到曝光而点击 <3%：撤或重写入口，不扩到全站。使用 ≥20 而订阅为 0：撤去提示或更换明确价值，不恢复强制墙来美化注册率。两次同时改动是方向性实验，不声称为随机 A/B 因果检验。

## 新工作约束

“旧实验失败”只否掉该受众、入口、时间窗下的旧实现；不等于该领域永远没有需求。允许低成本、有限队列、明确读数的获客实验。不得用程序生成页数、MCP 抓取、健康绿灯替代增长结果。


对标依据与 14 站投入优先级见根 `docs/growth-reset-2026-09-18.md`。方案实验目标为 28 天内 ≥20 次真实组装操作且 ≥5 次导出/复制操作；新事件旧值不可同比。
