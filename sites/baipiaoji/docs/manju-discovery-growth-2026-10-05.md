# 帧选 SEO / GEO 发现与转化更新

## 三轮收敛

1. 目标与用户：中文观众按题材找剧，创作者找当前有依据的选题；把相关访问引导到官方入口、收藏与选题导出。
2. 证据与约束：现有 414 条目录、200 条红果官方快照、13 条历史报告记录。没有搜索量或流量增幅证据，不创建空月份页、逐部薄内容页、虚构封面/评分/播放量。
3. 交付与验收：8 个有足够记录的题材落地页、选剧/数据问答指南、官方榜单剧名站内搜索直达、主页与片单互链、结构化数据和文字版；最终构建后的统计覆盖、本地浏览器与线上验收、实际变更 IndexNow。

## 发现路径

都市、奇幻、古风、恋爱、家庭、末世、年代、乡村各有独立 canonical 页面，最少 10 条现有目录记录。每页具有独立的选择建议、标签边界、所有本分类作品的资料出处、核查日期和后续动作。没有空分类占位，不把目录数当热度，也不按关键词笛卡尔积制造页面。

全站首页保留帧选目录入口，新增榜单/选题入口。目录里有普通可抓取题材链接；落地页链接到带实际筛选状态的片单、作品锚点、相关分类和创作参考。榜单新增稳定的“快照组 + 原榜名次”锚点；不在基础目录中的官方榜单作品进入站内搜索，直达正确可见榜单和行，不落回默认组。

新指南回答去哪看、AI 与漫剧的区别、热度与播放量口径、月份缺口、引用方法、收藏状态。FAQ 结构化内容与可见答案相同；分类 CollectionPage/ItemList/BreadcrumbList 与实际记录一致。已有官方引用保持完整，新增 Markdown 资料与 llms 导航。未添加虚构 VideoObject、评分、版权许可或平台合作关系，也不保证 FAQ 富结果或 AI 引用。

## 商业与衡量

免费层为可追溯选片、收藏、按条件生成/导出选题参考。潜在付费对象为创作者与发行工作室；专题物料合作和趋势跟踪目前仅收意向，无新支付、广告支出、自动消息或收费排名。沿用现有账户入口，账户不等于片单云同步。

沿用固定事件 manju_open、save、share、topic_complete、topic_export、inquiry_ok，以公开 page path 区分分类落地。默认统计保留已有 opt-out、QA/DNT/GPC 和私密页排除；搜索词、收藏内容和询价文本不进分析参数。点击、收藏、导出、询价均不是收入。上线后按同长窗口观察搜索曝光/点击、落地后的官方入口点击、收藏、选题完成和真实合作意向；低曝光先解决发现问题，有访问无动作再检查落地匹配，不因页面发布就宣称增长。

## 两轮自检

第一轮检查薄内容与误导：分类页具有真实作品、独立选择建议和来源；不生造搜索量、AI 制作认证、9 月榜或版权许可。
第二轮检查流量断点：站内搜索去重器必须保留榜单锚点，非默认榜单必须自动展开，分类 CTA 必须落到正确筛选；所有公开新路由进 sitemap、统计覆盖与实际变更清单，文字版和页面来源保持一致。

## 本地验收

3354 个 HTML 页面内容检查零错误，3349 个规范路由通过校验；manju 静态/单元/浏览器、全站搜索、agent-watch 回归均通过。浏览器覆盖了“首页搜新漫剧 → 非默认红果漫剧榜的可见行”和“分类页 → 正确筛选 → 可收藏”两条实际路径。所有生成器之后完成 GA4 coverage 写入与复查；新页面与既有入口一起参与部署门禁。上线、索引接收、实际收录与引流效果分别验证，不把测试请求算新增用户。
