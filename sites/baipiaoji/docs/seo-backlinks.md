# 外链策略：怎么被别人收录，以及怎么挂别人

先回答两个直接问题：

- **本站能挂外链到别的网站吗？** 能。已内置友情链接位（`data/links.json`），全部自动加 `nofollow`。
- **本站能被别的工具站收录吗？** 能，而且这是新站最重要的冷启动手段。下面是提交清单。

---

## 一、为什么外链对这个站特别关键

新域名（baipiaoji.com 于 2026-07 注册）在搜索引擎眼里没有任何信任基础。搜索引擎判断"这个站值不值得给排名"，很大程度看**有多少别的站愿意链接你**。

方向要分清：

| 方向 | 对 SEO 的作用 | 该怎么做 |
|---|---|---|
| **别人链向你**（反向链接 / backlink） | ⭐ 决定性正面作用 | 主动提交，越多高质量站收录越好 |
| **你链向别人**（友情链接 / 出站） | 中性偏负面（权重外流） | 少量、精准、加 `nofollow` |

一句话：**收外链要贪，给外链要抠。**

## 三、挂别人的友情链接（谨慎做）

### 怎么加

编辑 `data/links.json`：

```json
[
  { "name": "对方站名", "url": "https://example.com", "desc": "一句话介绍", "enabled": true }
]
```

`enabled: false` 的条目不会渲染。推送后 CI 自动部署，页脚即显示。

### 交换前的筛选标准（不合格就别换）

1. **主题相关**：AI 工具、效率工具、开发者资源类才换。什么行业都挂的"友链农场"直接拒绝。
2. **对方站是否正常收录**：在搜索引擎搜对方域名，搜不到说明可能被惩罚过，别沾。
3. **对方友链数量**：一个页面挂几十上百条友链的，权重稀释到几乎为零，没意义。
4. **对方是否给你 dofollow**：如果对方也给你加 `nofollow`，这次交换对双方 SEO 都无意义，只剩导流价值——那就看对方流量值不值得。

### 为什么我们给出去的链接都是 nofollow

`rel="nofollow"` 告诉搜索引擎"我链接它，但不为它背书"。友链对象是不可控的第三方——今天正规，明天可能变成垃圾站或被黑，届时你的站会被连累。加 nofollow 既保住了导流合作，又不承担对方的风险。

如果遇到真正优质、长期信任的伙伴站，可以手动去掉那一条的 nofollow（改 `scripts/build.mjs` 里的 `friendLinksHtml`），但这应该是例外而非默认。

## 四、比外链更重要的一件事

外链是加速器，不是发动机。这个站真正的护城河是**内容本身的独特性**：

- 72 个工具、9 大场景，每条都标注核实日期
- 每日自动巡检，数据比人工维护的博客文章新鲜
- 只收录真有免费额度的工具，不做大而全

搜索引擎现在越来越看重"这个页面是不是提供了别处没有的信息"。与其花大力气刷外链，不如**保持数据准确、持续补充新工具**——当用户搜「XX 免费额度怎么领」能搜到你且内容确实有用，排名自然会来。

## 五、互补导流：让别人有动机主动引用我们（2026-08-02 新增，已上线）

前面几节都是「求收录」——要人工注册账号提交。这一节反过来：**造出别人引用我们比不引用更划算的资产**。三件已上线：

### 1. 开放数据 + 署名许可（引用磁铁）

`https://baipiaoji.com/limits.json`（机器可读）与 `/limits.md`：11 条**逐条核实到官方来源**的额度数据，
以 **CC BY 4.0** 开放转载（含商用），条件是注明「白嫖计」并回链。

为什么有人会用：这个生态里最缺的就是**有来源的数字**——
- guide 农场（atlascloud/costbench 等）互相抄且数字打架，引用我们等于免费获得可追责的来源
- **GitHub awesome 清单是最对口的互补方**：`cheahjs/free-llm-api-resources`（活跃、5 天内有更新）、
  `mnfst/awesome-free-llm-apis`、`open-free-llm-api/awesome-freellm-apis`——社区驱动、接受 PR、被 dev.to 反复推荐。
  它们收录的正是我们 api 类目核实过的那批（Groq/Cloudflare/NVIDIA/SiliconFlow…）
- AI 搜索引擎：llms.txt 已声明该数据可引用

### 2. 核实徽章（工具方回链飞轮）

每个已核实的工具都有 `https://baipiaoji.com/badge/<slug>.svg`（154 个，随构建生成，日期自动更新），
工具页新增折叠区「是这个工具的团队？」给出嵌入代码。
逻辑：**工具方拿第三方核实背书，我们拿官网/README 的外链**——这是导航站被验证过的经典飞轮（Futurepedia 等都靠它）。

### 3. 数据授权声明进 llms.txt

AI 引擎抓取时直接看到「此数据可引用、如何署名」。
