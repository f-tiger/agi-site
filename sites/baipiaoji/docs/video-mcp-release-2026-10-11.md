## Product and distribution

Free audience: Chinese video creators, App developers, AI drama viewers, and their MCP-capable assistants. The service exposes `evaluate_video_publish`, `get_video_platform_rules`, and `search_manju` through `https://baipiaoji.com/api/video-mcp` (Streamable HTTP). No account or API key is required. This release adds no paid service or commission contract.

Installation and limits live at `https://baipiaoji.com/manju/video-fit#mcp`. The existing public page, Markdown, JSON, llms.txt and repository README link the tool and its official Registry query. A compact catalogue is generated from the same published data, with official/source/search entry labels and dated metric provenance. The existing daily content deployment refreshes it; there is no second crawler or new scheduled job.

Website input stays in the browser. Optional MCP calls transmit chosen structured declarations or search terms to the server. The MCP endpoint accepts no files, media URLs or private scripts, fetches no caller-supplied URLs, and does not persist inputs/reports or write analytics events. For best-effort rate limiting, one worker instance retains short-lived IP digests and counters in memory for approximately one minute; this is not a distributed WAF or a durable usage ledger. Assistant conversation retention belongs to the client. The page retains existing GA4 controls and measurement; those pageviews are not MCP call counts. No claim of real MCP users can be derived from release probes.

## Independent challenges

The architecture audit found the existing public catalogue was about 19.7 MB because per-work metrics repeated entire cohort records. A separate compact generated asset removes that duplication for MCP. Existing registered services cover free-tier discovery, Task Loop and startup research, so a separate video identity describes distinct callable functionality.

The independent reviewer also required protocol negotiation, notification/body/origin handling, bounded output, evidence dates, no media fetches, fail-closed argument validation, no fabricated zero metrics, and truthful Registry wording. The independent review caught explicit null arguments being treated as empty input, missing rate limiting and two broken documentation anchors; all were corrected before release. Local protocol/schema and registry tests, the official MCP SDK 1.32.1 connection/calls, the existing browser privacy/responsive checks, static verification, canonical checks and final GA4 coverage passed. The compact 662-record MCP catalogue is about 808 KB. Actual release outcomes are recorded by the deployment run and Registry receipt artifacts; configuration alone is not evidence of successful publication.
