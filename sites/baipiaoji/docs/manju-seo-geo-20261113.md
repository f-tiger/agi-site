# 帧选 SEO / GEO：可遍历目录与可引用资料

日期：2026-11-13。范围：改善现有帧选，不扩张未经核实的作品详情或付费产品。

## 问题与依据

线上首页未压缩 HTML 为 6,840,315 字节，服务端一次输出 1,511 张卡片，再用 JavaScript 隐藏至 24 张；作品页重复携带全目录的编号、名称和链接，抽查页为 216,524 字节。目录的翻页按钮没有可抓取的链接。用户明确要求 SEO / GEO 优化；之前的访问上涨混有自动流量，不作为需求量或营收证据。

2026-11-13 检索“红果 漫剧 AI短剧 热度 排行榜 官方 观看入口”，结果混有原站、资料聚合和自称官方的其他域名。需要解决的是准确找剧、辨别官方入口、理解热度日期和单位。原站 https://hongguoduanju.com/rank/hot-drama 说明综合热度基于观看与互动，不等于播放次数。Google 的 AI 搜索说明仍要求可索引、可显示摘要的有用页面，无特殊 AI 标记要求：https://developers.google.com/search/docs/appearance/ai-features 。

## 产品与实现

- 首页和目录分页在 HTML 中直接提供每页 24 条完整作品卡片、普通上下页链接；每页独立 canonical、标题和仅对应本页的 ItemList。搜索、收藏和旧作品锚点仍覆盖完整目录。
- 公共目录索引移为可缓存静态资源。交互按需读取同一套公开分页 HTML，仅挂载当前结果；不向搜索服务发送本机收藏或搜索原文，不向机器人提供不同内容。
- 作品及指南给出可直接引用的事实摘要、来源、观察日期和引用边界；HTML / JSON / Markdown 同源生成。补足网站实体关系，修正过时的问题标题和含糊的主标题，不添加虚构评分、演员、播放量或更新日期。
- 保留现有 robots、隐私排除、GA4、可访问性和权利说明。按现有发布机制更新 sitemap / llms 文档 / IndexNow，不新增定时任务。

## 验收与测量

所有目录记录在无 JavaScript 的分页中恰好出现一次、沿链接可达，分页 schema 与可见列表一致。首页 HTML < 250 KB；抽查作品页 < 80 KB；交互 DOM 同时最多 24 张卡片。完整搜索、翻页重载、旧锚点、跨页收藏/分享/导出、云片单、加载失败恢复、移动端和统计隐私必须通过回归。

商业意义是减少找剧阻力，观察有来源的官方入口点击、保存和后续回访；不将爬虫请求、PV、外跳直接当成观影或收入。发布后验证实时 canonical、sitemap、实体与分页响应、分析覆盖及 IndexNow 回执；索引/排名/AI 引用需要后续实际数据，不能用本地检查或提交成功代替。

## 两轮自检

假设检查：第三方分类不是制作审计；热度不是播放量；新页面只拆分现有目录，不制造新作品事实。失败检查：索引或分页加载失败时保留静态阅读路径，不清除收藏；异步请求不能覆盖新搜索；旧链接保持可用；部署绑定已验证的主分支版本。

## 本地验证记录

首页 HTML 为 128,982 字节，样例作品页为 13,517 字节（未压缩；生产分析脚本注入会略增）。共享搜索索引独立为 1,052,164 字节，gzip 约 108 KB，只加载一次并可缓存；这不是整页传输量下降 98% 的声明。63 页覆盖全部 1,511 条记录，DOM 同时最多 24 张卡片。

构建、canonical/sitemap、来源和跨格式一致性、自动同步、观看入口分类、搜索补查、收藏 SQLite、观看进度、lastmod、IndexNow URL 计划检查通过。Chromium 已验证搜索与输入法、移动端、分享隐私、跨设备片单，以及分页失败/重试/版本变化/请求竞争。浏览器全部使用本地请求拦截，不把测试事件计为真实用户或转化。

发布结果和提交回执将在交付时单独核对；本地测试不证明搜索收录、排名提升或 GA4 后台事件入库。
