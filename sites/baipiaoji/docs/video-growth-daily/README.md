# 帧选每日增长推进

2026-10-12。用户要求构建每天任务，推进 AI 视频站点成功。本文件定义执行职责；真实排期与启用状态以托管自动任务回执为准。

目标是增加有证据的任务使用、复用与独立引用，并逐步验证商业价值。中国市场，通用视频创作者优先；观众找剧与创作者工具分别衡量。任务先完成三轮目标、约束和验收优化，再做两轮审视；独立评审与自检分别标明。

## 每轮执行

1. 通过当前 GitHub main 恢复仓库规则、本文件、[状态](state.json)、[营销方案](../video-marketing-expansion-2026-10-11.md)、[计量清单](../video-marketing-kit/MEASUREMENT.md)与当前未完成材料；不依赖上次临时目录。读取相关开放 PR、部署运行与前轮成果，避免同目标重复施工。
2. 读取现有采集状态和聚合数据。来源文件与生成时间不变时，不将再次读取记为新观察。必要的 GA4/GSC 分项通过已连接 Windsor 先发现字段与账户再读取，不重做全舰队报表。直接读取 reach 每轮最多一次，不加随机参数绕小时缓存；403、权限失败、延迟均记录未知。
3. 按故障、计量缺口、真实体验摩擦、内容和分发的顺序选择一项最小动作。已经被其他任务完成的事项，验证后关闭；无人访问不是增加功能的依据。
4. 有执行环境及现有写权限时实施、验收并完成授权发布。环境、权限或外部分发条件不足时，保留可审阅的定位或补丁，明确未实施/未上线；不假装完成。不同项目和正在进行的任务保持原样。
5. 有实质进展才更新状态并提交，不为每日打卡制造代码提交。私有经营报告保留数据与判断，公开状态只保存工作对象、来源版本、验证链接和下一步。日报简要说明实际完成、关键数据、阻塞和下一行动。

| 优先级 | 行动 | 完成标准 |

| P1 | 每日 reach 导出保存帧选聚合及口径 | 缺失保留 null；真实时间窗；下一次原有日任务读回，不增 cron |
| P1 | 工具曝光、实质编辑及报告状态准确计量 | 目录与工具分开、示例和空输入不充有效任务、隐私排除通过 |
| P1 | 为实际启用渠道登记固定归因值 | 合法值可识别、未知值仍过滤；不能把拟议链接称已经归因 |
| P2 | 完成第一条通用教程、再做 App 教程 | 已核实演示、连续画面、字幕/音轨/解码；成片、平台发布分别验收 |
| P2 | 将可复算榜单观察转为适合读者引用的资产 | 沿用固定历史底稿，来源与统计可复算；无需每天扩写同类报告 |

持续只保留一项主实验。最高优先项因同一环境或权限阻塞无法推进时，保留一次可复核定位，转做一项不依赖该阻塞的已有工作，不反复生成相同补丁。没有新证据或分发条件时保留现状，并报告具体阻塞和复核点，不重复生成计划和同类草稿。可变行动状态由 [state.json](state.json) 保存；每轮先重新核实，不能机械执行旧缺口。

## 计量与周复盘

GA4、GSC、D1 各自保留日期、时区、事件定义和处理延迟，不混算分子分母。滚动累计差额不是日新增，重复读取不能累加。官方点击不是播放或佣金；热度不是播放量；报告渲染不是成功发布；MCP 登记、爬虫访问和自有资料不等于第三方采用。

以状态中的复盘日期为锚点：首个观察窗为北京时间 2026-10-13 至 19 日，2026-10-20 首次复盘；以后按七日推进。各数据源仍使用自身完整日期和时区，边界不同分别标明。到期即使数据缺失也总结已执行工作、阻塞和证据不足，不无限等待。复盘决定继续、调整或暂停某项实验；暂停实验不自动停掉本任务。首次小样本验证为五位创作者各一次真实任务，三位能指出具体帮助、两位在自然发生的下一任务自愿复用，作为继续投入的操作门槛，不是统计证明。样本不足或没有再次发布机会记待观察。不能创造访谈、账户或点击达标。

连续一周无真实分发，先说明缺少的渠道、权限或素材条件，不以反复改站代替分发，也不由低曝光判产品失败。商业价值依赖真实付款或协议结算，不能从出站点击推算。

## 发布与数据边界

用户已授权的站内维护、测试、文档、GitHub 提交和验收后部署继续执行。发布使用当前 main 和现有防回滚守卫，核实实际构建源；有同目标 PR 或任务在执行时先交接，不覆盖、不取消其他任务、不重复 dispatch。

站点公开页面改动沿用 SEO、GEO、GA4 和适用 IndexNow 门禁；只有实质变更 canonical 在成功部署后提交。纯文档提交不部署站点。MCP 正确性继续维护，登记不是每日重复动作。

不新增广告费、账号、付费 API 或服务，不签约、不发送新的邮件、私信、社交帖子或商务消息。已有少数派发送回执不代表接受，本任务不自动重复投稿。需要外部分发时准备具体可用材料并报告缺口。

公开仓库不保存用户输入、客户资料、媒体、分析账户标识或私人财务。任务私有报告与公开状态分开。未来运行没有当前执行环境时仍可读取公开仓库及已连接应用，但必须如实说明无法实施或验证的部分。
