# 联盟返利接入操作手册

目标：把站内 26 个工具的出站链接，从「官网直链」逐步换成「能带来收入的联盟链接」。

**先看懂一件事：两类返利的价值完全不同。**

| 类型 | 拿到的是 | 能否变成钱 | 代表 |
|---|---|---|---|
| **A 类：联盟佣金（affiliate）** | 真金白银的分成 | ✅ 可提现 | Canva、Gamma |
| **B 类：邀请返利（referral）** | 平台内积分 / 代金券 | ❌ 只能站内消费，不可提现 | 硅基流动、可灵、即梦 |

所以**收入靠 A 类，B 类只是省下自己的 AI 使用成本**。别把精力平均分配——先把 A 类的两个做完，它们决定这个站是否真能赚钱。

---

## 第一优先级：A 类现金佣金（先做这两个）

### 1. Gamma —— 最该先做的一个

理由：佣金比例高（30% 且持续分成）、申请门槛低、Gamma 在站内本就是"编辑推荐"位。

**步骤**
1. 打开 `https://gammaapp.partnerstack.com/?group=affiliates`
2. 填写表单：姓名、邮箱、受众类型（选网站/博客）、推广方式（填：中文 AI 工具福利导航站，baipiaoji.com）
3. 通过后在 PartnerStack 后台复制专属推广链接
4. 填入 `data/tools.json` 中 `slug: "gamma"` 那条的 `affiliate` 字段

**收益**：所有经你链接产生的付费，你拿 30%，无上限。

> 补充：Gamma 站内还有一个「邀请好友」入口（每邀 1 人得 200 积分，上限 2000）。那是 B 类，和联盟计划不冲突，可以自己另外用，但**填进网站的必须是联盟链接**。

### 2. Canva —— 用户基数最大（当前暂缓）

> **状态：暂不申请。** 先用 Gamma 跑通一遍完整流程（申请 → 审核 → 拿链接 → 上线 → 观察转化），确认这条路走得通、也确认佣金能实际到账，再决定要不要铺第二家。这样如果流程里有坑，只需要在一个计划上返工。

理由：Canva 是站内最大众化的工具，转化人群广。

**步骤**
1. 打开 `https://www.canva.com/affiliates`（即 Canvassador 计划，由 Impact 平台承接）
2. 提交网站地址 baipiaoji.com 与推广方式说明
3. 审核约 2–5 个工作日
4. 通过后在 Impact 后台取链接，填入 `slug: "canva"` 的 `affiliate` 字段

**收益**：按「成功转化为 Canva Pro 付费用户」计一次性佣金，30 天 Cookie 有效期。注意 **免费注册不计佣金**，所以站内文案要往"Pro 值不值"方向引导才有转化。

## 第二优先级：B 类邀请返利（顺手做，省成本）

这些拿到的是平台积分/代金券，**不能提现**，但能覆盖你自己测试 AI 工具的开销，且对用户是真实优惠（双方都得），放在站内不损害体验。

| 工具 | 怎么拿 | 双方能得到什么 |
|---|---|---|
| **硅基流动** | 控制台内「邀请」入口，可生成邀请码/链接/二维码 | 双方各得 16 元代金券，**无上限**，180 天有效；需完成实名认证才能领 |
| **可灵 AI** | App / 网页个人中心的邀请入口 | 新用户首月创作积分加成，邀请人得灵感值 |
| **即梦 AI**、**LiblibAI** | 各自 App 内「邀请好友」入口 | 双方得积分/点数 |

**步骤统一**：登录 → 个人中心找「邀请好友 / 推荐官」→ 复制链接 → 填对应工具的 `affiliate` 字段。

## 暂时不用花时间的

- **Runway、Recraft、Windsurf**：截至 2026 年中未见公开的对外联盟计划（Runway 只有站内双向邀请）。留空即可，日后官网出计划再补。
- **DeepSeek、Kimi、通义、元宝、讯飞星火、智谱、Google AI Studio、Cloudflare** 等：本身就是免费产品或大厂自营，没有分佣机制。这些是站点的**流量担当**（用户就是冲它们来的），不是收入担当，保持官网直链即可。
- **GitHub Copilot**：微软体系，个人站长拿不到分佣，保持直链。

## 拿到链接后怎么填（唯一需要动的地方）

编辑 `data/tools.json`，找到对应工具那条，只改 `affiliate` 一个字段：

```json
{
  "slug": "gamma",
  "name": "Gamma",
  "affiliate": "https://gamma.app/?via=你的推广ID",   // ← 只改这里
  ...
}
```

**规则**：
- `affiliate` 非空时，站内「领福利」按钮自动指向它；留空则用官网链接并自动附加 `utm_source=baipiaoji`。构建脚本已处理，无需改代码。
- 出站链接已统一带 `rel="noopener nofollow"`，符合搜索引擎对付费链接的要求。

**上线验证**（改完推送即可，CI 全自动）：
1. `git add data/tools.json && git commit -m "feat: add gamma affiliate link" && git push`
2. 等约 30 秒，GitHub Actions 自动构建并部署
3. 打开 https://baipiaoji.com ，点对应工具的「领福利」，确认跳转地址带上了你的推广 ID

## 合规与信任（别跳过）

站点的核心竞争力是"可信"，所以联盟链接必须**明示**，页脚已内置一行广告披露说明。这不是负担——用户看到"我们会获得佣金但不影响推荐"，反而比藏着掖着更容易信任你。

另外两条底线：
- **不要为了佣金调整推荐顺序**。有佣金的工具如果本身福利不如别人，就该排后面。一旦用户发现推荐失真，这个站的差异化就没了。
- **付费推广位（首页 sponsor）要标注"推荐"字样**，与自然收录区分开。

### PartnerStack 账号设置要点

1. **用同一个邮箱注册**（申请时填的那个），否则账号关联不上申请，看不到审核状态。
2. **收款方式优先选 PayPal**：Stripe 不支持中国大陆个人收款账户，PayPal 对国内个人开放且可提现到银行卡。在佣金产生前就设好，别等到有钱了才发现收不了。
3. **Marketplace 的「up to 2 programs」名额不必凑满**：只接站内已收录、且真会推荐的工具。为凑名额去推没收录过的工具，就得在站内硬塞条目，那正好毁掉「只做福利、每条都核实」的差异化——名额空着没有损失，塞错才是。
