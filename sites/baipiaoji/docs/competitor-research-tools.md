## 一、直接竞对画像

### yangmao.ai —— 中文侧的近同构对手（最值得研究）

结构几乎和我们一一对应，甚至更聚焦：

| 他们有 | 对应我们 | 差距 |
|---|---|---|
| `/zh/providers/<name>/free-tier/`（免费额度、注册送、使用限制） | `/tools/<slug>`（limits 字段） | 他们**每个厂商都有额度数字**；我们只核实了 4 条 |
| `/zh/top-free-llm-apis-2026/`（Top 30 免费 LLM API 真实额度对比） | `/c/api`（无对比表） | **他们有枢纽页，我们没有** ← 本轮补 |
| 「每日自动抓取政策，排名每周重算」 | 每日链接巡检 | 他们抓的是**政策内容**，我们只巡检可达性 |
| 变更邮件提醒（额度/价格/大陆可用性变化时通知） | 订阅框（未接邮件服务） | 概念相同，他们已跑通 |
| 双语 /zh/ /en/ | 双语 / /en/ | 打平 |
| 中国大陆可用性标注 | 「国内直连」标签 | 打平 |

### costbench.com / pricepertoken.com —— 英文侧的同款

- costbench：`/software/llm-api-providers/<name>/free-plan/`，标题公式 **"Is X Free? Free Tier Limits & Upgrade Triggers"**——正是我们 FAQ 第一问+第六问的页面化
- pricepertoken：`/endpoints/<provider>/free`，**"Free Models, Credits & Limits"**——按厂商列免费模型清单

这两家验证了：**「免费到哪为止」这个页面模式在英文侧同样是赢家**——而我们的英文版恰好正在起量。

## 二、判断：抄什么、不抄什么

**抄（本轮就做）**：
1. **枢纽对比页的思路**——但不做新 URL，直接把「已核实额度上限」表加进现有分类页（`/c/api` 等）。
   理由：新 URL 模式有 doorway 风险，而分类页本来就该更厚；且这正是 GA4 里被访问的页面。
2. 标题里回答问题的写法（costbench 的 "Is X Free?"）——我们的 FAQ 已覆盖，不必改 URL。

**不抄（想清楚了的）**：
1. **「每日自动抓取额度政策」**。这是他们的核心引擎，也是他们的软肋：自动转述的数字没有人背书。
   我们的差异化恰恰是**只写核实过的、写明来源、缺席即信息**——4 条真数字 + 明说「其余没查到官方来源」，
   比 46 家自动抓的数字更可信。跟进自动抓取等于放弃唯一打不过我们的点。
2. 厂商 free-tier 独立子页——等 limits 填过 20 条再考虑，现在做就是 154 个空壳。

**竞对没有而我们有的（护城河，别丢）**：
- 每日**链接巡检**核实日期（他们没有可达性核验）
- 痛点→方案→工具的内容阶梯 + 赚钱作业层（他们纯工具向）
- 视频/图像/办公等全品类覆盖（他们只做 LLM API 厂商）——GA4 里以色列用户连逛 5 个视频工具页，验证这个宽度有用

## 三、增长形状的最新读数（2026-08-01）

   `/c/api` 立刻获得 3 行真数字（cloudflare-workers-ai / zhipu-glm / nvidia-nim），`/c/office` 获得 Gamma 一行。中英同步。

# 第二轮补充（2026-08-02）：视频类目的竞对格局

GA4 指到 video 类目后，按同样方法反查「视频工具+免费额度」的 SERP：

## 竞对画像：guide 农场，数字无锚点

- **英文侧被 atlascloud.ai 一家吃掉**：「kling/pixverse + free credits」的前 8 个结果里它占 5 席，
  打法是**每个工具铺一组页**（Is X Free? / X Pricing / X Referral Code / X 免费指南）。
- **它们的共同软肋和 LLM API 侧一模一样：数字互相打架且无官方出处**。
  「Kling 66 积分」有说每天有说每月；全部第三方转述。

## 按我们的规则核实的结果

| 工具 | 结论 |
|---|---|
| **kling** | ✅ 填入：每日登录 66 灵感值 ≈ 6 个 5 秒视频——快手**官方发布的会员方案**，量子位等多家中文媒体 + 英文来源交叉一致，且解决了英文博客「每天 vs 每月」的分歧（官方口径：每日登录赠送） |
| pixverse | ❌ 不填：「60/天、0:00 UTC 重置、约 35 积分一个视频」四家博客口径一致，**但零官方锚点**——与 siliconflow 同一待遇 |
| vidu / qingying | ❌ 不填：连一致的第三方口径都没有 |

**这再次验证了差异化**：竞对在这些词上的供给是「量大、快、无锚点」；我们的供给是「少、但每条都能追责」。
视频分类页的对比表从本轮起有了第一行（kling），表头如实写 1/15。

## 下一步

- pixverse 的数字大概率是对的，差的只是官方页——人工开一次 pixverse.ai 定价页即可转正
- atlascloud 的「Referral Code 页」是它独有的内容类型（邀请码/返利码聚合）——**不跟**：
  邀请码时效性极强，过期即失信，与「每条核实」根本冲突

说明这类词上官方页强势时，农场吃的是长尾变体。我们的位置还是那一个：**带核实日期的中文/双语答案**。

## 本轮核实结果（limits 7 → 11）

| 工具 | 结论 |
|---|---|
| **elevenlabs** | ✅ 最干净的一条：官方定价页一手来源，10,000 credits/月 ≈ 10 分钟 TTS；**关键坑是免费档无商用权、需署名**——比额度本身更容易踩 |
| **poe** | ✅ nvidia-nim 式诚实条目：官方 help 确认「每日积分、24h 重置」机制，但**不公布数额**；第三方 300–3000 打架，一概不采信，页面如实写「官方未公布」 |
| **qoder / codebuddy** | ✅ 填入试用与订阅结构（官方定价 + 多方报道印证）；正式免费档数额官方未公布，不写 |

## 本轮最重要的产出不是 limits，是一次纠错

**qoder 与 codebuddy 2025 年 9 月已转订阅制**（腾讯新闻、知乎多方报道），
而站内 `free` 字段还写着「个人版免费使用」——**这是过时信息，正在误导用户**。已改写为
「已转订阅制：新用户免费试用两周…试用后免费档功能有限」。

> 教训入档：链接巡检只能保证「网址活着」，保证不了「描述还对」。福利描述的时效性目前没有任何机制兜底，
> 全靠这类调研撞见。这是**已知缺口**——竞对 yangmao.ai 的「每日抓政策」解决的正是这个问题，
> 我们拒绝自动抓取，就必须接受人工巡的成本，或者做「描述超过 N 天未复核就降级显示」的机制（待议）。

# 第四轮补充（2026-08-02 深夜）：点击-额度交叉分析，limits 11 → 16

**先记一件事故：Supermetrics 试用已到期**（"Unable to find a valid subscription"），GA4 的会话级拉数通道断了。
本轮分析基于当日早间拉全的 07-26→08-02 数据。**在 GA4 服务账号 secrets 配好之前，站点处于数据盲飞状态**——
这把「配 secrets」从待办升级为最高优先级的人工动作。

## 点击 × limits 覆盖的交叉表（本轮的核心发现）

| 有无核实数字 | 会话 | 出站点击 | 点击率 |
|---|---|---|---|
| 页面**有**具体额度数字（qoder/fireworks/elevenlabs/kling/groq） | 10 | 6 | 60% |
| 页面**无**数字（deepl/wps-ai/qwen-chat/pixverse/vidu/qingying，及 poe「官方未公布」） | 7 | 0 | **0%** |

之前的「64% 点击率」是平均数；拆开看，**转化全部来自有数字的页面**。
CRO 框架（cro skill）确认了同一结论：specificity（数字）是价值主张的第一杠杆；
出站 CTA 文案已是强动词（「直达官网领取」），无需改。
**结论：流量正在敲门而我们给不出数字的页面，就是流失的全部来源。本轮全力补数字。**

## 核实结果：5 填 1 拒（判例沿用）

| 工具 | 结论 |
|---|---|
| **deepl** | ✅ API Free 每月 50 万字符——官方开发者文档明示（满互联网的「网页版 5000 字符」依旧无官方出处，只写「有上限、官方未公布数字」） |
| **wps-ai** | ✅ 免费版每日约 10 次 AI 额度——wps.cn 官方文章口径「10 次左右」，保留官方的模糊度，不擅自写成精确数 |
| **pixverse** | ✅ 转正！第二轮拒绝过（第三方一致但零官方锚点），本轮在 pixverse.ai 官方博客拿到 30–60/天官方口径——按官方范围写，不采信第三方的「60/天」单值 |
| **qingying** | ✅ Kling 判例：官方发布口径（免费开放）+ 多家独立媒体交叉 + 2026 现况页复核（防 qoder 式过时）；会员 19 元/月去水印 |
| **vidu** | ✅ nvidia-nim 式诚实条目：官方页同时出现 40/80 两种月度积分口径→拒绝取单一数字，写机制（月度积分 + 错峰模式不耗积分） |
| **qwen-chat** | ❌ 不填：官方明说「权益经常调整、以 App 内为准」，无公开数字——siliconflow 同判例 |

video 分类对比表由 1 行涨到 4 行（kling/pixverse/vidu/qingying），writing/office 分类首次有行。
