## 转化数据边界

GSC Wizard 返回 GA4 `notConfigured/no_scope`，当前连接不能读取注册、使用或收入转化。

站内 reach 快照是 08-30—09-27 的 396 条外部来源客户端 PV；其中 Google 177、Bing 155。它与 GSC 在引擎、时间窗口、日界、度量单位上不同。客户端 ref 可自报、重复加载可多次记数、历史数据无法可靠去重或识别自动化，因此不是“396 个真人”。已将 API 定义更正为事件数并保留旧字段兼容。

同一快照的 go=117、star=10、calc=9、sheet_dl=5 只用于操作计数；sub_ok=4 是邮箱订阅，不是新的免费账户注册。订单库存/状态多数为 lifetime，不是本窗获客转化。未得到真实注册、激活、留存或收入率；不得用上述不同分母相除声称漏斗成立。

新增客户端 QA 排除：`__ci`、`__probe`、`qa=1` 不发 PV 与 bpjEv。它减少未来自测污染，不追溯清洗历史，也不证明其余全部是真人。
