# BPJ：存量搜索入口与分层转化度量

## 优化后的执行指令

基于 GSC 点击率下降分析，改进英文首页额度查询路径；只在 Fireworks、PixVerse 两个已有曝光的英文工具页测试搜索摘要，保持其标题与正文不变，Suno、Kling 为非随机观察对照。建立机器可读实验清单、基线、停止条件与验收；复用现有 reach 小时缓存和每日导出，把使用事件、样例操作、真实账户创建分别量出来。验证后一次发布 BPJ，不改其他站点，不新增付费服务或营销外发。

## 三门与需求证据

- 数据：GSC Web 2026-08-28—09-24：613 曝光、3 点击，英文首页 28/1；Fireworks 42/0、PixVerse 27/0、Suno 31/0、Kling 18/0（曝光/点击；合并旧 .html 变体）。
- 需求：前窗可见搜索有 `pixverse daily credits`；免费额度、用完后的计费与发布权限是现有页面已经回答的具体任务。不是把泛词排名当需求证明。
- 商业：让查询者进入现有工具、保存清单与免费账户，再观察实际使用；付费云项目仍是后续选择，不把官网跳转当联盟营收。
- 限制：基线点击太少，不足以测量小幅 CTR 提升；page×country×device API 只返回 6 次曝光，远少于 page 汇总，保留原始结果 `search-experiment-baseline-20260927.json`，不得用它代表完整市场结构。前期 55 次点击中 49 次发生于 7/31—8/4，不能当平稳基线。

## 实施与实验边界

1. `/en/` 在既有自研工具入口后新增三个额度查询入口：API、视频、商用条件；复用原有样式、真实链接和 `home` 区块事件。中文首页不新增此英文实验区块。首页变化单独观察，不并入工具页摘要实验的因果判断。
2. 两个工具页只覆盖英文 meta/OG description，语义对应已有正文，不新增额度数字，不把历史核实日期刷成今天。Google 可能自行改写摘要，不能保证搜索展示采用我们的文本。
3. `data/search-experiment.json` 固定实验/观察对照、旧标题/摘要、日期、样本门槛。对照关键词与排名不同，因此不是随机 A/B，也不宣称统计显著。

观察窗口：2026-09-28—10-25（GSC Pacific 日界），10-29 后读取完整数据。按页报告点击/曝光/CTR、查询覆盖率和排名构成；查询×国家×设备×排名分层只在数据足够且口径可比时做。每组少于 500 曝光或总计少于 10 点击，结果为不确定、不扩页。这是投入判定门，不是显著性阈值。即使超过门槛也只能提出后续验证，不能证明摘要导致提升。

停止条件：事实错误、抓取/索引/路由技术故障立即修复并标记中断；实验期间 cohort 元数据或正文被其他更新改变，登记污染；期满不自动延期或扩页。事实纠错优先于实验冻结，不因控制组身份保留已知错误。

## 度量契约

`/api/reach.conversion_stages` 使用完整 UTC 日 `[start,end_exclusive)`；原 reach 字段继续保持历史契约，不混合分母。

| 阶段 | 真值/口径 | 不代表什么 |
|---|---|---|
| Google 搜索点击 | GSC，Pacific 日界、等待数据完整 | 站内 PV、独立访客、AI 引用次数 |
| PDF/图片/报价结果 | 现有成功操作事件；own/demo 分开；图片可能部分批次成功 | 唯一用户、整个批次全成功 |
| 下载 | 成功生成结果后的下载动作 | 文件已落盘、付款 |
| 视频 | 成功导出视频/批次；每个批次记一次动作 | 成片数量、唯一用户 |
| 其他 calc | 未归入上述已审查成功契约的操作，单列 | 所有工具完成任务 |
| 免费注册 | 数据库中窗口内创建且 qa=0 的尚存账户 | 留邮箱订阅、按钮点击、唯一真人 |
| 新账户已验证 | 上述注册 cohort 当前的邮箱验证状态 | 窗口内验证事件、渠道归因 |

账号删除后不在存量统计中；历史未标 QA 的自动访问仍可能存在。无访客 ID、Cookie、指纹或新 PII；不把这些独立计数相除报获客转化率。源表/查询失败返回 null，并使快照 partial，不能伪装成 0。账户统计不读取邮箱、用户名或密码字段，不修改认证逻辑。

报价计算生成的结果可以包含“资料不全/不可比较”等判定，算分析操作，不算合格报价或采购成功。分层统计反映实际动作，不承诺任务或商业结果成功。

成本：已有 reach 每小时缓存上增加两条聚合查询，其中 hits 走已有 `hits_events` 部分索引，另一条只聚合小规模账户表并按主键关联身份表；没有新 schedule、没有追加 hits 行、没有整表爬虫扫描。每日 reach-export 保留这个字段供复核。

## 验收与反证

- 生成产物测试限制为两页英文摘要覆盖；对照页标题/摘要保持原值，工具正文不因实验改变；中文覆盖为零。
- SQLite 真执行验证 CI/样例/own、完整日边界、未知事件、空表、读取失败、QA 账户排除，EXPLAIN 确认事件索引。
- 保留原账户、D1、站点 canonical、断链、JSON-LD 和双语门禁；移动端/桌面检查新增入口与埋点。
- 上线成功只证明交付和仪器可用，CTR/注册增长待观察。GSC 连接没有 GA4 scope，本次不据此声称 GA4 未安装或已打通用户级归因。

官方依据（2026-09-27）：https://developers.google.com/search/docs/appearance/snippet —— Google 主要从正文生成摘要，也可能采用描述；应针对关键页面写准确、独特描述，无展示保证。

本地验收：2,349 页结构/断链/JSON-LD/双语门禁全零错误；2,347 条 canonical 检查通过。逐文件比较 221 个英文工具页，仅两页 head 摘要变化，body 全部未变。390/1440 像素新增入口显示正常、无横向溢出，实际导航事件路径正确，QA 不上报；原中英账户浏览器生命周期测试通过。D1 索引与缓存回归通过，新增统计使用真实 SQLite 测试。生产验收由 workflow 的 `verify-search-experiment-live.mjs` 检查真实页面及统计字段；结果以对应 Actions run 为准。
