Before you pay: 60 seconds

Every version of this scam needs one thing: that you act now. So you only have to do one thing: take 60 seconds. Answer six questions in that minute. If any one of them is unanswered, do not pay. A genuine emergency is still genuine one minute later.

60

  • Have I ended the call or closed the chat?Hang up first, think second. "Don't hang up" is the reason to hang up.
  • Did I call back on a number already saved in my phone?Not the number that called. Not a number they read out. If there is no answer, call another family member.
  • Did they answer the code word?No code word yet? Make one — it takes two minutes.
  • Is this an account I have paid before?"Use this other account", "our usual one is frozen", "pay into the safe account" — a new account is a stop sign.
  • Has nobody asked me for a code, a password, or screen sharing?A verification code is the last lock your bank gives you. It is never read aloud — not to "support", not to "the police".
  • Have I told one other person?"Don't tell anyone" is part of the script. Saying it out loud ends half of these calls.
Pay only with all six ticked. Any box unticked means do not pay.

Why these six

ItemWhat it is for
Hang up, call back on a saved number, tell someoneBreaks the controlled channel and the isolation the script needs. Callback verification is the defence public safety agencies actually recommend
Code wordA voice and a face can be generated; a shared family memory cannot. See why "spot the fake" advice fails
New account, codes, screen sharingThe three routes around your bank's own controls. A verification code handed over defeats the protection it exists to provide
