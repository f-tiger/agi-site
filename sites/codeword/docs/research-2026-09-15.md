# Code Word 建站调研 · 2026-09-15(owner:「扩展几个适配欧洲、美国的站点」)

检索工具 WebSearch。**沙箱出网代理挡住了 ic3.gov、eur-lex.europa.eu、digital-strategy.ec.europa.eu 等域名**
(已实测,非偶发),因此:①页面一律给出一手来源链接供读者自行核对;②只写多家互不相关的具名专业来源
**逐字一致**的数字与日期;③核不到原始报告的分项统计一律不上页。这条限制写进了 `/about`。

## 一、为什么是这个方向(三门)
| 门 | 证据 |
|---|---|
| 数据门 | 主站 Bing 明细证明吃引用的是**判定/定义型**页面;本方向的三个问题全是判定型,且两条有**带日期的政府文件**可挂(FCC 2024-02-08、FTC 2024-04-01)。中文站识骗同题材已于同日上线,结构已验证 |
| 需求门 | 「AI voice scam」「is this call a scam」「family code word」是持续性高频消费者查询;更关键的是**现有答案质量差**——大量页面教人「听出机器音」,这条建议每代模型都更错一点 |
| 商业门 | 与识骗同构:不直接变现,是网络的信任入口与上游流量,向主站追踪器与 AI Act 台账分流。本站不设任何收费面,也刻意拒收安全产品联盟(见下) |

**刻意接受的代价**:英文反诈内容极度拥挤(政府站、银行、安全厂商、媒体)。本站唯一的位置是
**「判定 + 条款日期 + 不上传的工具 + 零推荐」**,尤其是那句「检测不是防线」的反常识判断。
判定线 11-15 / 12-31 结算这个赌注。

## 三、竞品格局
| 类别 | 代表 | 缺口 |
|---|---|---|
| 政府 | FTC consumer alerts、IC3 PSA、Europol | 权威、分散、按机构切分;没有「这条建议什么时候会失效」的判定层,也没有工具 |
| 银行与电信 | 各自的 fraud hub | 立场是自家客户与自家产品 |
| 安全厂商 | 防骗 App、身份保护订阅 | 卖方立场;内容常以恐惧驱动转化 |
| 媒体 | 案例报道 | 记住的是恐惧不是动作;统计常无出处 |
| 检测类创业公司 | 深伪检测 API/插件 | 与本站判定直接相反——我们认为消费者侧「检测」是错误的防线 |

**没有一家把「带日期法条 + 反常识判定 + 三个不上传的工具 + 零推荐」放在一起。**

## 四、由此定下的 v1
三页判定 + 三个工具 + 官方入口 + 关于。工具按**三个时刻**切:事前(暗号卡)、事中(60 秒六问)、
拿不准(12 问)。`/code-word` 有一条不可放松的技术红线:**该页不得有任何网络调用**,部署闸门强制。
**刻意不做**:深伪检测工具或评分、案例库、号码查询、任何付费服务收录、欧盟各国举报电话表
(泛欧消费者举报热线并不存在,编一个比不写更糟)。

## 五、第二批候选(未过三门,只登记)
- "Is this text from my bank real?" —— smishing 定义型,需求大,依据可用 FTC/FCC + 各行公开提示。
- "Can a deepfake of me be removed?" —— 美国州法(如 ELVIS Act)与 NO FAKES 类立法进展需重新核实,暂不做。
- "Do AI scam-detection apps work?" —— 与本站判定同源且更尖锐,但需要可核实的第三方评测,现无。
- "What the EU's 2 December 2026 marking rule changes for consumers" —— 日期已定,**建议作为 12-02 当周的
  时效页**,由主站 AI Act 台账供数,本站只写消费者侧影响。
