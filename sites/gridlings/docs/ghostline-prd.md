# GHOSTLINE — 第二款冲 CG 首页的游戏（薄 PRD，2026-09-06）

owner：「再根据 CG 的首页情况，再做一个有机会冲击首页的游戏」

## 一、三门证据
- **数据门**：Driving 是 CG 16 个一级分类之一，首页常驻区块；PolyTrack（Trackmania 式计时赛、幽灵车、
  排行榜、赛道编辑器）被媒体称为 2026 最强黑马并持续更新（2026-03 加实时多人）；Moto X3M 是 CG 最受欢迎
  游戏之一；Drift Hunter / Drift Boss / Rush Hour 常年在列。算法看玩家数 × 时长：计时赛的「再来一次」
  循环天然长时长。
- **需求门**：计时赛玩家的核心需求是「看见自己在哪丢了时间」（幽灵车 + 分段计时），这正是 AI 克隆能放大的：
  对手不是别人，是被你训练出来的模型。
- **商业门**：Driving 类 CG 分成 + 每 3 局一次 midgame 广告（类目标准）；hub 回链；与 SINGULARITY 不同分类，
  不自相残杀。

## 二、设计
- **核心循环**：自动油门 + 左右转向 + 刹车/漂移；程序生成的低多边形赛道（种子决定），检查点分段计时，终点结算。
- **AI 克隆（差异化）**：记录你最好一圈在每个赛道位置上的转向/刹车，克隆按这份策略驾驶并做局部优化
  （减少横向偏移、提高过弯速度）；每次你完赛它都重新训练。它以半透明幽灵车同场跑，分段处显示 +/-。
  克隆的成绩就是奖牌线：金 = 克隆最优 ×1.02，银 ×1.10，铜 ×1.25（数据驱动，不手填）。
- **内容**：Campaign 12 条种子赛道（长度与复杂度递增）；每日赛道（种子 = 日期）；随机赛道无限；
  6 辆车按奖牌数解锁；本地最佳与幽灵存档。
- **物理**：轨道坐标系（沿程 s、横向 d、相对航向），护栏 = 横向夹紧 + 速度惩罚；无物理引擎，稳定且可在 node
  里跑验证器。
- **Juice**：速度线、FOV 随速度、漂移烟与胎痕、检查点 +/- 飘字、终点彩带、引擎音随速度、胎响、音乐循环。
- **手机**：屏幕左右半区转向、右下刹车键；自动油门保证单手。
- **CG**：加载后 3-2-1 自动起跑（零交互 gameplayStart）；奖牌 happytime；每 3 局 midgame。
- **验收线**：同 SINGULARITY §六（两轮对标 + 手机轮 + 门禁轮）。数值门 `verify-ghostline.js`：12 条赛道克隆
  优化器都能完赛；朴素驾驶（只对中）能在铜牌 ×1.5 内完赛；最小转弯半径与限速匹配。

## 三、判定线
Basic Launch 结束：转化 ≥80%、D1 ≥10%、平均时长 ≥ 五款小游戏均值 ×3；<2 条达标记反面发现。
