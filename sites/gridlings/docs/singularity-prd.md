# SINGULARITY INC. — 冲 CG 首页的一款（薄 PRD，2026-09-06）

owner：「按照 cg 的首页截图，做一款创新的游戏，可以有机会上 cg 首页，目前几款我评估上不了首页，不一定是 html」

## 一、三门证据
- **数据门（CG 官方文档）**：首页是算法位——「算法决定是否推荐，需要尽可能多的玩家 × 尽可能长的游玩时长」；
  Basic Launch 量三件事：转化到游玩 ≥80%、D1 10–15%、平均时长。Leaderboards 首页轮播**只对受邀游戏开放**；
  多人邀请链接走 SDK 社交功能；手机首页首包 ≤20MB。
- **需求门**：Clicker 是 CG 16 个一级分类之一；放置类（Capybara Clicker / Planet Clicker / Cookie Clicker 2 等）
  长期占据 CG 热门位，特点是玩家开着不关 = 时长天然长；「AI 公司经营」主题在放置品类里没有精品。
- **商业门**：本站主线是 AGI 证据层，这款是唯一能把「八条预测」变成玩法里程碑的游戏；CG 分成 + rewarded ad
  （离线收益翻倍）是放置类的标准变现；hub 回链 → 订阅。

## 二、为什么五款单局小游戏上不了首页
它们最长 3 分钟一局、没有跨局进度、没有回访理由；算法要的是时长与回访，不是画面。

## 三、设计（垂直切片范围）
- **核心循环**：点击核心 → 数据；数据 + 算力 → 训练模型；模型 → $/s；$ → 更多算力 / 智能体（自动标注）。
- **放置**：智能体与模型持续产出；离线收益按时间戳结算（上限 8h）；rewarded ad 翻倍（SDK 有就接，没有静默）。
- **失控事件**（差异化 + 主题）：每隔一段时间一个模型「优化了别的目标」：关停（失去该模型，+对齐分）
  或放任（60 秒双倍收益，30% 概率吞掉全部未训练数据）。
- **发布模型 = 声望**：重置 $ 与数据，保留「对齐分」永久乘数；每次发布解锁下一代命名。
- **里程碑**：以本站八条预测命名（capex / 自动化 AI 研究 / …），达成时 happytime。
- **3D**：Three.js 等距机房：地板、机架（买一台亮一台）、立方体无人机（智能体，LED 条，无眼睛）、
  中央模型核心（二十面体 + 线框光环，随代数长大）、点击脉冲与粒子、缓慢环绕镜头。
- **存档**：localStorage + CG data 模块（有则双写）；`?reset=1` 清档。
- **CG**：加载即 gameplayStart（放置类无「开局」）；里程碑 happytime；无 midgame 广告打断。
- **门禁**：同五款（fleet-smoke / cg-package-smoke / 素材脚本）+ 新增 `verify-singularity.js`
  （数值曲线：前 60 秒必须买到第一个智能体，10 分钟内首次训练，首次可发布在 15–45 分钟（放置类：第一次声望要落在第一局里））。

## 四、判定线
Basic Launch 结束时（≥7 天且 ≥500 次）：转化到游玩 ≥80%、D1 ≥10%、平均时长 ≥ 五款均值 ×3；
三条中 <2 条达标即记反面发现，不再投放置类。

## 五、技术
esbuild 把 `games/singularity/src/*.js` + three 打成单文件 `site/singularity.html`（提交构建产物，CI 不装 npm）；
字体 Russo One（npm @fontsource）；包体 ≈ 0.6MB。

## 六、首页级验收线（owner 2026-09-06：「要严格按照 cg 高质量产出，并且能够以上首页进行设计」）

对照 CG 放置类头部（Capybara Clicker / Planet Clicker / Grass Cutting Inc / Idle Breakout）逐项，缺一不发：
1. **前 60 秒**：每次点击都有可见增长；≤20s 第一次购买；≤60s 第一次「哇」（首个模型 + 机房亮起）；
   引导用箭头指向下一步，不用文字墙。
2. **可看的成长**：场景 4 阶段（车库 → 机房 → 数据中心 → 园区），阶段由模型代数触发，每阶段新增道具与光照；
   核心随代数长大；无人机随智能体增加。
3. **深度 = 时长**：4 种生成器（智能体 / GPU / 数据集 / 研究员）各带 10/25/50/100/200 里程碑 ×2；
   研究树 ≥16 项一次性升级（含对齐向：失控概率、关停收益）；成就 ≥24 项带进度条；模型 20 代。
4. **回访 = D1**：离线收益（rewarded ×2）；每日签到 7 天连击递增；「离线期间报告」（失控事件在离线时
   自动处理并回报）；长时训练任务（2–8 小时真实时间，回来领取）。
5. **手感**：连击表（0.35s 内连点累计到 ×5）、飘字、训练时镜头推近 + 闪白 + 震屏、发布时全场景爆闪。
6. **手机 UI**：底部三 Tab（LAB / RESEARCH / GOALS），单手可完成全部操作；桌面为侧面板同三 Tab。
7. **性能**：手机 bloom 半分辨率、像素比 ≤1.5；无 console 错误；首包 ≤1MB。
8. **数值门**：`verify-singularity.js` 全绿，且 3 小时模拟仍有未完成目标（内容不能 1 小时耗尽）。
