Download the Games

Every game on this site is downloadable as a standalone HTML5 package. One folder, no backend, no build step: 450 machine-verified daily boards plus the free-play pools, playable from any static file server. The zips are also portal-ready builds (entry file index.html, relative paths) — the exact artifact itch.io-style sites ask for.

Self-host in 30 seconds

Unzip, then serve the folder with any static server — e.g. python3 -m http.server 8000 — and open http://localhost:8000/. (Opening index.html straight from disk won't load the puzzle data: browsers block JSON fetches from file://.) Each package's README repeats these steps.
