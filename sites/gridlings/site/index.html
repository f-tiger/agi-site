How to play

  • Fill the grid so every row and column contains each animal exactly once and each color exactly once.
  • Every animal–color pair appears exactly once in the whole grid.
  • The same animal never touches itself — not even diagonally.
  • Every Gridlings board has exactly one solution, and you never have to guess: there is always a next cell you can prove. That's checked by machine before a puzzle is published.

If you enjoy daily logic games like LinkedIn's Queens or Tango, this is the same kind of pure-deduction habit — with a double constraint that makes each board a tighter knot. New puzzle at 00:00 UTC.

FAQ

How do you play Gridlings?

Fill the grid so every row and column contains each animal once and each color once, every animal-color pair appears exactly once, and the same animal never touches itself, even diagonally. Tap a cell, then pick an animal-color pair from the palette.

Is there a new Gridlings puzzle every day?

Yes — a new daily board goes live at 00:00 UTC, the same board for every player worldwide, with streak tracking. Unlimited free play in three difficulties and a full archive of past dailies are also free, with no account and no ads.

Can Gridlings be solved without guessing?

Yes. Every published board is machine-verified before release: a solver proves exactly one solution exists and is reachable by logical deduction, so there is always a provable next step.
