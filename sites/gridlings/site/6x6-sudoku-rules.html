6×6 Sudoku Rules — Small Grid, Same Logic

Standard sudoku, one size down. Fill the 6×6 grid with the numbers 1–6 so every row, every column, and every outlined 2×3 box contains each number exactly once. The rectangular boxes are the twist: each box spans only two rows but three columns, so box-line interactions fire differently than in the 9×9 you know.

The rules

RuleWhat it means
Rows & columnsEvery row and every column contains 1–6 exactly once.
2×3 boxesEach outlined box (two rows × three columns) also contains 1–6 exactly once.
GivensPre-filled cells; the daily board is minimized while keeping a unique deduction-reachable solution.

Box-row claiming

A box covers three cells of a row. If a number's only spots in the box sit in one row, that number is banned from the rest of the row — this fires constantly on 2×3 boxes.

Pair up the six

With only six values, a row missing three numbers over three cells is a tiny puzzle on its own. Naked pairs and triples appear early and often — look for them before scanning.

Two-box bands

Each band of two boxes spans two rows exactly. A number placed in one box of a band forces its row within the neighbor box — the 6×6's version of pointing pairs.

FAQ

What are the rules of 6x6 sudoku?

Fill the grid with numbers 1–6 so that every row, every column, and every outlined 2×3 box contains each number exactly once. It is standard sudoku logic on a smaller grid.

How are the boxes shaped in 6x6 sudoku?

Each box is a rectangle of two rows by three columns; the grid holds six of them. The rectangular shape makes box-and-row interactions more frequent than in 9×9 sudoku.
