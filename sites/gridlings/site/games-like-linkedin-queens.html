FAQ

What is the LinkedIn Queens game actually called?

The puzzle type is star battle, a placement puzzle from the international puzzle-championship scene. Queens is a one-star variant with crown symbols; the classic form, playable here daily, uses two stars per row, column, and region.

Are there free alternatives to LinkedIn's daily games?

Yes — this site runs 11 free daily logic puzzles covering the same families (star placement, binary balance, path drawing) plus classics like futoshiki, nonogram, and skyscrapers. No account or app is required.

Do these puzzles ever require guessing?

No. Every board is checked by machine before publication to have exactly one solution reachable by pure deduction — the same fairness property the LinkedIn games are known for, verified rather than assumed.
