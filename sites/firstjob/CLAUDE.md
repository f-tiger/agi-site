## 定位
应届生的**判定站**,不是招聘站也不是鸡汤站。差异化只有一条,且是全中文互联网上没有第二家在做的:
**把「AI 正在收窄入门级台阶」这件事,用一份可点开、可复核、带日期的一手研究讲清楚,再落到条款和清单上。**
上游是主站 AGI-2027 追踪器(AI 能力每上一个台阶,入门岗就再窄一分)。
**不卖课、不收费、不接广告、不做内推、不收录任何第三方付费服务、不用注册。**

判定页六件套(标题即问题 / 首屏一句结论 / 一张表 / 可见 FAQ 与 FAQPage JSON-LD 逐字一致 /
带日期的一手依据 + 一手源外链 / 翻转条件)——`faq ok` 是部署闸门的一部分。

## 内容硬约束
1. 可引的一手依据只有四类:①法律与行政法规原文(《劳动合同法》第九/十九/二十条)②政府文件
   (人社部发〔2023〕26 号取消报到证;教育部办公厅推广 24365 通知)③教育部口径数据(2026 届 1270 万,
   2025-11-20)④可点开的研究原文(斯坦福数字经济实验室《Canaries in the Coal Mine?》2026-08 更新,
   ADP 数据,22–25 岁缺口约 19%、机制为少招、无全经济范围大规模替代)。
2. **不引任何「就业率 / 签约率 / 岗位替代率 / 平均投递份数 / 有效校招岗位数」**——2026-09-15 检索到的
   全是二手转述,追不到发布机构原始口径。部署闸门 grep 这一类写法。
   **`/ai-entry-level-jobs` 有一节专门写「本站刻意不引的数字」,那一节不许删**——它本身就是差异化。
3. 引用斯坦福研究时必须同时保留「**没有发现全经济范围的大规模替代**」这一条。掐掉它去制造恐慌,
   是本站最容易犯也最不能犯的错。
4. 法条与政策只概括不解释;应届生认定一律写「以你要报的那份公告为准」,**永不逐省列表**
   (各省表述、适用岗位、生效时间不同且在变,列了就等于替读者承担落选风险)。
5. `/ai-exposure` 的结果必须一直标注「本站编辑判断,非官方分类」。它是问题清单,不是预测模型。
6. 各地补贴金额、名额、地方违约金上限一律不列,只给查询入口。
