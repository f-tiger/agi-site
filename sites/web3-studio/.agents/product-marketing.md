# Product marketing context — Web3 Workbench

Version 1, 2026-09-19. Scope: only sites/web3-studio. The owner explicitly authorized all remaining researched directions to ship after validation.

Positioning: practical, local worksheets that turn supplied AI/Web3 operational records into inspectable decisions and portable reports. Ten free betas, not an exchange, investment service, autonomous agent marketplace or legal/security certification service.

Provisional buyers: service-business finance operators; agent integrators and procurement teams; data collaboration operators; compute/zkML engineers; disclosure analysts. These are research hypotheses, not interviewed or paying customer segments.

Jobs: reconcile payments, review task evidence, plan bounded fallbacks, retrieve dated protocol facts, check declared data grants, compare workload costs, stress-test reward economics, plan proof deployment, decode known token calls, compare disclosure records. Each catalog entry defines its narrow user and output.

Current value: no account or wallet needed, local input processing, fictional worked examples, form and exact JSON contracts, visible assumptions and exclusions, portable report, downloadable CLI running the same engine. The protocol API is an actual free read-only endpoint.

Alternatives: spreadsheets, internal scripts and notebooks, Request Finance/Cryptio, Promptfoo/8004scan, OpenRouter/LiteLLM, Dune/The Graph, Vana/Ocean, Akash/Runpod, Bittensor/Gensyn, EZKL/snarkjs, Blockaid/Tenderly, RWA.xyz and primary reports. Do not imply these lack functionality they already provide. Our tools sacrifice integrations, data breadth and automation.

Distinctive hypotheses: exception-first reconciliation, evidence denominators and version boundaries, worst-case procurement budgets, grant-conflict reporting, accepted-output economics, organic-versus-subsidy separation, explicit versioned engineering manifests. None is a validated moat.

Voice: concrete, calm, review-oriented. Say what the tool calculates and what evidence the user must supply. Never claim safe transactions, trusted agents, lawful rights, proven reserves, investment returns, verifiable AI or live monitoring from arithmetic alone. Do not call a hash a ZK proof.

Commercial status: every current function is free. No checkout, paid package, payment or customer is claimed. Potential paid work requires independently verified recurring needs, measured improvement over the current alternative and an actually built deliverable.

Distribution: owner-controlled hub and contextual links, guides, machine-readable examples and CLI. No automated outreach or social posts. Existing fleet traffic is not evidence for this new portfolio.

Measurement: optional, self-reported submissions with an explicit QA flag. No input upload. At 2026-10-19, five own-task/helped submissions and three recurring-task submissions per site trigger manual validation only; no demand conclusion without evidence of relevant exposure. See fleet-bets and the research document.
