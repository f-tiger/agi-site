Your working data

QuerySprint runs its free workbench in your browser. Quotes, cost rows, SQL queries and TradeCheck document data are not uploaded. TradeCheck MCP downloads run locally, but your AI assistant may send supplied documents to its own model provider. The server receives the requests needed to serve the site. Cloudflare, the hosting provider, may process network and security information.

Optional measurement

Usage measurement is off by default. If you enable it, we send an event name, site, source category, sample/exercise/own-data label and a random identifier for this page visit. We store no entered content, email, API key or IP address in the experiment database. Events are deduplicated within the visit and kept in a 35-day active window. Older records are deleted on the next measurement request; if there are no requests, they can remain longer. There is no cross-site profile. Closing the page discards the browser's visit identifier. Disabling the checkbox stops future optional events.

The optional past-30-day question submits only the chosen answer category (none, once, or twice or more), with the same anonymous visit fields. The price-interest button explicitly submits an anonymous interest event even when general measurement is off. A success message appears only if the server records it. It does not subscribe you, charge you or reserve a product. Anonymous counts cannot establish distinct buyers or revenue.

What is available

The free workbench is available. The proposed paid product is not for sale. We have not claimed customers, savings, job outcomes or verified suppliers. The displayed proposed price is a research hypothesis, not a checkout quote.

About this experiment

This tool is part of the AGI Scorecard project. Use the main project site for project information. You can use every free function without sharing optional events. Downloaded files stay on your device.
