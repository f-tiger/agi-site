SEC Company Facts: Match Exact Periods Before Comparing

A reporting period and a filing date answer different questions. Match entity, concept, unit and exact period first; then compare what was available at each filing cutoff.

By FilingLens project team · Published 19 September 2026 · Fictional examples, reproducible calculations

One annual period, two reported values

FilingLens's fictional example reports revenue for 1 January–31 December 2024 as 125,000,000 USD at an earlier filing cutoff and 123,000,000 USD at a later cutoff. The absolute difference is −2,000,000 USD. These are illustrative values from a fictional company, not a real issuer disclosure.

The comparison asks what value was available for the same period at two cutoffs. It does not compare one year's revenue with another year's revenue.

Reproduce an evidence check

  1. Start with the fictional example, or use the browser's Apple total-assets lookup for live SEC data.
  2. Select one exact period and unit from the available observations.
  3. Choose two filing-date cutoffs. The tool selects the latest eligible filed date at each cutoff.
  4. Read both values and the absolute difference, then follow the real accession links to the filings.
  5. Export the source note and record any unresolved context before drawing a conclusion.

Missing and conflicting values

No observation before a cutoff means incomplete evidence, not zero. Different values reported on the same selected filing date remain ambiguous. Two cutoffs can correctly select the same filing and produce no change. A changed value alone does not prove a restatement or explain its cause.

Data and tool boundaries

The live browser lookup uses the SEC companyconcept API for a small allowlist of US-GAAP concepts. An uploaded file is not authenticated. The local MCP performs comparisons only and does not fetch data. Neither interface provides trading signals. Read the methodology and setup guide.
