# The Power Bill 建站调研 · 2026-09-15(owner:「扩展几个适配欧洲、美国的站点」)

检索工具 WebSearch;**eia.gov / pjm.com / eurostat 等发布方域名多被出网代理挡**,故所有数字只取
多家具名独立来源逐字一致者,并在页面给出发布方链接供读者复核。该限制写进 `/about` 与 `/resources`。

## 一、为什么是这个方向(三门)
| 门 | 证据 |
|---|---|
| 数据门 | 判定型页面吃引用(主站 Bing 明细);本题的核心问题「Is AI raising my electricity bill」正在被两边各说各话,**而市面上几乎没有一页把反向证据放在同屏**——这正是可被引用的稀缺形状 |
| 需求门 | 电费上涨是英语世界当下最普遍的家庭痛感之一,且已与数据中心绑定进入主流讨论;消费者调查显示多数人担心数据中心推高自家电价(方向性证据,本站不引其百分比) |
| 商业门 | 与主站论题直接同源:AI 资本开支是追踪器的判定之一,电网是它的物理落点。本站向主站 `/ai-capex-trillion-dollar` 与追踪器分流,向德语家庭节能站 getecoback 分流。**本站自身不设收费面、不接联盟**——一旦收能源联盟佣金,这页的判定就不可信了 |

**刻意接受的代价**:能源内容里联盟佣金极厚(换电价、光伏、储能),拒收等于主动放弃变现路径。
这是有意识的取舍:本站的全部价值在于它没有卖方立场。

| 欧洲:都柏林及荷兰、法兰克福部分地区新增数据中心接入长期受限;大负荷接入排队以年计;增容成本经受管制网络电价回收 | 欧洲电网运营商与监管机构(多来源一致) |

**刻意不用**:任何「数据中心让你每月多付 $X」的人均归因(取决于公用事业公司与电价方案,全国口径必为猜测,
**部署闸门 grep 禁止**);无公开方法论的调查百分比;各州/各国 docket 清单(必然快速过期)。

## 三、竞品格局
| 类别 | 代表 | 缺口 |
|---|---|---|
| 财经媒体 | CNBC/Fortune/Forbes 等 | 单篇、无翻转条件、少有把反向证据并排 |
| 倡导组织 | 反数据中心与环保团体 | 立场先行,数字常来自己方测算 |
| 行业 | 电力与数据中心行业机构 | 立场相反,同样先行 |
| 换电价/比价站 | 各类 switching 站 | 卖方立场,佣金驱动 |
| 监管与统计机构 | EIA、Eurostat、PUC | 权威但不作判定,也不告诉读者该看哪份文件 |

**没有一家做「带日期的双向证据 + 明确翻转条件 + 只用你自己数字的工具 + 零联盟」。**

## 四、由此定下的 v1
两页判定 + 两个工具 + 数据来源页 + 关于。
**工具的选法**:本题最常见的错误是把「账单涨了」直接等同于「电价涨了」。`/bill-decomposer` 用读者
自己的两张账单把变化拆成价格效应/用量效应/交叉项,**零外部数据**,因此永远不会过期也永远不会编造;
`/who-pays-check` 把「我该去投诉谁」变成「我该去搜哪份文件」。
**刻意不做**:人均归因计算器、供应商比价、光伏/储能推荐、逐州 docket 表、任何联盟链接。

## 五、第二批候选(未过三门,只登记)
- "What is a large load tariff?" —— 定义型,依据来自具体 filing,需先确认能引到监管机构原文。
- "Do data centres use that much water?" —— 需求真实,但一手数据零散且口径混乱,暂不做。
- 下一次 PJM 容量拍卖结果 —— **不是新页**,是首屏数字与翻转条件的定期复核义务(见 CLAUDE.md)。
- 欧盟侧单独页(爱尔兰案例) —— 若 `pev` 显示欧盟读者占比可观再做,否则维持现有欧洲小节。
