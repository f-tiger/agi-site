  1. 01

    Inspect the offer

    Check required fields in an x402 v2 exact EVM challenge. Atomic amounts stay exact; token decimals are never guessed.

  2. 02

    Check the delivered output

    Use JSON Pointer paths to require types, exact values and numeric bounds. A rule match is evidence of fit, not proof of truth.

  3. 03

    Repeat after a change

    Export your report. Save sanitized fixtures and run the same checks in your own CI with the local runner. Batch checks include entered failure and retry costs in each accepted-output calculation.
