Your inputs stay in the workbench.

Local checks

Payment challenges, response JSON, batch attempt records and acceptance contracts are processed in this browser tab. They are not sent to our server or a model provider, and are not saved to cookies, local storage or an account. Tool switches keep inputs only in tab memory. Reloading clears the input. Local file imports are read in this tab and are not uploads. No pasted endpoint is fetched. Browser extensions and your own browser settings remain outside this tool's control.

Downloads

Reports are generated in your browser and saved only when you export them. Reports can include field paths, payment terms (including addresses or URLs from compared snapshots), attempt IDs, task labels, provider labels, entered costs and error messages. Exported acceptance contracts can contain your expected values. Review downloads before sharing. The local Node runner reads files you specify and prints a report; it has no network functionality.

Optional feedback

Only pressing “Send anonymous feedback” sends application data to us: your selected past-month frequency, your selected price-interest answer, whether an own-task check completed, a random one-time deduplication ID, and a QA flag. We add the submission time. We do not include your pasted inputs, wallet address, email, referrer, or an account identifier. We do not store your IP in the feedback table. No feedback is sent automatically when you visit, type or run checks.

The feedback endpoint uses Cloudflare's request rate limiting, which processes an IP transiently. Cloudflare also processes normal web request metadata to deliver and protect the site. We do not control every platform-level log. No advertising or third-party analytics scripts are loaded.

The public aggregate counter shows anonymous feedback counts grouped by answer and QA status for a rolling 35-day window. These are submissions, not verified people, leads, purchases or retained customers. Old feedback rows are deleted when a feedback or aggregate-counter request next runs after they age beyond 35 days; deletion is not a scheduled guarantee.

Experimental status

This site is an AGI Scorecard experiment. The tool is free. The monthly monitoring price is a research hypothesis; no purchase, subscription or reservation occurs when you send feedback. Feedback contains no contact details, so it cannot be used to follow up with you.
