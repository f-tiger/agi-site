# AdSense 接入指南（robots-disallowed working file）

目标：全站接入 Google AdSense Auto Ads（程序化广告，无需等赞助商）。
工程已全部预制好（tools/add_adsense.py）——**你只需完成账号步骤（约 10 分钟 + 谷歌审核 1–2 周）**。

## 你要做的（唯一人工步骤）
1. 打开 https://adsense.google.com → 用你的 Google 账号注册。
2. 添加网站：`agiscorecard.com`。
3. 拿到发布商 ID（形如 `ca-pub-1234567890123456`，后台右上角"账号"里能看到）。
4. **把这个 ID 发给我**（对话里直接粘贴即可）。
5. 我运行 `python3 tools/add_adsense.py ca-pub-XXXX` → 自动完成：
   - 生成 `/ads.txt`（谷歌验证站点所有权的行业标准文件）
   - 把 Auto Ads 代码注入全部 73 个可索引页面（自动跳过 noindex 分享页/widget——那里放广告违反投放政策也伤体验）
   - validate + 推送上线
6. 回到 AdSense 后台点"申请审核"。谷歌审核通常 3–14 天；通过后广告自动开始展示，无需再动代码。

## 诚实的预期管理
- **当前流量（约 150 用户/28 天）下，AdSense 收入 ≈ 每月几美分到 1-2 美元。**
  展示广告的行业经验：日 PV 数千才有像样收入（CLAUDE.md 的调研结论一致）。
- 所以接入的意义是**基础设施先就位**：流量起来那天（游戏铺开/目录外链生效/AGI 新闻спike）
  收入自动跟着来，不用临时抱佛脚。
- 近期真实营收主力仍是：**订阅（beehiiv Boosts $1-3/sub）+ 赞助位**。AdSense 是第三条腿。

## 百度联盟为什么不接
需要 ICP 备案 + 国内主体认证；本站托管 Cloudflare、无备案，审核过不了。
国内流量的变现路径：/cn 的订阅 + 赞助位（已上线）。

## 政策注意（已在工程里处理）
- ads.txt 必须与后台 ID 一致（脚本自动生成）。
- 广告不进 iframe 嵌入页/noindex 分享页（脚本自动跳过）。
- 赞助位与 AdSense 可共存（赞助位有清晰"Sponsored"标注，不冲突）。
- 审核期间站点保持正常更新即可（每日运行本来就在做）。

## 谷歌注册要求（2026 核实，中国大陆视角）
1. **Google 账号** + 年满 18 岁。
2. **站点条件**（我们已全部满足 ✅）：
   - 站点境外托管（Cloudflare ✅）、可从国外正常访问 ✅
   - 有充实原创内容（建议几十篇以上——我们 73 页 ✅）
   - 有 privacy policy / about ✅、导航清晰 ✅、无违规内容 ✅
   - 无官方流量门槛（流量小也能过审，只影响收入不影响资格）
3. **中国大陆特别注意**：
   - 大陆身份可以注册（选"中国"地区），但**境内备案网站不能用**——我们是境外托管，OK。
   - 注册后会寄 **PIN 码明信片**到你的地址做验证（约 2-4 周），也可累计到一定金额后用身份证明验证。
   - **收款是最大痛点**：起付 $100；大陆银行接收谷歌电汇/西联常要求提供合同证明，
     且受 $5 万年度外汇额度限制。常见解法：用支持外币入账的银行账户（或香港账户）。
     反正离 $100 起付还早，先注册过审，收款到时再解决。
4. 审核周期：提交后通常 **3-14 天**。
