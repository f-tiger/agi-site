Check a small client delivery locally

Paste an SRT or a workflow-run CSV. The original deterministic checks run in this browser without uploading the file or calling AI. They find structural flags, not translation accuracy or business truth.

Defaults are editable examples, not a platform standard. Language, audience and screen size change readability.

CSV columns: run_id,finished_at,status,output_count. Accepted statuses: success, failed, running, cancelled. Only logged records are checked; compare the actual destination separately.

Saved checks and retest comparison

Free, up to 20 summaries in this browser. Save only when you choose: counts, flags, thresholds and time; no source text, run IDs or filenames. Browser storage can be cleared. Download a backup to keep records or move them between devices.

    Choose the same client task and scope. Comparison requires the same check type, thresholds, review time and record count. It shows flag-count changes; it cannot match individual defects or prove they were fixed.
