## 第 0 部分：动手前必须先接受的三个事实

### 事实 1 — 在 200 UV/月 上，一半的营收模型在数学上已经死了

| 模型 | 200 UV/月 的期望收入 | 判定 |
|---|---|---|
| AdSense（科技类 RPM ~$8） | **约 $1.6/月** | 死 |
| 通用联盟（2% CTR × 3% 转化） | **约 0.1 次点击/月** | 死 |
| 展示广告网络 | 多数网络门槛 10k UV/月，**不达标** | 死 |
| 订阅（$10/月 × 转化 2%） | 4 人 = **$40/月** | 勉强 |
| B2B 数据/咨询（$200–2000/单） | **1 单 = $200–2000** | **活** |

**推论：所有依赖流量规模的变现方式，现阶段一律不做。**
不是"以后再做"——是现在做等于把时间花在测量噪声上。
唯一可行的方向是 **单用户价值高、样本需求低** 的模型。

### 事实 2 — 流量慢的原因不是站做得差，是赛道的商业意图低

站内实测（2026-07/08）：涨的四个页面全部是 AGI 论点类查询
（dario-amodei、when-will-agi、how-close-is-agi、situational-awareness-summary）。
这类人搜完就走——**他们没有在做一个花钱的决定**。
而站内商业意图最高的两个资产（/invest、/ai-job-risk-check）几乎零流量，
因为它们被埋在一个"AGI 论点"品牌之下，没有独立的获客面。

**推论：不是要"重做网站"，是要"重做要约（offer）"。**
域名不必换。真正要换的是：把流量目标从"对 AGI 好奇的人"
改成"正在做一个和 AI 有关、且有钱在里面的决定的人"。

### 事实 3 — 这个站真正可复利的资产不是 AGI 这个话题，是方法

八项预测 + 事前登记的翻转条件 + 逐条收据 + 一个可审计的分数。
**这套方法可以搬到任何"有人公开放话、但没人记账"的领域**，
且它自带三个别人抄不走的特性：可验证、有时间沉淀、越老越值钱（复利）。

爆仓事件是这条推论的实证：当"有人放的话到期了"，
本站是全网唯一能逐行回答"哪条判定动了"的地方——单日流量 +26%。

## 关于"像孙宇晨那样的致富实验"

可复制的部分：**高速度、公开叙事、把过程本身做成内容**。这部分我们全要。
不可复制的部分：靠制造预期而非交付价值来变现。
原因不是道德说教，是**这个站唯一的资产就是可信度**——
一个以"事前登记、绝不事后改口"立身的站点，
一旦被发现在自己的营收上含糊其辞，八项判定的公信力同时归零，
那才是真正不可逆的损失。

所以本组合采用的是"**公开对赌版**"：
每一个实验事前公布假设、成功阈值、以及**什么结果算失败**，
到期无论成败一律公开数字。这既是实验纪律，本身也是内容。

## 第 1 部分：实验设计规范（每个实验都必须填满）

沿用本站给预测评分的同一套纪律：

| 字段 | 含义 |
|---|---|
| **假设** | 一句话，可证伪 |
| **机制类** | A=单用户高价值 / B=依赖流量 / C=产品即渠道 |
| **前置成本** | 我的工时 + owner 工时 + 现金 |
| **成功阈值** | 事前写死的数字 |
| **失败阈值（kill）** | 达到即停，不许找理由续命 |
| **对照** | 和什么比。没有对照的不算实验 |
| **最小可检测效应** | 在当前样本量下，多小的差异是可信的 |
| **时间盒** | 到期强制判定 |
| **依赖** | 需要 owner 做什么 |

**对抗性要求**：每个实验必须写出"**什么证据会证明我错**"。
只写成功路径的不是实验，是许愿。

## 第 2 部分：十个方向（按可执行性排序）

### E1 · 公开营收实验日志 `/experiments` 【机制 C · 自带获客】
- **假设**：把"一个 200 UV 的站能不能赚到钱"这件事本身公开做，
  能吸引 indie hacker / build-in-public 受众——这个群体规模大、极爱转发、
  且聚集在本站目前完全没有流量的 X / HN / Reddit / 即刻。
- **为什么它排第一**：它是唯一能同时解决"没流量"和"要营收"的一件事。
  其他九个实验的结果都是它的内容原料——**实验越失败，内容越好看**。
- **成功阈值**：30 天内 ≥3 个外部域名引用 /experiments，或 HN/Reddit 单帖 >50 分
- **失败阈值**：30 天 0 外链且 0 讨论 → 说明"公开做实验"这个钩子对本站受众无效
- **对照**：现有的 GEO 深页发布节奏（同期新页的自然外链数）
- **依赖**：无（我可全自动执行）

### E2 · AI 岗位风险付费报告 【机制 A · 高意图】
- **假设**：`/ai-job-risk-check` 覆盖的是全站商业意图最高、搜索量最大的需求
  （Stanford 2026 AI Index：22–25 岁开发者就业下降近 20%）。
  免费给层级，付费（$9–19）给"你的岗位 vs 你所在行业的具体证据 + 12 个月观察清单"。
- **成功阈值**：前 100 个完成测试的用户中 ≥3 人付费（3% 付费率）
- **失败阈值**：≤1 人 → 该需求的付费意愿不成立，止损
- **对照**：同期免费版的订阅转化率（付费是否只是把订阅挤掉）
- **最小样本**：需 100 次完成测试。**当前流量下这需要数月**——
  所以此实验必须挂在 E1 或外部分发之后，不能单独启动
- **依赖**：owner 开通收款（Stripe / Gumroad / Lemon Squeezy）

### E3 · 预测市场证据层 【机制 A+B · 需先解合规】
- **调研结论**：Polymarket 与 Kalshi 均有真实联盟计划
  （首次入金 CPA 约 $10 / $25 + 手续费分成；Polymarket 走 Dub.co，Kalshi 内部计划）。
  2026 世界杯期间 Polymarket 单题成交 $30 亿、Kalshi $5 亿——市场是真的。
  Kalshi 已与 CNN、CNBC 签数据合作，说明"媒体+预测市场"是被验证的路径。
- **假设**：本站的"事前登记翻转条件"对 PM 交易者有真实使用价值。
- **必须先解决的问题（owner 决策）**：
  ① 中国大陆对加密与对赌类产品的监管红线——**你本人所在地是硬约束**；
  ② 站点定位风险：一旦挂交易联盟链接，"独立评估者"身份受损，
     而这正是 /for-agents 明确写过"we take no fees from any market"的承诺。
  **我的建议：只做"证据层"不做"导流分成"**，即为 PM 用户提供数据、
  用订阅而非佣金变现。这样不违背已公开的承诺。
- **失败阈值**：60 天内 PM 相关页面无自然外链、无 referral → 该受众不认

### E4 · 13F / AI 持仓追踪订阅 【机制 A · 站内最高商业意图】
- **假设**：爆仓事件已证明"谁在 AI 上押了什么钱"有真实需求。
  13F 是公开的、季度更新的、可自动化的——**天然复利资产**（越久历史越值钱）。
- **产品**：追踪 N 个 AI 相关基金，季度披露当天出解读 + 变动预警，付费订阅。
- **成功阈值**：Q2 13F（8 月中）发布后 30 天内 ≥10 个付费订阅
- **失败阈值**：≤2 → 止损
- **对照**：同期免费简报的订阅增量
- **依赖**：owner 决定定价 + 收款

### E5 · B2B 时间线简报 / 咨询 【机制 A · 单价最高】
- **假设**：企业战略部门需要"AI 时间线的可审计判断"，且愿意为一份
  带事前登记条件的定制评估付费（$500–2000）。**1 单即等于 3 个月的其他全部收入**。
- **成功阈值**：90 天内 ≥1 次真实询盘
- **失败阈值**：90 天 0 询盘且 /advertise 也 0 → 说明当前受众不含决策者
- **对照**：/advertise（已上线数月、0 询盘）——这是**已有的阴性对照**
- **依赖**：owner 出面成交（我可备齐材料）

### E6 · 工具白标授权 【机制 A · 复利】
- **假设**：嵌入已免费开放，若有站点真的嵌入，其中一部分愿意付费去掉品牌回链。
- **前置**：**必须先有真实嵌入发生**。当前 `embed_copy` 事件为 0——
  所以此实验现在**不可启动**，前置条件是 E1 带来的分发。
- **失败阈值**：90 天内 embed_copy 仍为 0 → 嵌入策略整体重估

### E7 · 方法迁移：第二个记分牌 【机制 C · 最大想象空间】
- **假设**：事实 3 成立——方法可移植。
  选一个"有人公开放话、有钱在里面、但没人记账"的领域做第二个记分牌，
  用同一套引擎（pre-registered conditions + 收据 + 0–100 指数）。
  候选：AI 公司营收承诺、芯片产能承诺、自动驾驶落地承诺、能源/电网承诺。
- **对抗性设计**：这是对"是不是赛道问题"的**直接检验**。
  同样的方法、同样的执行者、不同的赛道——如果新赛道 90 天内自然流量
  明显高于 agiscorecard 同期同龄表现，则"赛道低容量"成立，值得转移重心；
  若同样起不来，则问题在分发而非赛道，**不要再换赛道**。
- **成功阈值**：新记分牌 90 天自然搜索用户 > agiscorecard 同龄期 2 倍
- **依赖**：owner 决定是否愿意开第二个域名（也可先用子路径低成本试）

### E8 · 付费预测联赛 【机制 C · 复利留存】
- **假设**：/agi-test + /future-bet 已有互动，把它升级为**记分制联赛**：
  用户锁定预测 → 到期按真实结果结算 → 排行榜 → 付费层（历史战绩、私人榜单）。
  复利来源：**排行榜的价值随时间线性增长，且迁移成本极高**。
- **失败阈值**：60 天内 `prediction_lock` < 30 → 用户不愿被记分，止损
- **注意**：不涉及金钱对赌，纯声誉积分——绕开博彩监管

### E9 · Agent / 数据 API 付费层 【机制 A · 但前置不足】
- **诚实评估**：`/data.json` 目前只有 **8 条预测 + 2 个历史点**。
  这不足以构成可售数据产品。**现在做会砸招牌**。
- **前置**：数据集需先扩到有厚度（E7 的第二记分牌、E4 的 13F 历史都会喂养它）
- **判定**：**本轮不启动**，列为 6 个月后复评

### E10 · AdSense 【机制 B · 作为阴性对照保留】
- **作用**：**这个实验的价值不是赚钱，是校准**。
  它给出"纯流量变现"在当前规模下的确切数字（预计约 $1–2/月），
  从而让其他实验的收益有一个可对比的基线。
- **成功阈值**：无（预期即为极低）
- **科学价值**：如果 30 天后 AdSense 收入 > 所有 A 类实验之和，
  说明我对"低流量下价值模型优先"的判断错了——**这是本组合的自我证伪条件**

   因此设定了前置依赖，而不是假装能测

## E11（2026-08-05 追加，已上线第一步）：把追踪指数接到股票上，做成可订阅的产品

owner 指令："网站与股票工具进行联动增强，而不是一个内容站，然后股票工具未来可以收费或者订阅。"

**为什么这条比前面几个实验更有戏**：前面的调研已经证明，在约 200 UV/月的量级上，
所有**按流量计价**的变现（AdSense 约 $1.6/月、泛联盟约 0.1 次点击/月）在算术上就是死的，
出路只能是**按人计价**。而按人计价需要一个别人给不了的东西。本站恰好有一个：
**AGI-2027 追踪指数**——一个公开、可审计、按 8 条判定重算的 0-100 分数。
把它接到股票上，就得到一个**没有第二家能做**的读数。

**已上线（免费层）**：`/ai-stock-exposure` + `/zh/ai-stock-exposure`。
17 个标的 → 8 条判定的映射，组合分数用**与追踪指数完全相同的权重**，
所以 62.5 是一条有意义的对照线，而不是随便找的基准。持仓来自公开 13F（只有逐笔文件的两家）。

**第一个真实发现，而且它自己就是卖点**：
一致度分数几乎对所有 AI 组合都在 95-100——因为上市 AI 标的压的都是已判定成立的那三条。
真正有区分度的是第二个数：**「押在 AGI 本身」的比例**（基建组合约 2%，ARK 持仓 13%）。
**结论：AGI-2027 这条命题，公开市场基本买不到；你买到的是基建。**
这句话可以独立传播，而且它是从站内数据里算出来的，不是观点。

**付费层（未建，按顺序）**：
1. **判定翻转提醒** —— 判定一变，本页所有组合分数同时变。这是唯一站得住的复购理由：
   产品的价值锚定在"数据会动"，而不是"内容会更新"。
2. **季度 13F 差分** —— 对着用户保存的组合做差分，8-14、11 月、次年 2 月各一次，有天然节奏。
3. **完整标的映射** —— 免费层 17 个，付费层扩到全覆盖。

**收款路径（需先核实，不要当成事实）**：优先确认 beehiiv 现有套餐是否直接支持付费订阅
（若支持，则**不需要新选支付处理器**，E2/E4 卡住的那个 owner 决策同时解掉）。
核实前不要写任何价格到公开页面上。目前 `/ai-stock-exposure` 的付费段落写的是
"还没做、没有等待名单表单、定价前先问订阅者"——**这是有意的**：
对一个不存在的产品挂价格牌，会把这个站唯一真正的资产（可信度）换成几个邮箱。

**判定条件**：`exposure_score` 与 `subscribe_click{exposure_en/zh_pro}` 出现真实计数，
且 `tool_click{opinion_invest}` 证明"内容→工具"这一跳成立。
若 90 天内 exposure_score 仍接近 0，说明问题不在变现设计而在流量结构，回到 E1/E7。
