## 一、竞品格局:没有一个站同时做「建议 + 撮合 + 二次启动」

| 类别 | 代表 | 它做什么 | 对 35+ 失业者的缺口 |
|---|---|---|---|
| 招聘平台 | BOSS直聘 / 智联 / 猎聘 | 岗位撮合,HR 筛选 | 年龄栏是第一道过滤;35+ 在这里被系统而不是人拒绝 |
| 职场社交 | 脉脉(自称 1.2 亿用户,2026 年 1–4 月新发岗位 +22.6%,来源:cnblogs 转载,未核) | 人脉、内推、猎头付费挖人 | 面向在职中高端;失业者没有可展示的「当前公司」 |
| 付费专家咨询 | 在行(本轮检索未出结果,按既有认知列出) | 用户付费约专家 | 供给方要审核入驻,面向名校/大厂标签;普通 20 年从业者进不去 |
| 零工/众包 | 猪八戒 / 一品威客 | 项目接活 | 价格竞争,不认经验只认交付;无「先聊半小时」的低门槛 |
| 银发招聘 | 银发聘(2024–2026 存在,来源 sohu/163,未核) | 退休人员岗位 | 服务 55+ 退休群体,不是 35–55 失业者 |
| 美国 | WIOA Dislocated Worker(2026 约 $1.1B,来源 metaintro,未核);scale.jobs / TealHQ 等求职软件 | 政府培训券;AI 求职助手 | 无一个面向 45+ 的专门平台(检索结论) |

**结论**:撮合面上,35+ 失业者被三类平台同时排除:招聘看年龄、社交看现职、专家平台看标签。
**本站占的位置**:不看年龄、不要现职、不审标签,只要一句「帮谁把什么搞定」+ 报价 + 联系方式。

## 二、用户原声(知乎,检索摘要)

高频问题(原题):「35岁失业找不到工作,能做什么?」「快 35~40 岁了,失业该怎么办?」
「那些 35 岁失业的中年人,后来都怎么样了?」「35岁失业,如何走出低谷,找到新的方向」。
高赞回答的共同建议:**发动所有亲友内推**、**按行业看年龄而不是一刀切**(医生律师建筑师
35 岁还在起步,互联网最严重)、**心态与行动**。

对本站的含义:
1. 用户问的是「能做什么」,不是「哪里招人」——所以首屏应该是路径决策,而不是岗位列表。✅ 已有 /paths
2. 「内推 / 亲友」= 撮合的真实渠道是熟人网络,不是平台。所以本站撮合的正确形态是
   **一张可以被转发进微信群的卡**,而不是一个要登录的市场。✅ 卡 + 分享;本轮加「同行业匹配」链接
3. 「后来怎么样了」= 用户想看同龄人的结果。零编造下本站不能写故事,只能让**真实的卡自己
   长出来**——判定线 10-14 / 12-14 就是在测这条。

## 六、刻意不做的(写明理由,后续会话别再提)

- **LLM 生成「个性化建议」**:本仓无 LLM API 密钥;更重要的是,对失业者说的每句话要经得起
  「出处在哪」——决策表 + 算术 + 法规条款比一段生成文本更可信,也更便宜。
- **账号 / 邮箱注册**:舰队既有结论(邮件表单 0/246);卡号 + 撤卡码已足够当身份。
- **种子卡 / 示范卡 / 「成功故事」**:零编造。空就是空。
- **岗位抓取 / 聚合招聘信息**:那是招聘网站的战场,而且年龄过滤问题原样存在。
- **付费**:在撮合被验证(判定线 12-14)之前,任何收费都是在向失业者收钱,不做。
