Edit a screen recording into a short tutorial.

Shotcut provides a desktop timeline for cutting clips, adding titles and exporting video. The selected introductory video is linked by Shotcut’s official tutorial page.

The tutorial is from 2019 and demonstrates fundamentals, not the latest interface. Check current documentation for menus and export options. TDS does not provide a browser video editor.

Import a short recording and make a copy of the project.

Remove an unwanted beginning or ending on the timeline.

Add a clear title and test a short export.

Prepare a separate web thumbnail with the TDS image compressor.
