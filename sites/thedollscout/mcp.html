Call these tools from your AI assistant

We already publish the data and the rules. This makes them callable: an assistant can ask with your numbers and get the same answer this site would give, including the parts we could not verify.

Endpoint: https://thedollscout.com/mcp — Model Context Protocol over streamable HTTP. No key, no account, no rate limit worth documenting. Open it in a browser to see the tool list.

What makes this different from an API over a spreadsheet

No rule is reimplemented in the endpoint. Every answer is read from the published JSON at request time — the same files behind the dataset, the recourse matrix and the cost model. If those change, the endpoint changes with them, or it stops answering. It cannot quietly disagree with the pages, because there is no second copy of the rules to drift.

Every answer carries its caveats. The recording date, the dataset's stated limitations, the open questions. A tool that returns a bare number strips exactly the context a careful page spent paragraphs establishing, and the caller has no way to know what was dropped.

It refuses. Ask about a height we have no listings for and it says so and lists the heights it does have. Ask about Section 75 outside the UK and it returns "not verified" — never a clean "no", because that would be a claim about your country's law that we have not checked.
