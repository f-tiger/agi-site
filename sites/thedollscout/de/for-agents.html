TDS / MCP

Sammelwerkzeuge für KI-Assistenten

TDS-Sammelwerkzeuge mit einem MCP-kompatiblen Assistenten finden, lesen und aufrufen.

Remote-MCP-Server verbinden

Diese URL in einem Client mit Remote-MCP-Unterstützung hinzufügen. Für die öffentlichen, nur lesenden Werkzeuge sind weder Konto noch API-Schlüssel nötig. Einrichtung und Verfügbarkeit hängen vom Client ab; der Katalog allein aktiviert keine Verbindung.

Was der Assistent nutzen kann

Die folgenden englischen Namen und Beschreibungen sind die originalen Protokollfelder.

labubu_rarity_odds

Commonly reported secret/chase odds for Labubu / The Monsters blind-box series, by series format (6-figure, 12-figure, collabs, glow variants), with per-row sources. The box-printed odds for a specific series outrank every row returned here, and the result says so.

{
  "type": "object",
  "properties": {},
  "additionalProperties": false
}
labubu_fake_signals

The eight authenticity checks for a Labubu figure (teeth count, face finish, box finish, anti-counterfeit seal, figure markings, build quality, price floor, seller of record), each with its named public sources. Compiled signals, not a guarantee; limitations are included.

{
  "type": "object",
  "properties": {},
  "additionalProperties": false
}
secret_pull_probability

Probability of pulling at least one secret across N blind boxes at printed odds of 1-in-oddsN, plus the box counts a 50% and 90% chance require. Independent single-box model — sealed whole-case allocation can differ, and the result carries that caveat.

{
  "type": "object",
  "properties": {
    "oddsN": {
      "type": "integer",
      "description": "The N in printed odds 1:N, e.g. 72",
      "minimum": 2,
      "maximum": 100000
    },
    "boxes": {
      "type": "integer",
      "description": "Number of blind boxes to be opened, e.g. 12",
      "minimum": 1,
      "maximum": 100000
    }
  },
  "required": [
    "oddsN",
    "boxes"
  ],
  "additionalProperties": false
}
define_labubu_term

Plain-language definition of a Labubu / blind-box collecting term (blind box, series, regular, secret/chase, printed odds, case, glow variant, vinyl plush pendant, Lafufu, seller of record). Matches the term or its aliases; an unknown term returns the list of available terms, honestly.

{
  "type": "object",
  "properties": {
    "term": {
      "type": "string",
      "description": "The term to define, e.g. 'lafufu' or 'printed odds'",
      "maxLength": 120
    }
  },
  "required": [
    "term"
  ],
  "additionalProperties": false
}
calculate_style_probability

Calculate independent-box chances for one regular style, a secret, or a user-supplied per-style probability. Required by mode: regular needs regularStyles and secretOddsN; secret needs secretOddsN; printed needs probabilityPercent. Regular mode assumes equally likely regular styles and replacement by a secret; not official series odds or sealed-case allocation.

{
  "type": "object",
  "properties": {
    "target": {
      "type": "string",
      "enum": [
        "regular",
        "secret",
        "printed"
      ]
    },
    "boxes": {
      "type": "integer",
      "minimum": 1,
      "maximum": 100000
    },
    "regularStyles": {
      "type": "integer",
      "minimum": 1,
      "maximum": 1000
    },
    "secretOddsN": {
      "type": "integer",
      "minimum": 2,
      "maximum": 100000
    },
    "probabilityPercent": {
      "type": "number",
      "minimum": 0,
      "maximum": 100
    }
  },
  "required": [
    "target",
    "boxes"
  ],
  "additionalProperties": false
}
find_collector_tools

Find TDS collecting tools and guides by task. Returns canonical links, supported languages, inputs and which functions MCP can actually call. Browser-only collection records are never read.

{
  "type": "object",
  "properties": {
    "task": {
      "type": "string",
      "enum": [
        "all",
        "odds",
        "display",
        "collection",
        "guides"

      "default": "all"
    },
    "language": {
      "type": "string",
      "enum": [
        "en",
        "de",
        "zh"
      ],
      "default": "en",
      "description": "Interface language; some browser-only tools are available only in EN/DE."
    }
  },
  "additionalProperties": false
}

Ihre Sammlung bleibt privat

Der Server kann weder lokale Sammlungen noch Cloud-Konten, private Dateien oder Mitgliedschaften lesen. Sammlung und digitale Dateiwerkzeuge laufen auf ihren eigenen Browserseiten. Der Katalog liefert Links und Anforderungen, keine behauptete Remote-Ausführung.

Auffindbarkeit ist ein Einstieg

Öffentliche Seiten, Klartext und MCP-Katalog helfen kompatiblen Diensten, die Werkzeuge zu finden. Suchaufnahme, Empfehlung und Erlaubnis zum Werkzeugaufruf sind getrennte Schritte und werden hier nicht garantiert.
