Collector data, current MCP tools and historical Labubu datasets.

This page separates the current multi-brand remote MCP contract from older Labubu-only JSON snapshots. Each dataset keeps its original recording date; updating this page does not refresh the underlying odds or authenticity signals.

Current multi-brand MCP

The published server contract is 2.4.0 over remote Streamable HTTP. A compatible MCP host can connect to https://thedollscout.com/mcp. This is a hosted endpoint, not an npm package or local stdio command; client support varies. Use the connection guide and tool limitations before adding it.

Discovery: MCP Registry manifest · well-known discovery manifest · tool catalog · source-checked series catalog.

Tools exposed by the current contract

  • labubu_rarity_odds — historical, source-linked reported odds; a specific box's printed odds take precedence.
  • labubu_fake_signals — source-linked authenticity indicators, not a guarantee of authenticity.
  • secret_pull_probability — independent-draw math using stated odds; sealed-case allocation can differ.
  • define_labubu_term — plain-language collecting definitions with source dates.
  • calculate_style_probability — calculations from explicit inputs and model assumptions, not official odds.
  • find_collector_tools — returns links and capability limits; browser-only tasks are not executed remotely.
  • get_collecting_guide — source-linked guides for supported brands, with review dates and limitations.
  • plan_display_fit — a single-layer rectangular fit estimate, not 3D packing or a load/safety certificate.
  • compare_blind_box_budget — arithmetic on supplied cost inputs, not live prices or inventory.
  • estimate_collection_progress — an assumption-based estimate, not a guaranteed pull or collection outcome.

Published MCP resources

  • learning-guides.json — practical guides with official source links.
  • tool-capabilities.json — tool capabilities, inputs and execution boundaries.
  • brand-guides.json — published brand guides.
  • document-assets/tool-capabilities.json — existing browser-only digital tools, not remotely executed by MCP.

The MCP is read-only: it cannot read or edit a checklist stored in your browser, upload a private collection, or sync records across devices. It does not provide live stock, current prices, resale valuation, guaranteed authentication or affiliate links.

Historical Labubu datasets (CC BY 4.0)

These four JSON snapshots were recorded on the dates shown below. They are not a live product feed and do not establish current stock, price, popularity or manufacturer odds. Use the specific box's printed odds and the manufacturer's current guidance for the product in hand.

rarity-odds.json

Historical reported secret/chase rates by Labubu format, with per-row source links and stated model caveats. Recorded 2026-08-30; a specific box's printed odds take precedence.

labubu-fake-signals.json

Eight source-linked authenticity indicators with stated limitations. Recorded 2026-08-30; these signals do not certify an item as genuine.

labubu-glossary.json

Ten collecting terms and aliases from the Labubu glossary. Recorded 2026-08-30.

pull-math.json

Example box and case sizes computed from rarity-odds.json; no second source for odds and no claim about current availability. Recorded 2026-08-31.
