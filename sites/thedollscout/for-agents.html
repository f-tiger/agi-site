Collection checklists for your AI assistant

Ask your assistant to find a SMISKI or Sonny Angel series, compare the figures you own, and return a sourced checklist you can use in the conversation.

Use TDS to find the SMISKI Museum series. I own Smiski Dali and Smiski Pearl Earring. Show the catalog names I have not marked as owned, with the source and check date. Only Smiski Bacchus is on my wishlist. Return a copyable checklist and keep any unrecognized names unresolved.
Connect a remote MCP server

Connect a remote MCP server

In a client that supports remote MCP, add this URL. No account or API key is needed for these read-only public tools. Setup and connector availability depend on your client; adding a catalog does not enable a connection automatically.

https://thedollscout.com/mcp

Connect with Claude Code

With Claude Code installed, run this in the terminal for your current project, then inspect the connection. The first command adds the configuration; it is not proof of a successful tool call.

claude mcp add --transport http tds https://thedollscout.com/mcp
claude mcp get tds

In Claude Code, open /mcp to check the server and its tools, then send the collection request above. Client availability, plan requirements and organization rules may differ.

Try a collection task

Use TDS to find the SMISKI Museum series. I own Smiski Dali and Smiski Pearl Earring. Show the catalog names I have not marked as owned, with the source and check date. Only Smiski Bacchus is on my wishlist. Return a copyable checklist and keep any unrecognized names unresolved.

Find the exact series

Call search_collection_series first. Use a returned seriesId and the source names for the comparison.

{
  "name": "search_collection_series",
  "arguments": {
    "query": "Museum",
    "brand": "smiski",
    "limit": 5,
    "language": "en"
  }
}

Prepare the checklist

These are tools/call parameters. Only explicitly supplied wanted names become the wishlist; an unmarked figure is not automatically a purchase request.

{
  "name": "prepare_collection_checklist",
  "arguments": {
    "seriesId": "smiski-museum",
    "owned": [
      "Smiski Dali",
      "Smiski Pearl Earring"
    ],
    "wanted": [
      "Smiski Bacchus"
    ],
    "language": "en"
  }
}

What your assistant can use

These names and descriptions are the exact public tool contract.

labubu_rarity_odds

Commonly reported secret/chase odds for Labubu / The Monsters blind-box series, by series format (6-figure, 12-figure, collabs, glow variants), with per-row sources. The box-printed odds for a specific series outrank every row returned here, and the result says so.

{
  "type": "object",
  "properties": {},
  "additionalProperties": false
}
labubu_fake_signals

The eight authenticity checks for a Labubu figure (teeth count, face finish, box finish, anti-counterfeit seal, figure markings, build quality, price floor, seller of record), each with its named public sources. Compiled signals, not a guarantee; limitations are included.

{
  "type": "object",
  "properties": {},
  "additionalProperties": false
}
secret_pull_probability

Probability of pulling at least one secret across N blind boxes at printed odds of 1-in-oddsN, plus the box counts a 50% and 90% chance require. Independent single-box model — sealed whole-case allocation can differ, and the result carries that caveat.

{
  "type": "object",
  "properties": {
    "oddsN": {
      "type": "integer",
      "description": "The N in printed odds 1:N, e.g. 72",
      "minimum": 2,
      "maximum": 100000
    },
    "boxes": {
      "type": "integer",
      "description": "Number of blind boxes to be opened, e.g. 12",
      "minimum": 1,
      "maximum": 100000
    }
  },
  "required": [
    "oddsN",
    "boxes"
  ],
  "additionalProperties": false
}
define_labubu_term

Plain-language definition of a Labubu / blind-box collecting term (blind box, series, regular, secret/chase, printed odds, case, glow variant, vinyl plush pendant, Lafufu, seller of record). Matches the term or its aliases; an unknown term returns the list of available terms, honestly.

{
  "type": "object",
  "properties": {
    "term": {
      "type": "string",
      "description": "The term to define, e.g. 'lafufu' or 'printed odds'",
      "maxLength": 120
    }
  },
  "required": [

calculate_style_probability

Calculate independent-box chances for one regular style, a secret, or a user-supplied per-style probability. Required by mode: regular needs regularStyles and secretOddsN; secret needs secretOddsN; printed needs probabilityPercent. Regular mode assumes equally likely regular styles and replacement by a secret; not official series odds or sealed-case allocation.

{

  "properties": {

      "type": "string",
      "enum": [
        "regular",
        "secret",
        "printed"

    "boxes": {

      "minimum": 1,
      "maximum": 100000
    },
    "regularStyles": {
      "type": "integer",
      "minimum": 1,
      "maximum": 1000
    },
    "secretOddsN": {
      "type": "integer",
      "minimum": 2,
      "maximum": 100000
    },
    "probabilityPercent": {
      "type": "number",
      "minimum": 0,
      "maximum": 100

prepare_collection_checklist

Does not assume missing means wanted, infer quantities or trade intent, certify a complete set, or access browser storage. Use exact names from search_collection_series. Supplied lists are processed remotely but not saved by the tool.

      "type": "string",

You choose what to send

The assistant sends the names you choose to the TDS MCP server to prepare the result. TDS does not save those arguments or include them in its usage telemetry; successful calls may record only a fixed tool name and result category. Your assistant provider has its own data handling. MCP cannot read or update your browser collection, private files, account or membership. Browser tracking and backups remain separate.
