# DollScout 推广方案（渠道 / 自动化 / 节奏）

## 一、先说结论：为什么不能靠投流

| 渠道 | 可行性 | 说明 |
|---|---|---|
| **Google Ads** | ❌ 基本不可行 | Google 把成人用品（Shopping 政策明确点名 sex toys）列为 restricted adult content；仅在有限国家、强制年龄门、落地页无露骨内容时才可能过审。叠加联盟站还要面对 bridge page（导流页）政策，实际过审率极低，反复违规直接封户。 |
| Meta / TikTok Ads | ❌ 不可行 | 成人用品广告全面禁止。 |
| 成人广告网络（ExoClick / TrafficJunky 等） | ⚠️ 可行但不匹配 | 流量来自成人视频站，用户处于消费内容而非采购决策状态，与本站"高客单价决策辅助"定位错配，CPA 高、退出率高。**不建议在有自然流量之前烧钱。** |
| **SEO（自然搜索）** | ✅ 主战场 | 本品类搜索意图极强（"is X legit"、"tpe vs silicone"、"import sex doll to UK"），且广告被禁 = 竞争对手也买不到量，自然位价值被放大。 |
| **社区（Reddit / 论坛）** | ✅ 高价值 | 本品类用户原声几乎全在社区。工具型内容（防诈清单、成本计算器）是社区愿意自发引用的东西。 |
| **邮件列表** | ✅ 唯一自有资产 | 平台会封、算法会变，邮件不会。本品类用户极重隐私，匿名发件是关键。 |

**核心判断：广告封杀对我们是利好而非利空**——它把所有竞争者都赶回自然渠道，而我们的差异化（工具 + 透明方法论）恰恰是自然渠道最吃的东西。

### 已执行的 SEO 修复（2026-07）

审计发现并已修掉三类问题：

1. **28 个页面标题全部超长**（63–87 字符，Google 约 60 截断）→ 全部重写至 ≤53 字符，关键词前置；描述统一压到 ≤153。国别页改在 `scripts/build-pages.mjs` 生成器里，新增国家自动继承。
2. **内链严重不均**。导航页各 27 个内链，而 `guides/import-costs-2026.html`（本站最强外链磁铁）只有 2 个，日/马/新/韩国别页各只有 1 个。修法：每个国别页链向列表中后续 3 个国家（环绕，故每页恰好被 3 个页面链接），4 篇 guides 的"Keep reading"改链 import-costs。结果：import-costs **2 → 17**，国别页 **1 → 4–6**。
3. **两个王牌工具对爬虫是空页**：quiz.html 仅 97 词、cost-calculator.html 仅 181 词（内容全靠 JS 渲染）。已补上真实编辑内容——测验页解释"为什么先问重量"和四种结果的实际含义，计算器页拆解五类隐藏成本与估算方法。**quiz 97 → 743 词，calculator 181 → 774 词。**

审计现为零问题、零死链、零孤儿页。

### GEO（AI 搜索优化）—— 2026-07 已执行

这是本站被严重低估的渠道。逻辑：**广告在本品类全线被禁**，而"这家店靠谱吗"这类问题正在从搜索框迁移到 AI 助手。被 AI 引用是竞争对手同样买不到的位置，且我们的内容天生适合被引用（具体日期、政府来源、公开标准）。

| 动作 | 实现 |
|---|---|
| **显式欢迎 AI 爬虫** | `robots.txt` 逐个具名放行 GPTBot / OAI-SearchBot / ClaudeBot / PerplexityBot / Google-Extended / Applebot-Extended。**同品类多数站点选择屏蔽，我们反向操作** |
| **`llms.txt` 结构化索引** | `scripts/build-llms.mjs` 自动生成（手写必然漂移，过期索引比没有更糟）。前言部分是关键——它明确列出**最常被别处写错的可核查事实**，决定了 AI 总结本站时会总结出什么 |
| **schema 日期** | 此前全站零日期。旗舰资产是一条有日期的法规更正，**无日期的断言不可被引用**。生成器用常量而非构建时间——每次部署都盖"今天"等于虚报新鲜度 |
| **FAQPage schema** | 新增 `faq.html`（14 问 1736 词）+ quiz 页。每个回答都写成**自包含**形态，因为那才是会被整段引用的形式 |

### YouTube:被低估的发现渠道（2026-07-28 调研确认）

广告封杀的是**投放**,不是**内容**。调研确认本品类在 YouTube 有活跃创作者生态(AllYourDolls、DollLab 及多个开箱评测播放列表)。这些人已经有受众,而他们的观众每期都问同样三件事:**这家店靠谱吗 / 多重 / 关税多少**——我们三样都有现成答案。

因此 0→1 的打法不是我们去发内容,而是**让已有受众的人愿意引用我们**:

- **`/for-creators.html`** —— 分发资产。可直接粘贴的 YouTube 简介、论坛回答、Discord 短句、可嵌入的清单代码。
- **关键设计:所有 snippet 一律不含分销链接,也不要求署名。** 一个悄悄替别人受众变现的 snippet,对方理应拒绝;不含分销链接才是它会被真正使用的原因。已用"解析 URL 查询参数"的方式校验(不是子串匹配),确认 7 条 URL 全部无 `ref`/`tag`/`utm` 参数、全部指向本站。
- 从 scam-check、checklist、weight chart、trust 四处入口链入。

**这条渠道你需要做的**:找到上述创作者,以真人身份联系,提供数据(不是求链接)。页面已经把"给什么"准备好了。
