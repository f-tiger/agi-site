# Collection checklists for your AI assistant

https://thedollscout.com/for-agents
Content updated: 2026-10-31

Ask your assistant to find a SMISKI or Sonny Angel series, compare the figures you own, and return a sourced checklist you can use in the conversation.

In a client that supports remote MCP, add this URL. No account or API key is needed for these read-only public tools. Setup and connector availability depend on your client; adding a catalog does not enable a connection automatically.

https://thedollscout.com/mcp

Try a collection task

Use TDS to find the SMISKI Museum series. I own Smiski Dali and Smiski Pearl Earring. Show the catalog names I have not marked as owned, with the source and check date. Only Smiski Bacchus is on my wishlist. Return a copyable checklist and keep any unrecognized names unresolved.

Find the exact series

Call search_collection_series first. Use a returned seriesId and the source names for the comparison.

{"name":"search_collection_series","arguments":{"query":"Museum","brand":"smiski","limit":5,"language":"en"}}

Prepare the checklist

These are tools/call parameters. Only explicitly supplied wanted names become the wishlist; an unmarked figure is not automatically a purchase request.

{"name":"prepare_collection_checklist","arguments":{"seriesId":"smiski-museum","owned":["Smiski Dali","Smiski Pearl Earring"],"wanted":["Smiski Bacchus"],"language":"en"}}

Example result from the current named catalog

Marked owned: Smiski Dali, Smiski Pearl Earring

Not marked owned: Smiski The Source, Smiski Fuzin&Raijin, Smiski Bacchus, Smiski Vela’zquez

Explicit wishlist: Smiski Bacchus

Official series source: https://smiski.com/e/products/museumseries/

Source checked: 2026-10-30

This compares the named figures verified in TDS, not every item ever released. Secret figures or variants may be absent. It cannot certify a complete set, ownership, authenticity, stock or value. Repeated name inputs are not duplicate-figure quantities or trade offers.

Example only. Reading this page does not call a tool, save a collection or count as a completed collection task.

Connect with Claude Code

With Claude Code installed, run this in the terminal for your current project, then inspect the connection. The first command adds the configuration; it is not proof of a successful tool call.

claude mcp add --transport http tds https://thedollscout.com/mcp
claude mcp get tds

In Claude Code, open /mcp to check the server and its tools, then send the collection request above. Client availability, plan requirements and organization rules may differ.

secret_pull_probability: Probability of pulling at least one secret across N blind boxes at printed odds of 1-in-oddsN, plus the box counts a 50% and 90% chance require. Independent single-box model — sealed whole-case allocation can differ, and the result carries that caveat.

prepare_collection_checklist: Compare user-supplied distinct owned names with one verified series. The assistant sends the names you choose to the TDS MCP server to prepare the result. TDS does not save those arguments or include them in its usage telemetry; successful calls may record only a fixed tool name and result category. Your assistant provider has its own data handling. MCP cannot read or update your browser collection, private files, account or membership. Browser tracking and backups remain separate.

Public pages, text mirrors and the MCP catalog help compatible services discover the tools. Search inclusion, a recommendation and permission to call a tool are separate; none is guaranteed by this page.
