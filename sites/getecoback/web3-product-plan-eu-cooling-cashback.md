## 〇、竞对调研结论（先调研，再判断方案是否合适——CLAUDE.md强制流程）

**验证过的市场信号（非假设）：**
- 2026年欧洲创纪录热浪期间，三星/美的/三菱电机空调销量暴涨（德国美的线上销量5月同比+37%，西班牙/法国出货量+108%）；美的PortaSplit便携空调在部分渠道售罄，二手价反超新机，正常售价€900（纯制冷）/€1200（冷暖两用），热浪期间被炒到2-3倍价格；京东国际站空调销量在6月19-25日热浪周环比暴涨近40倍。([CNN](https://www.cnn.com/2026/06/25/asia/europe-heat-wave-air-conditioning-intl-hnk), [Bitget News](https://www.bitget.com/amp/news/detail/12560605480368), [heise online](https://www.heise.de/en/news/Heatwave-in-Germany-Where-to-still-get-a-Midea-Portasplit-11341431.html))
- 厂商明确将便携空调走红归因于"西欧安装成本高（专业安装费用超€1000）、等待周期长、老旧住房多"——用户不是不想要固定安装的空调/热泵，而是被高昂安装成本劝退。热泵单套安装成本2.7万-5万欧元（补贴后仍需1.2万-2.2万欧元），太阳能系统0.7万-3万欧元（带储能可达4万欧元）。([EU Heat Pump Grants Comparison](https://embuild.eu/en/blog/eu-heat-pump-grants-comparison-2026), [SurgePV](https://www.surgepv.com/blog/solar-installation-cost-per-kwp-europe))
- 欧洲空调家庭普及率仅约20%，远低于亚洲/北美水平——这不是一次性热浪红利，是结构性的长期增长空间。([CGTN](https://news.cgtn.com/news/2026-06-29/How-Europe-s-heatwave-is-driving-demand-for-cooling-technology-1OmDdWzGHSw/p.html))

**竞对情况：**
- 加密+可再生能源项目已存在且部分已融资：SolarCoin（2014年至今，按发电量给太阳能业主发代币，已验证"代币奖励能把回本周期缩短6-18个月"）、Glow（以太坊太阳能项目，融资3000万美元）、Fuse Energy（Solana DePIN能源项目，融资7000万美元，估值50亿美元）。全部聚焦**发电端**，没有一个聚焦**消费端**（购买节能家电时的即时返现）。
- 通用加密返现产品已存在（Lolli、Fold、CoinRebates，联盟营销驱动，返现1.5%-30%，平均约7%），但没有专门针对节能家电垂直品类的产品。
- 需求响应聚合商在欧洲需要各国注册认证，流程繁琐成本高——**明确排除这条路径**，不做电网市场参与者。

**结论**：方向成立，锁定在"联盟营销返现工具"这个不需要牌照的法律结构里，不做能源市场参与者。

## 一、目标用户与JTBD

**目标用户分两层：**
- **主力人群（获客引擎）**：西欧（德国/法国/西班牙优先）家庭消费者，在热浪期间紧急购买便携空调等免安装家电，客单价€300-1200
- **高价值人群（利润引擎）**：计划安装热泵/太阳能系统的房主，客单价€1.2万-5万，决策周期长（通常需要多家安装商报价对比）

**JTBD**：用户刚为一次"热浪逼出来的紧急/计划外大额消费"花了钱，情绪上希望"觉得自己占了便宜"；传统厂商返现（mail-in rebate）流程慢、体验差。这个需求当下真实存在、有情绪驱动力。

**为什么比上一版扎实**：上一版（多客户对账）JTBD弱（Excel就能解决）、TAM窄（中文+多客户USDT收款双重限定）。这一版JTBD强（占便宜的情绪+即时到账体验优势）、TAM大且数据验证过（欧洲空调普及率仅20%，热泵/太阳能是政策+气候双重驱动的确定性增长市场）。

## 二、产品方案

### 2.1 双轨产品结构（核心设计）

调研中发现一个此前遗漏的关键差异：便携空调这类家电走标准电商结算流程，适合"联盟营销+即时返现"；而热泵/太阳能是**报价制、多点触达的销售流程**（用户找安装商上门评估、比价，不是电商下单），需要用**线索推荐（lead-gen）**模式而不是"购买后返现"模式。这两条轨道互补，构成完整产品：

| | 轨道A：轻量返现（获客引擎） | 轨道B：线索推荐（利润引擎） |
|---|---|---|
| 品类 | 便携空调、除湿机、小型风扇类 | 热泵、太阳能、分体空调安装 |
| 转化动作 | 点击联盟链接→电商平台下单 | 提交安装咨询表单→匹配认证安装商 |
| 变现方式 | 联盟佣金分成（3.5%-9%） | 每条有效线索固定费用（€30-150，参考法国Selectra/Effy等能源线索平台的行业惯例） |
| 客单价 | €300-1200 | €1.2万-5万 |
| 决策周期 | 即时/几天 | 数周到数月 |
| 用户返现 | 即时稳定币返现1-3% | 提交咨询即获小额稳定币奖励（如€5-15），成交后额外奖励 |
| 角色 | 高频、高搜索量、热浪新闻周期驱动的流量入口 | 单笔利润远高于轨道A，是真正的营收支柱 |

**产品逻辑**：轨道A用热浪热点内容吸引流量、建立"这个平台真给我返钱"的信任，再把同一批用户导流到轨道B（"你买了便携空调应急，要不要顺便测算一下装热泵能拿多少补贴+返现"），这是classic的"低价钩子产品导流高价值产品"打法，同时也是产品自身实现"复利"（老用户能反复变现，而不是获客即用完即走）的关键设计。

### 2.2 详细用户旅程

**轨道A（轻量返现）：**
1. 用户通过内容/搜索/社群找到网站或安装浏览器插件
2. 网站展示"当前欧洲各大零售商便携空调返现榜单"（MediaMarkt、Otto、Amazon等，标注返现比例、库存状态）
3. 用户点击跳转，在零售商官网完成购买（不改变用户熟悉的结账流程，降低信任门槛）
4. 联盟网络回传转化数据，系统记录待确认订单
5. 等待联盟网络的佣金确认期（通常30-90天，需在产品里向用户清晰说明，避免"钱怎么还没到账"的客诉）
6. 确认后，用户绑定钱包（或用托管余额，降低小白用户的钱包门槛），领取稳定币返现
7. 领取后触发：（a）转介绍邀请弹窗（好友通过链接购买，双方各得额外奖励）（b）轨道B的定向推荐（"看看装热泵能省多少"）

**轨道B（线索推荐）：**
1. 用户从轨道A导流，或直接通过"热泵安装到底要花多少钱""补贴申请指南"类内容进入
2. 填写简单表单（房屋类型、地区、预算范围）
3. 系统即时发放小额稳定币奖励（激励用户完成表单，降低表单填写这个高摩擦动作的心理门槛）
4. 系统把线索分发给2-3家认证安装商（安装商付费买线索）
5. 安装商联系用户报价，若最终成交，安装商向平台支付成交奖金，用户获得额外稳定币奖励

### 2.3 技术架构（MVP阶段，尽量用现成组件）

- **前端**：轻量网站（内容+返现榜单+表单）优先于浏览器插件（插件安装摩擦大，MVP阶段先用网站验证需求，插件作为V2留存工具）
- **联盟追踪**：接入Awin/CJ/Rakuten Advertising的postback/API，记录点击-转化归因
- **钱包与发放**：Coinbase/Circle API处理稳定币发放，优先选择Base/Polygon等L2（网络费用低于$0.01/笔，批量发放可把200笔交易的手续费从$2500压缩到$380左右），小额返现的链上成本不是问题
- **托管余额选项**：为不熟悉加密钱包的用户提供"先托管，攒够再提现"选项，降低小额返现的链上摩擦和心理门槛
- **数据看板**：内部记录转化漏斗、留存、复购数据，为后续数据资产变现打基础

### 2.4 产品路线图

| 阶段 | 内容 |
|---|---|
| V1（MVP，0-3个月） | 轨道A网站+联盟接入+稳定币发放，验证核心转化漏斗 |
| V2（3-6个月） | 加入轨道B线索表单+安装商匹配，浏览器插件，转介绍机制 |
| V3（6-12个月） | 多语言扩展（法语/西班牙语/意大利语）、数据看板产品化（对B端销售）、可能的订阅制"深度比价+优先返现"付费层 |

## 三、营销策略

### 3.1 定位与信息传递

核心信息："热浪让你多花的钱，我们帮你省回来一部分——而且是秒到账，不用等厂商寄支票。" 定位锚点是"应对气候变化带来的意外支出"，这比单纯"加密货币返现"更有情绪穿透力，也让加密货币的novelty成为一个正向差异化点而不是理解门槛。

### 3.2 内容与SEO（主渠道，符合无渠道资源的现实）

内容方向直接对应真实、当下的搜索需求（这轮热浪已经证明了这些搜索词的存在）：
- "欧洲热浪买空调避坑指南"、"Midea PortaSplit哪里还有货/最划算"类实时性内容——蹭当下的搜索流量高峰
- "热泵安装到底要花多少钱""各国热泵补贴对比"类长尾内容——为轨道B打基础，搜索意图更精准、转化率更高
- 语言优先级：先做英语（覆盖面最广，欧洲多国受众都能读），验证后再投入德语/法语本地化（这两个是热浪+安装成本痛点最集中的市场）

### 3.3 PR角度

当前热浪本身正在被CoinDesk、DL News等加密媒体报道（因为空调厂商股价、供应链成为财经新闻热点），可以主动向这类媒体投递"首个专门针对气候驱动型家电消费的加密返现产品"这个新闻角度，蹭现成的新闻周期，不需要自己制造话题。

### 3.4 社群与联盟合作

- 目标社群：欧洲本地房产/装修论坛、Reddit的r/HVAC及各国子版块、Facebook本地生活/装修群组、比价网站（idealo.de、Check24等）的内容合作
- 不做冷启动阶段的付费广告（CAC不可控，且没有预算验证过的转化率支撑广告投放决策），优先内容+社群渗透

### 3.5 转介绍机制（内建增长循环）

参考行业基准：电商类转介绍计划中位转化率3-5%，头部达8%以上；双边奖励（推荐人和被推荐人都得奖励）的转介绍计划占比78%，且现金/折扣类奖励比积分类奖励转化率高约40%。产品设计上，每次领取返现后主动弹出转介绍邀请，奖励用稳定币直接发放（比积分更有吸引力），这是获客成本随用户规模增长而下降的关键杠杆。

## 四、获客漏斗与增长模型

**漏斗结构：**

内容/搜索/社群曝光 → 网站访问 → 联盟链接点击（轨道A）/表单填写（轨道B）→ 确认转化（轨道A需等待30-90天佣金确认期；轨道B即时确认线索有效性）→ 返现/奖励发放 → 复购或转介绍

**关键假设与需要验证的指标（MVP阶段的核心工作就是拿真实数据填这张表，而不是假设）：**

| 指标 | 行业参考基准 | 说明 |
|---|---|---|
| 内容访问→点击/填表 | 待验证 | 需通过前3个月真实内容测试获得 |
| 联盟点击→确认转化 | 电商平均1-3% | 取决于零售商自身转化率，非平台可控 |
| 转介绍转化率 | 中位3-5%，头部8%+ | 来自转介绍的leads转化率是其他渠道的5倍 |
| 病毒系数（K因子） | 0.15-0.25为健康水平 | 双边奖励+现金类奖励是提升K因子的关键杠杆 |

**增长循环设计**：内容获客（慢但免费）→ 首批用户产生真实转化数据 → 数据反哺内容优化（哪些品类/地区转化率高就加大投入）→ 转介绍机制放大存量用户价值 → 规模化后用早期数据去谈更好的联盟佣金位（网络通常给高流量发布者更优惠费率），形成正循环。

## 五、商业化与单位经济模型

### 5.1 双轨营收模型

**轨道A（联盟佣金差）：**
- 电子家电类目联盟佣金率3.5%-9%（保守取4%）
- 便携空调AOV约€900-1200，按€1000计算：联盟佣金约€40
- 支付用户返现2%（€20）
- 每单毛利约€20（未扣除链上手续费<$0.01、托管/发放系统运营成本）

**轨道B（线索推荐费）：**
- 参考法国Selectra/Effy等能源线索平台行业惯例，每条有效线索€30-150
- 保守取€50/条线索
- 支付用户提交奖励€10 + 成交额外奖励€20（若成交）
- 每条线索毛利约€40（未成交）到€20（成交，因为需要多付成交奖励，但安装商愿付的成交线索费通常远高于普通线索费，实际毛利需要谈判后验证）

**轨道B单条毛利是轨道A单笔毛利的2倍，且客单价是轨道A的10-40倍，这是长期利润的真正来源，轨道A的角色是低成本获客入口。**

### 5.2 定价策略

- 用户侧：透明展示返现比例/线索奖励金额，不做隐藏门槛
- 安装商侧（轨道B）：线索费按季度根据平台带来的实际成交率动态调整，早期为了拿到第一批安装商合作，可以先用较低的线索费（如€30）换取安装商愿意尝试新渠道，验证转化后再提价

### 5.3 后续营收层（V3阶段）

1. **数据资产变现**：向ESG报告机构、家电制造商（需求预测）、碳信用核算机构出售脱敏聚合数据
2. **订阅制**：面向重度用户（比如同时装太阳能+热泵+多台空调的用户）的"优先返现+深度比价"付费层
3. **白标授权**：验证模型后，把"稳定币返现引擎"授权给其他垂直领域（如新能源汽车充电桩安装）复用，这是把单一产品跑通后的横向复制路径

## 六、财务预测（情景推演，用于规划假设验证，不是承诺）

以下是粗略情景模型，用于判断"这门生意值不值得投入"的量级判断，所有数字需要在执行过程中用真实数据替换：

**保守情景（第6个月）：**
- 轨道A：月500笔确认转化 × €20毛利 = €10,000/月毛利
- 轨道B：月50条有效线索 × €30毛利 = €1,500/月毛利
- 合计约€11,500/月毛利（未扣除内容制作、工具订阅等运营成本）

**中性情景（第12个月，转介绍循环开始发挥作用）：**
- 轨道A：月2000笔确认转化 × €20 = €40,000/月毛利
- 轨道B：月200条有效线索 × €35（含部分成交奖金调整后均值）= €7,000/月毛利
- 合计约€47,000/月毛利

**关键假设风险**：这些数字高度依赖内容获客的实际转化率和联盟网络的实际佣金率，MVP阶段（前3个月）的核心任务就是拿真实数据校准这张表，而不是把这些数字当作既定目标去倒推资源投入。

| 第6-9周 | 内容+SEO冷启动 | 围绕真实热点搜索需求做内容，目标获取第一批100-500个真实用户，拿到第一批真实转化率数据 |
| 第10-13周 | 转化验证+轨道B准备 | 验证轨道A漏斗数据；同步接触2-3家热泵/太阳能安装商（欧洲本地中小安装商，非大品牌），验证线索推荐模式的意愿和价格 |
| 第4-6个月 | 轨道B上线 | 线索表单+安装商匹配上线，加入转介绍机制，浏览器插件开发 |
| 第7-9个月 | 规模化获客 | 基于验证过的转化数据，评估是否值得投入小额付费获客测试；启动德语/法语内容本地化 |
| 第10-12个月 | 数据资产层 | 开始接触ESG报告/家电制造商，探索数据变现的第一批合作，评估白标/横向复制可行性 |

## 八、复利如何形成（对照孙宇晨模式的核心结论）

不追求"发行权+做市权一体化"（需要牌照），对应"多业务闭环互相导流 + 数据资产随时间积累增值"这条规律：

1. **第一层（单人价值，第1天就有）**：消费者用网站买东西拿到即时返现，不需要任何B2B关系就能上线。
2. **第二层（双轨互导，几个月后）**：轨道A的高频低价值用户被导流进轨道B的低频高价值场景，同一个用户在平台上产生两次变现，而不是获客即用完即走。
3. **第三层（转介绍循环，规模化中）**：双边奖励的转介绍机制让获客成本随用户规模增长而下降，这是复利的第一个具体体现——早期用户带来的边际成本比后期更高。
4. **第四层（数据资产复利，规模化后）**：平台积累"哪些型号真被买、真实线索转化率如何"的验证过数据集，可以卖给ESG报告、家电制造商需求预测机构，形成不依赖持续获客的第二增长曲线。

## 九、风险清单与应对

1. **销售旺季窗口期风险**：热浪驱动的需求高峰可能是阶段性的，需要用最快速度（5周内）上线轨道A验证，而不是追求完美产品再上线。
2. **稳定币返现的合规边界**：需要跟每个目标市场（德国/法国/西班牙优先）确认，加密货币返现是否触发当地对促销/反洗钱的额外披露要求，需要基础法律咨询确认。
3. **联盟网络准入风险**：部分联盟网络对新发布者/个人账号有审核门槛，需要在第1-2周实际申请时验证，至少申请两个以上网络，不要单点依赖。
4. **佣金率被平台方压缩的风险**：联盟网络可以随时调整佣金率，第四层的数据资产复利正是为了在验证期之后建立不完全依赖联盟佣金的第二收入来源。
5. **轨道B的安装商冷启动风险**：安装商是否愿意为"未经验证的新渠道"付费，是轨道B能否跑通的关键，需要先用免费/低价试用换取第一批案例背书，再规模化定价。
6. **佣金确认期拉长现金流/信任问题**：联盟网络30-90天的佣金确认期意味着用户从购买到拿到返现有较长等待，需要在产品体验上提前清晰说明预期，避免用户流失或投诉。
7. **财务预测假设风险**：第六节的数字是规划用的粗略情景，不是承诺，需要在前3个月用真实转化数据校准。
