## Common questions

### Does this tool submit anything to the EU?

No. It only prepares a local coordination checklist. Use the official registry for official actions.

### Is shared data automatically verified?

No. Registry sharing is not independent verification. If using actual emissions, consult the Commission's rules for accredited independent verifiers; this checker cannot verify emissions.

### Does a missing verification report in September 2026 prove a failure?

No. The Commission's published timeline places the first verification reports in January 2027. Ask for the status and expected availability, rather than assuming a report must already exist.

### What should I ask my supplier to send next?

Start with one installation and reporting period. Ask for the sharing recipient, retrieval status and, where actual emissions are planned, the verification owner and report status. Use the free request template and an agreed secure channel.

## CBAM data shared but not verified: what to request

Treat this as a coordination question, not a failed-compliance verdict. The next step depends on where the handoff stopped.

### Record not visible

Confirm the installation, reporting period and intended recipient together. A resent spreadsheet does not show that the right registry record is visible.

### Record visible, verification unclear

If actual emissions are planned, identify the verification owner and report status. Sharing a record does not replace an accredited independent verifier.

### Report not yet available

Record the planned next step and expected availability. The Commission's timeline puts first reports in January 2027; do not mark an absent report in September 2026 as an automatic failure.
