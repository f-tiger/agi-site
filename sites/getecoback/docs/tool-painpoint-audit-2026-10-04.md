# Tool task audit — 4 October 2026

The audit covers 56 public tool pages (including localized versions) and nine standalone workbench task pages. Blank legacy inputs previously produced default-based answers, some moisture explanations overclaimed what air-only models can establish, and edited inputs could leave stale exports available.

The release adds shared validation and stale-result handling to 17 legacy calculators, separates cellar drying from condensation risk, permits warmer measured surfaces, corrects air-capacity and cold-room model explanations, and directs generic electricity results toward measurement before purchasing. Country, household, professional and compliance flows invalidate stale results; compliance Markdown downloads use real newlines. Five narrow-screen overflow issues are corrected.

Validation: 402 browser audit checks across 56 pages and three widths; 92 task-flow assertions including nine localized workbench pages; seven Node test files and 39 Python release gates. Existing winter, AU, laundry, buyer-decision, energy-workbench and moisture-analytics suites also passed locally. Full browser engines run in CI. Both new suites block external traffic and API telemetry.

These are usability, formula-boundary and regression checks, not proof of demand or conversion improvement. Sizing remains indicative; moisture tools do not diagnose buildings or health conditions; documentary self-assessments do not certify compliance.
