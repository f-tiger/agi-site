## Source and routes

Canonical source is now `sites/getecoback/data/eu-evidence/`, generated by `tools/build_eu_evidence.py`. Generated pages live at:

Use `https://getecoback.com` for future evidence-tool marketing. Each page has a Markdown mirror, reciprocal language links, FAQ JSON-LD and links from the existing homepage, tool hub, workbench and compliance pages. The original standalone Site is not the target for subsequent ECO changes.

## Design and data boundaries

The layout follows ECO's existing evidence tools: blue navigation and hero (#0a4d7a / #0f6ba8), light background (#f7fafc), white bordered panels, green actions, system typography and single-column mobile layout. Chinese pages have Chinese interface copy and links to existing site-wide legal pages.

The checks run locally, accept no file uploads and send no answers to a backend. The €299 pilot remains indicative with no connected checkout. EcoBack's storage membership remains a separate purchase. No claimed customer or revenue result was added.

Official Commission source pages were rechecked on 2026-09-25 (source links are in the content files). The EUDR date helper now requires product-scope timing as well as organisation category; products newly added by Delegated Regulation (EU) 2026/2102 have a separate 2027-12-30 date. Unknown product timing yields an unknown result.

## Validation

`node tools/test_eu_evidence.cjs --discovery` covers four real checklist flows, answer-change invalidation, local export, clipboard success/failure, EUDR date branches, local links and discoverability. The deploy workflow builds the pages before its standard SEO gates and asserts the four live HTML and Markdown routes, assets, hub and search entries after deployment. Normal site checks also validate language groups and metadata.

The first production build exposed a sitemap-gate timezone mismatch: GitHub's commit retained a -04:00 offset while CI used UTC. Sitemap commit dates and the gate now use the same UTC date from the commit timestamp, with real-git regression fixtures for negative and positive offsets across midnight. The freshness gate remains enabled.
