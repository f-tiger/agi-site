# EcoBack：国家需求、决策界面、学习系统与 AI 引用

目标：增加真正需要解决家庭问题的访问者、有效商家交接和已核验净佣金。实施日期不是增长证据。当前 Windsor 账户数量超过可用计划，返回的占位零值不能训练模型；佣金、订单、退款和 EPC 仍未知。无新增付费服务、外联、社交发送或定时任务；不恢复 Growth Loop、储能或阳台光伏。

## 三轮优化与本轮交付

1. 明确目标：按国家和意图做有用的决策路径，保留维修、测量、不购买等正确答案，不以增加联盟事件次数代替满足需求。
2. 对抗检查：国籍不等于知识水平；德语不等于德国；英语不等于英国；热搜不是购买需求；相似度不是购买概率；页面上线不是增长。当地官方指引、独立用户痛点、确切型号和本地商家资格分别核验。
3. 验收：全站公共入口、移动端和无 JS 可用；国家不能交叉匹配；缺失/陈旧/失败证据不得发布；HTML 与 Markdown 的已有官方来源可追溯；固定事件不含搜索词；保持已有 IndexNow 增量节奏。

已实现：统一任务入口及搜索、四个德国分类页的明确下一步；按国家限定的 TF-IDF 需求检索；现有每日采集增加荷兰与澳洲；十个国家独立约束配置；官方引用链接保留；协商 Markdown 优先使用构建镜像；德国热门阅读过滤机器人和跨市场数据。

没有冒称实现：训练完成的购买预测、实时个性化提价、自动更换联盟商家、北欧批量翻译或已验证营收提升。TF-IDF 是在编辑维护的需求词表上拟合的轻量检索模型，不是大语言模型，也没有购买训练标签。

## 小站到中型站的 UI 与运营规则

参考 co2online 的按任务/季节组织、Topten 的同条件比较、Meaco 的家庭任务导航；借鉴路径，不复制文案、评分或未核验的效果。公开页面不能证明这些站点的转化率。

统一路径：**用户问题 → 直接回答与适用范围 → 少量可选条件 → 2–3 个可比较方案 → 本地商家交接**。账户不是使用工具的前置条件。

- 页面第一屏：一句回答、适用国家、无需填写的示例/任务卡、明确下一步。以住房/问题选择详细程度，不按国籍推断知识水平。
- 中段：并列条件、费用区间、公式和来源；专业细节折叠但可访问；不将同一型号在不同温湿度下的参数强行排名。未知时显示“先测量/检查”，不强推购买。
- 购买前：型号、插头、电压、配送、税费、保修、联盟披露和核验日期。没有当地可验证商家时提供比较依据，不出现错误市场的购买按钮。
- 小站阶段：集中 DE 与 GB 的少数决策簇，修补断链、无结果和错误分流；看完整 14 日，28 日复查。页面数量不是阶段门槛。
- 扩展阶段：只有当地需求、可用工具、可核验商品交接与稳定统计同时成立，才扩 NL/AU；北欧每国独立过门槛。多语言导航只链接真实等价页面。
- 中型站阶段：维护证据到期清单、型号变更、每市场内容负责人/检查规则及失败回退；用需求覆盖和任务成功衡量，不以批量内容数量衡量。

## 站点大脑：现在运行什么，下一阶段需要什么

现有每日流程：公开信号 → 国家/类别/日期/注入检查 → 精确任务匹配，或 TF-IDF 近似检索 → 现有页面及证据检查 → 运行报告。新增 NL/AU 采集复用原来的每日 04:30 UTC 流程，最多每国 100 条 RSS、1 MiB 响应；RSS 失败是未知。

近似检索只提出“深化哪个已有页面”，至少有两个词匹配、最低分和歧义差距；分数是词向量相似度。来源文字不会成为指令。新近似匹配始终为 research-only，不能绕过原有当地痛点、官方指导、型号、时效和发布质量门槛。

现有自动内容发布器继续在已授权范围内处理经过验证的 DE/GB 官方产品资料，遵守每天最多一篇、来源时效、原始事实数量、同市场需求和可追溯来源要求。此次没有放宽它，也没有让弱热搜自动变成商品页。

**实时推荐分两层：**

1. 当前已可运行：本地搜索词实时匹配该语言的已有决策页；固定任务卡免填写；德国热门阅读只依据德国 human-class 访问。搜索词不出浏览器，不据此建立个人画像。human-class 仍只是 UA 分类，不保证每条是真人。
2. 转化学习待数据就绪：每个合格推荐展示只产生一次机会，记录固定卡片 ID、同一分组和一次可关联点击；拒绝机器人、QA、无同意/已退出及缺失分母的数据。只用同窗口、同市场、同版本的匹配展示/点击，和可核验佣金独立关联。现有 page_view/affiliate_click 聚合不能代替此训练集。

学习候选模型：每市场/意图/卡片的 Beta-Binomial，`p | data ~ Beta(1+c, 1+n-c)`，其中 `n` 是已匹配的合格展示机会，`c<=n` 是其中发生目标动作的机会。输出均值和区间，绝不把事件数/用户数当转化。先离线时间切分评估校准与排序，再 shadow mode，再随机对照；样本不足回退固定编辑推荐。用于推荐相关性，不推断个人收入、国籍特征或紧迫感。

## A/B 方案与统计验收

第一项实验只测试 DE 晾衣页的任务入口表达：A 保持当前入口；B 使用“同一批衣物：比较耗电与时间”的明确任务文案，工具、商家和价格保持一致。页面内容/SEO 不按机器人与真人区别提供。

随机化单位为获得有效测量授权的会话，在整个实验保持分组，排除跨组污染。主指标为同一合格会话内完成工具判断并发生相关商家交接的比例；次指标为工具完成、回退/错误率与已验证净佣金。只有事件可关联且每会话去重，才计算比例；目前不能据现有聚合报表启动该分析。

启动前冻结基线 p、最小可检测差异、双侧 α=0.05、power=0.8、样本量和最长时长；不得以每周显著与否提前停。等分两组时每组近似样本量由两比例检验公式计算，不填虚构基线。每市场分别观察，不混合英国和德国提高“显著性”。14 日是最低完整观察周期，不是达到统计把握的保证。当前不启动随机实验，先修好分母与数据可读性。

## GEO / SEO / IndexNow 的发布合同

- HTML 直接可读的结论、适用地区、方法、单位、假设、原始来源、作者/编辑责任和诚实修订日期。专业判断提供“不适用/不知道”的边界；不要伪造实测、评分或专家背书。
- Markdown 从同一 HTML 生成，保留已存在的官方/技术参考链接；精确域名与路径白名单，剔除商家、联盟、带跳转参数或冒充域名的 URL。协商 Markdown 优先读取构建镜像，避免把工具证据表丢掉。链接可读不等于所有事实已核验。
- `canonical` 指向 HTML，真实等价语言才建立互返 hreflang，私有和 noindex 页面不进索引；工具、分类页与解答互链；FAQ/结构化数据必须与页面可见内容一致。`llms.txt` 是辅助发现入口，不是排名协议。
- 不存在“每个欧洲国家专属 AI 的统一开关”。按语言/国家建立人工可复验的问题集，分别检查 ChatGPT、Copilot/Bing、Gemini、Perplexity、Mistral 等实际引用及落地页。没有可读来源就记录未知，不把 robots 许可、爬虫请求或自测当推荐背书。
- AI 爬取、被引用、引荐访问、工具成功、商家交接、佣金分别度量；缺失 referrer 和统计同意会漏记。索引原因须由搜索平台数据核验，不能用 GA 零访问推断未收录。
- 保持现有 sitemap/IndexNow 增量流程，只处理适用且确有变化的 URL，不新增逐 push 全站提交。HTTP 接受仅表示接收，不等于抓取、收录、引用或流量增长。
