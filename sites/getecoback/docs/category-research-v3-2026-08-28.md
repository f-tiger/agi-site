# 品类调研 v3:把「变现层」也当成候选(2026-08-28,owner:「应该扩展品类调研」)

## 0. v2 的盲区(先说清楚哪里窄了)

v1/v2 与本会话早些时候那轮,**候选全部是「卖什么产品」,变现形态默认是 Amazon 联盟**。
六轴里只用了一轴半。结果:所有结论都被 Amazon 的费率带(2,5–6%)封顶,而这个前提
**从未被检验过**。本轮补上的是**费率/变现形态轴**——它比再找十个品类都值钱。

## 1. 本站单位经济(先立基准)

- €9,96 / 125 点击 = **€0,08 每次联盟点击**;€9,96 / ~600 pv = **€0,017 每次浏览**。
- 混合费率 **4,11%**,平均下单额 ~€92 → **约 €2/单**。
- 点击分布(D1 全窗口):95 次点击里 **83 次(87%)来自制冷簇**,秋冬两族合计 4 次。
- **要靠量做到 €100/月 需要流量翻 10 倍**;两个月内容投入没抬起流量 → 量这条路置信度低。

对比现在 ~€10。**转化率打到四分之一仍有 3 倍。**

## 3. 诚实的反面(不写就是骗自己)

1. **Amazon 的优势是转化,不是费率**。4,2% 点击→成交有很大一部分来自 Amazon 本身
   (一键结账、Prime、信任)。垂直小店几乎必然转化更差,差多少**未知**。
2. **必须 owner 申请并通过**(与 PartnerNet 同类),我无法代劳。
3. **线索侧受众错配——本轮已用现有数据实测,结论是杀(见第 3.1 节)。**
4. **DAA 按「有效」询单付费**:把不合格的租客推进去等于零收入,还可能被关停。
   任何线索面必须先用站内计算器做**业主/自有房**的资格问询,不合格者不进漏斗。
5. **能源板块 08-26 刚被 owner 降级**——那个决定基于 **Amazon 费率下的证据**
   (2 次点击 × €2 = €4)。费率轴改变的是**每次点击的价值**,不改变**26 pv/28 天**这个
   流量事实。10% × 几乎没有流量 = 几乎没有钱。**所以本条不构成「恢复能源板块」的理由**,
   它只构成「同样的点击别再用最差的通道」。

### 3.1 受众实测:不建探针,直接从落地页意图推断(2026-08-28)

上次 `lead_intent` 判负基于 0/11 次浏览,没有统计效力。但本站**不需要再建一个探针**——
落地页本身就是意图信号:有些页只有**不能改建筑**的人才会读(免打孔、Kippfenster、租房、
窗封),有些页只有**能装设备**的人才会读(阳台电站、储能、换供暖、红外安装)。

| 页面意图信号 | pv | affiliate_click |
|---|---|---|
| **租客信号**(mietwohnung / ohne-kernbohrung / ohne-bohren / kippfenster / dachfenster / 窗封) | **103** | **19** |
| **业主信号**(balkonkraftwerk / balkonspeicher / growatt / heizung-tauschen / infrarotheizung / heizkosten-vergleich) | **27** | **1** |

可辨意图的流量 **103 : 27 ≈ 79% : 21% 偏租客**;钱线上是 **19 : 1**。

**判定:PV/热泵线索方向(DAA €4-60/条、Vamo €30)对本站不成立,正式杀死并写入手册。**
理由不是「没人点探针」,而是**这批读者本来就不是业主**——把他们推进线索漏斗只会产出
无效询单,还可能被联盟方关停。**不要再提第三次。**

*诚实边界:落地页是代理指标不是自陈,租客也可能出于好奇读阳台电站页。但 19:1 的钱线
差距方向明确,且与本站定位自洽——「ohne feste Installation」本来就是写给不能施工的人的。*

**反过来,这个发现让候选①更强**:移动空调正是租客买的东西,而 Klimaworld 的 10% 恰好
覆盖它。**费率轴与本站受众相容,线索轴不相容。**
