# Instant examples and user-directed tool sharing

Forty-two existing consumer calculator pages now show an explicitly illustrative result without requiring typing. Scenario buttons reuse the existing calculation handlers and models; users can inspect assumptions or edit the original fields. Examples are not measurements, current tariffs, personalized recommendations or completed personal calculations. Required personal confirmations remain unchecked. People needing real evidence, uploaded documents or a contextual assessment still supply that evidence.

All 56 public tool pages and nine localized workbench pages receive a user-controlled sharing entry. Supported calculator results can be prepared as a draft with assumptions, a reproducible URL fragment and a PNG. Reddit/X intents are opened only by the user. Links are schema-checked on arrival; editing, resetting or importing invalidates outdated shares. Workbench/evidence tools share the public tool URL, not customer documents or paid outputs. Existing entitlements and checkout behavior are unchanged.

The audience is households evaluating comfort and energy costs, plus users discussing the existing tools. Free value is an immediate worked example and a defensible calculation to discuss; buying or paying is not required for these consumer examples. No posts, messages, advertising spend or publishing schedule were created. Sharing preparation and outbound intents do not establish a published post, visits, purchases or revenue.

Fixed opt-in analytics actions distinguish example selection, draft preparation, Reddit/X intent, successful copy and image export. No input values or file content are included in these event payloads. The new sharing flow puts numeric scenario values in the draft/link/image the user chooses to prepare. Existing country-calculator share buttons now also generate fragment-based links; old query links remain readable. Browser fragments keep these values out of HTTP requests to EcoBack.

Validation includes all 65 distribution pages, 42 automatic examples, share-state round trips, malformed fragments, narrow screens, no automatic completion events, and stale-share invalidation. Existing mathematical and browser regression suites are retained. SEO/GEO content, canonical URLs and formulas remain on the original pages; generators attach the experience after the tool builds and analytics coverage runs afterward. IndexNow follows the existing deployment delta policy. Real conversion lift and GA4 backend event receipt require subsequent evidence.
