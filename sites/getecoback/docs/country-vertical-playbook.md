# 国家垂直卖货 playbook —— 从 eco 的德国盘总结,给下一个国家用

写于 2026-09-15,owner 目标:「eco 前面的核心是德国国家垂直的推荐卖货,扩展不同国家子站点,
卖不同货品,特别是美国侧流量最大,实现不同国家都可以营收」。

**本文只写实测数字和由它们推出的规则。没有行业通论,没有「最佳实践」。**
每条规则后面都带它是怎么被证出来的;推不出来的地方明写「不知道」。

---

## 一、德国盘到底是什么形状

| 项 | 实测 | 窗口 |
|---|---|---|
| 德语指南页 | 137 | 2026-09-15 |
| 德国真人 pv | 280 | 28 天 |
| 德国点击 | 43 | 28 天 |
| **德国 pv→click** | **15,4 %** | 28 天 |
| 单点击价值 | **€0,085** | PartnerNet 30 天窗至 08-30 |
| 每件佣金 | **€1,03**(上一期 €1,99) | 同上 |
| 站内 tagged 链接 | 1.875 处 | — |

**一个市场(amazon.de)、一个 tag(getecoback-21)、一个语言。** 这就是全部。
没有多市场路由,没有比价,没有自建商城。

## 二、真正带来点击的是什么形状的页

不是品类页,不是「2026 最佳 X」,是**处境受限的安装题**。实测排名前列的页全是这一类:
房车、翻转窗、天窗、无钻孔 Split、越冬收纳。共同点是读者已经决定要买,卡在「我这个情况能不能装」。

反面同样实测:
- **08-29 的 16 个品牌/型号测评页,9 天合计 1 次 pv。** 产品页形态在本域不起量。
- **`heizluefter-stromsparend` 有 96 条站内入链,D1 全史 0 行。** 内链救不了排名。
- **「给已有完整货架的页面再加卡」**:75 个零点击页里 258 pv,全都已有意图匹配的货架。加卡无效。

→ **新国家不要从「写一批产品页」开始。**

## 三、新页冷启动 ≈ 0(五个独立队列)

| EN qm 13 页 + IT 11 页 | 8 天 0 |

`/it/` 是最直接的教训:**它就是「新建一个国家子站」的完整实验,结果是零。**
索引没坏(新页 2 天可被发现),坏的是排名。

→ **在一个国家有实测流量之前,不要为它建页面区。**

## 四、美国那条做对了什么(可复制的部分)

不建新区,**改已有流量落地页上的货与市场**:

1. **先量国家**。28 天 US 已是第二大来源(124 pv),不缺流量。
2. **找到该国搜索真正送来的是哪几页**。US 的搜索流量集中在英文故障排查页
   (`portable-ac-leaking-water` 10 次里 8 次来自搜索),不是首页也不是品类页。
3. **换货**:货架与买入条同时换成该国有来源的型号(`US_MODELS`,按具名美国媒体交叉核过)。
   **只换一半比不换更糟**——页面会同时推荐两个国家的机器。
4. **换市场**:链接走该国 Amazon + 该国 tag,**按名搜索不带 ASIN**(没在那个市场验过 ASIN,
   猜一个就是在新国家重犯 EX105 的错)。
5. **默认显示本地货**,用地理门揭示他国货:`America/*` / `Europe/*` 零网络直接判,
   其余问 `/api/geo`。无 JS 时显示多数读者对应的那套。
6. **点击分来源记**(`us-shelf` / `us-toppick` vs `models` / `toppick`),否则判定线没法读。

## 五、开一个新国家之前必须过的四道门

**① 量门**:该国 90 天点击 **≥30 次**(≈10 次/月)。
依据:IT+ES+FR+NL+PT 合计 16 次/90 天 ≈ 5 次/月,按 €0,085 算**不到 €0,5/月**,
写地理切换代码的工时永远赚不回来。US+CA 是 21 次且在增长,所以值得。

**② 账号门**:该市场的 tag 必须真的计佣,**且域名已列进该 Associates 账号的站点列表**。
两条实测反例:`getecoback-21` 在 amazon.co.uk **不计佣**(GB 8 次点击全部白送);
US 侧必须先把 getecoback.com 列进站点列表才切,否则佣金可判无效。
**这一步是 owner 侧的,不能替他做,也不能假设。**

**③ 物理门**:电压/插头/配送/关税能不能让这件货在那个国家真的用起来。
实测案例:**美国便携空调 115 V / 60 Hz,在欧洲 230 V / 50 Hz 插座上不能通电。**
所以讲「在西班牙/意大利/法国给房间降温」的页面**永不换成美国货**,与读者国籍无关。
这条不是口味问题,是一台插不上的机器。

**④ 货源门**:该国的推荐型号必须有**可归因的来源**(具名媒体的公开测评),
不能凭印象列。列不出来就只上品类链接,不要点名型号。

## 六、度量与判定(不设这些就别开工)

- 每个新国家的点击必须带**独立 source**,否则和本土点击混在一起,判定线读不出来。
- 判定线预登记两个数:**该国 source 点击数**,与**该国点击里落在正确市场的占比**。
- 归零时先查**机制有没有跑起来**(地理门是否被调用),再谈「这个国家不买」。
- PartnerNet 数字要带数据窗日期;沙箱进不去,过期数字等 owner 截图刷新。

## 八、不要再做的(实测判死,勿复活)

- 在没有流量的国家先建页面区(`/it/` 已证)
- 用内链救排名(96 入链 → 0 pv)
- 给已有匹配货架的页再加卡
- 为月点击个位数的国家写地理切换
- 猜 ASIN、猜型号、猜测评结论
