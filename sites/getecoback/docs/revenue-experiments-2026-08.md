# 营收方向实验组合（2026-08 启动）

## 0. 方法学前提：为什么这里**不能**做 A/B 测试

站点当前流量 ≈ **220 page_view / 28 天**。

标准 A/B split 测试要在 11% → 14% 的相对提升上达到 80% power、95% 置信，每臂需要 **≥2,000 会话**。
按现流量，一次测试要跑 **1.5 年以上**才可能显著 —— 期间季节、内容、排名全变了，结论无效。

**所以本组合不做 A/B 分流，改用"预注册证伪阈值的顺序式多臂实验"（pre-registered sequential portfolio）。**

科学依据：小样本下唯一可靠的测量不是"优化幅度"，而是**存在性**（effect size 巨大的信号）。
"有没有人愿意点这个方向"在 n=30 次点击时就有判别力；"CTA 改色提升 12%"在 n=2000 前毫无判别力。

**对抗性设计**：每条方向先写死"什么结果算这条路死了"，然后主动去撞那个阈值。
不设"成功了就继续"的模糊条件——只设**证伪条件**。撞到就杀，不留恋。

### 核心洞察
**一条 PV 线索（25–80€）≈ 2–8 台空调的 Amazon 佣金。**
而线索只需填表，购买需要真金白银下单——**转化率结构上高一个量级**。
这意味着：在同样的流量下，C 的期望收入可能是 A 的 5–20 倍。**这是本轮实验的主假设。**

## 2. 实验臂设计（预注册）

### 实验 1：渠道偏好探针（Amazon vs Fachhändler）— 验证方向 B
- **假设 H1**：买 Balkonkraftwerk 的用户中，有相当比例**更想去专业商家**而非 Amazon（因为需要咨询、保修、安装支持）。
- **最小实现**：诚实对比页 `/guide/balkonkraftwerk-wo-kaufen.html`，同时呈现两条真实路径，用 GA4 分别记录出站点击（`outbound_choice: amazon | fachhaendler`）。
- **✅ 存活条件**：60 天内该页出站点击 ≥30 次，且 **Fachhändler 占比 ≥25%**
- **❌ 证伪（杀）**：Fachhändler 占比 <10%，或总出站 <10 次 → 垂直联盟不值得注册，专注 Amazon
- **若存活 → owner 动作**：注册 Kleines Kraftwerk（10%）或 solago（6%），换成带追踪的联盟链接。期望：**80€/单 vs 48€/单**

### 实验 2：线索意向探针 — 验证方向 C（主假设）
- **假设 H2**：我们的能源受众里有一部分是**房主**（不是租客），他们的真实需求不是 800€ 的阳台光伏，而是 15,000€ 的屋顶 PV / 热泵 —— 这部分人愿意留资比价。
- **最小实现**：能源簇页面注入意向条「大屋顶也想装？先比 3 家报价」→ 点击记 `lead_intent`，落到对比页的房主专区（诚实说明我们目前只做导购、不卖线索）。
- **✅ 存活条件**：60 天内 `lead_intent` ≥15 次，且其中 ≥5 次来自 organic/AI 流量（非直访噪声）
- **❌ 证伪（杀）**：`lead_intent` <5 次 → 受众纯租客/DIY，线索方向不成立，删除探针
- **若存活 → owner 动作**：接线索买家（本地 PV/热泵公司，25–80€/条），或加入现成线索平台

### 实验 3：Widget 反链飞轮（已上线，观测中）— 验证复利基建
- **假设 H3**：免费 Widget 能自发获得嵌入（= dofollow 反链 + 引荐流量），形成不依赖平台的复利。
- **✅ 存活条件**：90 天内 ≥3 个外部域名嵌入（GA4 referral 或 GSC 链接报告可见）
- **❌ 证伪**：90 天 0 嵌入且 `embed_copy` <5 → 免费 Widget 无自然吸引力，需转为主动 outreach 或放弃

### 实验 4：季节复利验证（自动，无需动作）
- **假设 H4**：全年 Raumklima 定位（夏冷/秋湿/冬暖）能让流量跨季不归零。
- **✅ 存活条件**：9–10 月（Herbst 档）自然流量 ≥8 月的 70%
- **❌ 证伪**：跌破 40% → 说明本质仍是夏季站，需重构定位或接受季节性

## 3. 观测与判定纪律

- **统一观测期 60 天**（实验 3/4 为 90 天），中途不看单日噪声，不提前下结论。
- **Direct 流量视为爬虫噪声**，判定只用 organic + AI referral + 站内路径。
- **前提依赖（已自行解决，2026-08-05）**：不再依赖 GA4/Supermetrics。改用自建 Cloudflare D1 事件管线（`/api/ev` + `ecoback-events`），查询方式见 `analytics-first-party-d1.md`，CI 每次部署断言写入通路可用。判定数据从 2026-08-05 起累积。
- 每条方向的判定结果——无论生死——都写回本文件和 CLAUDE.md 决策记录。

## 4. 明确否决的方向（附理由，防止未来重复评估）

**F. Web3 / DePIN / 代币化能源**——否决。
1. **受众错配**：站内用户是德国租客和房主，搜索意图是"我的房间太热怎么办"。这个人群与加密受众的重叠接近于零，没有任何一条 GA4 数据显示 web3 意图。
2. **赛道已饱和**：本仓库 2026-07 的调研已确认发电端 DePIN 项目饱和、通用加密返现饱和（见 `web3-research-compounding-opportunities.md`）。
3. **历史教训**：本站前身"稳定币返现"定位已被否决过一次（`web3-product-plan-onchain-data-subscription.md`），且"返现"承诺因从未真实存在而在 07-19 全站移除——重蹈覆辙会再次损害 E-E-A-T。
4. **合规风险**：向德国消费者推加密产品涉及金融推广监管（MiCA），与现有 Amazon 联盟合规栈冲突。

**关于"孙宇晨式致富实验"的诚实判断**：那套打法的核心是**注意力套利**（争议营销 + 高频事件 + 币价反身性），它的前提是有一个可被投机的资产和一个投机受众。本站是**需求驱动的工具站**——用户带着具体问题来（房间太热、地下室发霉、电费太贵），复利来自"解决问题→信任→成交→SEO/AI 权重累积"这条慢飞轮。把注意力套利套在这上面会直接摧毁 E-E-A-T 和联盟账号。**方向选择应服从受众，而不是服从某种打法。**

**E. 展示广告**——现流量下月收入 <1€，且拖慢 CWV、挤占联盟点击。**流量到 10,000 pv/月 前不评估。**

- **背景**：用户提议"转售 1688 便宜货快速变现"。核实后**否决自建转售**——把中国电器首次投放德国市场者法律上视同制造商，须在开卖前完成 Stiftung EAR 注册 + 年度破产担保 + 处置费 + 产品标识，另有 LUCID 包装法、GPSR、14 天撤回权、2 年质保、IOSS 增值税、CE/RoHS；移动空调常用 R290 丙烷制冷剂属危险品运输。未合规＝罚款 + 销售禁令。且公司/支付 KYC/1688 账号/清关/仓储/退货全部绑定法人身份，**无法自动化**。
