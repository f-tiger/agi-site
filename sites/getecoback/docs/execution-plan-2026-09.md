每个优化改动上线前必须同时过三道门，缺一即为空转、不做：
1. **数据门**：有一手数据信号支持（D1 事件 / Bing 引用明细 / GSC / 爬虫日志）——
   没有数据依据的选题一律不做，包括「看起来该做」的

3. **商业门**：能一句话回答「这个改动把用户推向哪条营收路径」（点击→成交 /
   引用→钩子 / 探针→联盟激活）——回答不出就说明是空转
每个过门改动照旧带日期判定线。本文件与 PRD-energie-vertiefung 的选题都已按三门标注。
