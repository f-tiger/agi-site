# 网站重做策略：从 B2C 联盟站 → B2B 工具/内容供应商

> 触发：owner 判断"联盟站流量起来太慢"。本文档给出 10 个营收方向的评分、重做后的架构、以及可证伪的实验设计。

## 0. 问题的正确诊断

联盟站的收入公式是：**流量 × 转化率 × 18€**。
三个乘数里，转化率我们已经做到 11%（行业 2–5%），单价被 Amazon 佣金表锁死，**唯一能动的是流量——而它恰好是新域名上 6–18 个月的慢变量**。

也就是说：**不是执行不到位，是模型本身把成败押在了最慢的那个变量上。**

正确的重做方向不是换个题材再做一遍联盟站，而是**换一个不需要大流量就能产生收入的模型**。

## 2. 核心洞察：卖给"供给侧"比卖给"需求侧"快 10–100 倍

| | B2C（现状） | B2B（重做方向） |
|---|---|---|
| 单客户价值 | 18 €/单，一次性 | 29 €/月 = **348 €/年，经常性** |
| 达成 1000 €/年需要 | 56 笔成交 → 约 500 次点击 → 约 5,000 访问 | **3 个客户** |
| 获客方式 | 等 SEO 排名（6–18 个月） | **20 次合规接触（1 天）** |
| 验证成本 | 需要流量才能测 | **不需要流量就能证伪** |

而且德国手工业企业**已经有这笔预算**（软件 39.90–300 €/月、网站维护 75–200 €/月），痛点也真实：他们的网站普遍没有互动工具和专业内容——**而这恰好是我们这半年造出来的东西**。

**三个已有资产直接变成 B2B 产品：**
1. 8 个计算器 + Widget 嵌入基建 → 白标授权
2. 135 页德语专业内容 → 内容包授权
3. 消费者站的流量与信任 → 演示场 + 线索来源

## 3. 重做后的架构（保留复利，改变变现层）

```
getecoback.com
├── 消费者层（保留全部 135 页）        ← 不删！它是 ①信任证明 ②SEO/AI 资产 ③线索来源
│   ├── /guide/*   内容 + 工具
│   └── /widgets.html  免费版（带我们品牌链接）= B2B 的漏斗入口
└── 企业层（新增）                     ← 收入来源在这里
    ├── /fuer-betriebe.html   B2B 落地页：白标 Widget + 内容包
    └── （后续）客户专属 widget 实例
```

**为什么不推倒重来**：135 页内容 + 域名年龄 + AI 引荐（ChatGPT 已超 Google）+ 已达成的两个里程碑，都是**已经付出成本且不可快速再造**的资产。删掉它们等于把唯一的信任证明和演示场清零——而 B2B 客户第一个问题就是"你们凭什么会做这个"。**保留消费者站，正是 B2B 的销售论据。**

## 4. 实验设计（延续预注册证伪阈值，本轮全部不依赖流量）

### 实验 5：白标 Widget 需求验证（主实验）
- **假设**：德国 Solarteur/SHK 企业愿意为"能嵌进自己网站、带自己 Logo 的专业计算器"每月付 19–49 €。
- **最小实现**：`/fuer-betriebe.html` 报价页（三档：免费带我们链接 / 白标 19 €月 / 含内容包 349 € 一次性），CTA = 询价（不收款——先验证需求再建计费）。
- **测量**：`b2b_intent` 事件按档位分；owner 侧做 20 次**合规接触**（电话或明信片 → 口头同意 → 再发邮件；冷邮件在德国无同意时违法，见外联套件）。
- **✅ 存活**：20 次合规接触 → **≥3 家表达兴趣**，或 ≥2 次 `b2b_intent`
- **❌ 证伪（杀）**：20 次接触 0 兴趣且 30 天 0 `b2b_intent` → 白标方向死，转 §1 方向 2 或 3
- **周期**：30 天（不是 60——B2B 反馈快得多）

### 实验 6：内容包需求验证
- **假设**：企业愿意一次性付 349–899 € 买现成的德语专业内容包（10 篇 Ratgeber，可署自己名）。
- **测量**：同页第三档的 `b2b_intent{plan:'content'}`
- **✅ 存活**：≥2 次询价 / 30 天　**❌ 证伪**：0 询价 → 杀

### 实验 1–4（上一轮，继续跑）
渠道偏好探针 / 线索意向探针 / Widget 反链飞轮 / 季节复利——详见 `revenue-experiments-2026-08.md`。

## 5. 再次否决 Web3（本轮复核，理由不变且更强）

用户再次点名 Web3。复核结论：**仍然否决**，因为本轮新增了一个更强的反证——
我们刚刚发现了一个**已被市场验证有真实预算的客户群**（德国手工业企业，已在付 39.90–300 €/月）。
在存在"确定有钱、确定有痛点、20 次接触就能验证"的方向时，把资源投向"受众零加密意图、赛道已饱和、MiCA 合规风险、且本仓已两次否决"的 Web3，**是负期望值的决策**。

关于"孙宇晨式致富实验"：那套打法的内核是注意力套利，需要可投机资产 + 投机受众。本站两者都没有。
**真正与之等价的"快速致富杠杆"在这里是：从卖 18 € 的佣金，换成卖 348 €/年的订阅。** 同样是杠杆，但杠杆点在单位经济，不在注意力。
