# B2B 外联套件（实验 5/6 · owner 侧唯一人工动作）

> **2026-08-06 重写：上一版建议"发 20 封冷邮件"，那是错的，已作废。**
> 核实后确认：**德国 B2B 冷邮件在无事先明示同意时原则上违法**（§7 UWG）。UWG 里的"推定同意"
> 只适用于**电话**，不适用于电子邮件。无同意即可被 Abmahnung，典型费用 **500–2,500 €** 外加
> 停止侵害声明。本套件因此改为**先电话或书信、拿到同意后再发邮件**。
> 来源：[Nexsale](https://www.nexsale-consulting.de/wissen/kaltakquise-b2b-email-erlaubt/) ·
> [CegTec](https://www.cegtec.net/wissen/kaltakquise-b2b-email-rechtslage/) ·
> [ripeleads](https://ripeleads.eu/de/kaltakquise-email-dsgvo)
> **这不是法律意见。** 规模化之前请咨询竞争法/数据保护律师。

**目标**：20 次合规接触 → 判定"德国手工业企业是否愿意为白标计算器付费"。
**判定线**：≥3 家表达兴趣 = 方向存活，建计费与白标参数；30 天 0 回应 = 方向死，转内容包或线索方向。

---

## 0. 合规顺序（照这个顺序，不要跳步）

```
①  打电话（合法：B2B 推定同意）   ←— 或 —→   ①' 寄一张明信片（书信广告合法，仅需 opt-out）
                 ↓
②  电话里问这一句："Darf ich Ihnen den Link kurz per E-Mail schicken?"
                 ↓
③  对方说 "ja" = 明示同意 → 此时发邮件完全合法，而且对方在等它
```

**为什么这样反而更好**：邮件从"陌生打扰"变成"你要的那个链接"，打开与回复率高一个量级；
同时你留下了同意记录（记"日期 + 对方姓名 + 口头同意"即可）。

---

## 1. 找 20 家目标（约 20 分钟）

**筛选条件（10 秒内判断完）**
1. 有自己的网站（不是只有 Facebook 页）
2. 网站上**没有任何互动工具**（没有计算器、没有配置器）← 这就是切入点
3. 业务落在下表四个主题之一
4. **本地中小企业**，不是全国连锁（决策链短，接电话的常常就是老板）

**现成目录（直接能列出一批）**
- [muenchen.de 行业簿 · Bautrocknung/Schimmelbeseitigung](https://www.muenchen.de/service/branchenbuch/B/2560.html)（慕尼黑 24 家）
- [11880.com · Bautrocknung München](https://www.11880.com/suche/bautrocknung/muenchen)（109 家）
- 或直接 Google 下表搜索词，每城取 4 家 × 5 城 = 20 家

| 细分 | 搜索词（换城市即可） | 最该推的工具 | 为什么对口 |
|---|---|---|---|
| 防霉 / 建筑干燥 | `Bautrocknung München` / `Schimmelsanierung Köln` | **Taupunkt-Rechner** | 客户最常问"现在该不该开窗"，露点算的正是这个 |
| Solarteur / 阳台光伏商 | `Solarteur Leipzig` / `Balkonkraftwerk Händler Stuttgart` | **Balkonspeicher-Rechner** | 客户第一个问题永远是"能省多少" |
| SHK（供暖 + 空调） | `SHK Betrieb Klimaanlage Hamburg` | **BTU-Rechner** | 报价前必须先定制冷量 |
| 能源顾问 | `Energieberater Dresden` | **Stromkosten-Rechner** | 咨询时当场算给客户看 |

建议城市组合：München、Köln、Leipzig、Stuttgart、Hamburg（避开柏林，竞争最密）。

## 2. 电话脚本（合法渠道 · 60 秒 · 照着念）

> 拨号前看一眼对方网站首页，记住一个具体的词（他们的主营项目）。整段脚本只需要这一个词。

```
Guten Tag, mein Name ist [Name] von EcoBack.

Kurz und ohne Umschweife: Wir bauen kostenlose Fach-Rechner zum Einbinden in
Handwerker-Websites. Ich habe gesehen, dass Sie [Schimmelsanierung / Balkonkraftwerke /
Klimaanlagen] anbieten — dafür haben wir einen [Taupunkt-Rechner / Balkonspeicher-Rechner /
BTU-Rechner], den Sie in zwei Minuten auf Ihre Seite setzen können.

Der Punkt für Sie: Wer auf Ihrer Seite ausrechnet, wie viel er braucht, kommt mit einer
konkreten Zahl ins Erstgespräch statt mit einer offenen Frage. Und der Ergebnis-Button
führt zu Ihrem Kontaktformular, nicht zu uns.

Kostet nichts, keine Registrierung, kein Plugin — eine Zeile HTML.

Darf ich Ihnen den Link kurz per E-Mail schicken, dann schauen Sie in Ruhe rein?
```

**"Und womit verdienen Sie Geld?"** — 照实答：
```
Der freie Rechner trägt einen kleinen Quellenlink zu uns, darüber finden uns neue Besucher.
Wenn Sie den weghaben oder Ihr Logo drin haben möchten, gibt es eine kostenpflichtige
Version — die brauchen Sie aber nicht, um loszulegen.
```

**"Ich habe gerade keine Zeit."** —
```
Verstehe. Soll ich Ihnen den Link trotzdem schicken, dann liegt er da, wenn es passt?
```
（依然是在争取那句 "ja" ＝ 同意。）

## 3. 明信片 / 信件（完全合法，无需同意；在邮件泛滥的市场里反而显眼）

正面印一张计算器截图，背面：

```
Kostenloser Rechner für Ihre Website

Sie beraten zu [Schimmel / Balkonkraftwerk / Klimaanlagen] — wir haben dafür einen
fertigen Rechner gebaut, den Sie kostenlos einbinden können. Zwei Minuten, eine Zeile
HTML, kein Plugin.

Wer bei Ihnen rechnet, landet mit einem Klick auf Ihrem Kontaktformular.

Ansehen: getecoback.com/widgets.html

EcoBack · [Impressum-Zeile]
```

## 4. 拿到同意后的邮件（**只在对方说过 ja 之后发**）

**Betreff：** Wie besprochen: der [Taupunkt-Rechner] für Ihre Website

```
Hallo [Name],

wie eben am Telefon besprochen — hier der Link:

getecoback.com/widgets.html

Was Sie dort tun können, ohne sich anzumelden:
• Rechner auswählen (Taupunkt, BTU oder Stromkosten)
• Ihre Farbe einstellen
• Die URL Ihres Kontaktformulars eintragen — der Ergebnis-Button führt dann dorthin
• Den fertigen Code kopieren und einsetzen

Kostenlos und dauerhaft nutzbar. Einzige Bedingung ist der kleine Quellenlink zu uns.
Wenn Sie den entfernen oder Ihr Logo einbinden möchten, schreiben Sie mir einfach zurück.

Wenn Sie keine weiteren Nachrichten möchten, antworten Sie kurz mit „Nein" — dann melde
ich mich nicht wieder.

Viele Grüße
[Name]
EcoBack — getecoback.com
[Impressum-Zeile: Firma, Anschrift, Kontakt]
```

**两样不能省**：完整 Impressum 行、以及那句退订提示。

## 6. 判定

- **✅ 存活**：20 次接触内 ≥3 家表达兴趣，或 30 天内 ≥2 次 `b2b_intent` → 建付费档（去来源链接 / 自有 Logo / 使用报表）与计费。
- **❌ 证伪**：20 次接触 0 兴趣且 30 天 0 `b2b_intent` → 白标方向死，转内容包（299–899 €/次）或线索方向。

## 7. 纪律

- **先给，后卖**：主推免费版，白标只在被问到时提。德国 B2B 对硬推销反感度高。
- **不群发**：电话与信件都要带一个针对对方的具体词。
- **最多跟进一次**（7 天后），再多损害品牌。
